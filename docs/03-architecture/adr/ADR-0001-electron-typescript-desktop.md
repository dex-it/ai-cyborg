# ADR-0001 Настольное приложение на Electron и TypeScript с разбиением на главный процесс и интерфейс

> Реконструировано из кода, не согласовано: решение видно в коде, драйверы и альтернативы восстановлены составителем.

## Decision Drivers

- Продукт запускает локальные процессы CLI в псевдотерминале и читает локальную файловую систему и git (BRD, BR-001, BR-002).
- Интерфейсу нужны эмулятор терминала и просмотрщик кода с подсветкой - зрелые веб-компоненты (xterm, Monaco) снимают их разработку.
- Один язык для системной части и интерфейса - инженерный вывод: снижает стоимость сопровождения личного инструмента.

## Context

Cyborg - рабочее место поверх нативных сессий Claude Code на машине разработчика. Ему нужны доступ к процессам
и файлам ОС и богатый интерфейс с терминалом и редактором.

## Decision

1. Продукт - настольное приложение на Electron; код пишется на TypeScript в строгом режиме.
2. Код делится на две части: главный процесс (процессы сессий, файлы, git, хранение) и интерфейс (отрисовка,
   терминал, просмотр). Интерфейс не обращается к ОС сам, только через границу из ADR-0002.
3. Терминал сессии в интерфейсе - xterm; просмотр файлов - Monaco.
4. Проверка: `tsc --noEmit` проходит без ошибок; модуль интерфейса не импортирует модули ОС (`node:*`, `electron` кроме типов).

## Consequences

- Positive: доступ к ОС и веб-компонентам в одном рантайме; один язык на весь код.
- Negative: размер дистрибутива и памяти Electron; нативный модуль терминала пересобирается под версию Electron.
- Risks: обновление Electron ломает нативный модуль до пересборки.

## Alternatives Considered

- **Расширение VS Code.** Pros: терминал, дерево и редактор уже есть. Cons: привязка к редактору, сессия живёт в
  чужом интерфейсе. Why rejected: продукт задуман отдельным рабочим местом.
- **Терминальное приложение (TUI).** Pros: лёгкое, без браузерного движка. Cons: просмотр кода с подсветкой и
  несколько панелей сложнее. Why rejected: интерфейсу нужны вкладки файлов и подсветка.
- **Tauri.** Pros: меньший размер. Cons: системная часть на Rust - второй язык. Why rejected: один язык на весь код.

## Расхождения с текущим кодом

Расхождений нет.
