# SRS фичи 14 - окно «Расширения»

## 1. SRS overview

Требования к окну «Расширения»: меню, области, чтение магазинов, плагинов, скиллов и серверов MCP, проверка связи, установка и удаление плагинов, подключение магазинов, хабы, каналы главного процесса. Вход - BRD фичи (`brd-feat.md`, BR-14001), код `src/renderer/extensions-dialog.ts`, `src/renderer/extensions-model.ts`, `src/main/extensions.ts`, `src/main/extensions-read.ts`, `src/main/extensions-act.ts`, `src/main/extensions-handlers.ts`, `src/main/extensions-usage.ts`, `src/main/hubs.ts`, `src/shared/extensions.ts`, `src/main/menu.ts`. Основания решений - `decision-log.md` (D-NN) и ADR-0018.

## 2. Purpose

Задать наблюдаемое поведение окна так, чтобы правка проверялась по требованию, а не по коду.

## 3. Scope

Окно и меню «Расширения», вкладки «Магазины», «Установленные», «MCP», «Хабы», области «Сессия», «Проект», «Везде», фильтр, установка и удаление плагина, подключение и отключение магазина, хабы, статистика вызовов, переход на страницу магазина, размер окна, каналы `extensions:load|probe|act|usage`, `hubs:list|change|fetch`. Вне фичи: включение и выключение плагинов, правка серверов MCP, вставка вызова в сессию, запись в файлы Claude Code напрямую (`brd-feat.md`, раздел 3).

## 4. Product perspective

Окно поверх интерфейса (`<dialog>`), как окно поиска (фича 13). Главный процесс читает настройки Claude Code и вызывает `claude plugin ...` через login-шелл пользователя, как сессии; интерфейс получает только разобранные данные без секретов (ADR-0002, ADR-0018).

## 5. Product functions

Вызов окна; области; обзор магазинов, установленного и серверов MCP; проверка связи; установка и удаление плагина; подключение и отключение магазина; хабы и поиск магазина в них; фильтр; статистика вызовов; переход на страницу магазина; размер окна; каналы.

## 6. User characteristics

`inherited`: BRD продукта, раздел 5.

## 7. Limitations

Нужен `claude` в `PATH` пользователя; без него окно показывает файлы настроек и называет причину. Новых npm-зависимостей нет. Linux и `--add-dir` в живой сессии не проверялись (D-02, D-05).

## 8. Assumptions and dependencies

Допущения D-01, D-02, D-04..D-09, D-12..D-17 открыты до подтверждения владельцем. Формат вывода `claude plugin list --json`, `claude plugin marketplace list --json` и итоговой JSON-строки действий проверен на Claude Code 2.1.314; разбор терпит неизвестные поля.

## 9. Apportioning of requirements

Интерфейс: FR-14001, FR-14002, FR-14007, FR-14008, FR-14009 (формы), FR-14011 (вкладка), FR-14015 (подпись), FR-14016, FR-14017. Главный процесс: FR-14003..FR-14006, FR-14010, FR-14012..FR-14014, FR-14015 (подсчёт).

## 10. Specified requirements

Общие атрибуты, если у требования не сказано иное: `feature: 14-extensions`; приоритет - обязательно; основание - Issue #59 (`brd-feat.md`); уровень верификации - модуль (`npm test`) для испытания, собранное приложение (`npm run smoke`) для демонстрации.

## 11. External interfaces

Команды `claude plugin list|install|uninstall`, `claude plugin marketplace list|add|remove`, `claude mcp list`, `claude --version` (запуск через `$SHELL -lc 'exec claude …'`); файлы настроек и журналы сессий Claude Code только на чтение; https-адреса хабов только на чтение; страница магазина открывается браузером системы.

## 12. Functions

### FR-14001 Окно вызывается из меню «Расширения» и сочетанием, на экране его нет

- **Требование:** в меню приложения есть пункт верхнего уровня «Расширения»: «Магазины…» (`CmdOrCtrl+Shift+X`), «Установленные плагины и скиллы…», «Серверы MCP…» и «Хабы магазинов…»; каждый открывает окно на своей вкладке. Пункты доступны, когда выбран проект. Пока окно не вызвано, его на экране нет. `Esc` закрывает форму действия, если она открыта, иначе окно; клик по затемнению и «Закрыть» закрывают окно. Вкладка, область и переключатели фильтра помнятся между запусками.
- **traced from:** BR-14001.
- **источник:** Issue #59; D-05.
- **rationale:** reason - расширения нужны от случая к случаю, постоянное место на экране им ни к чему; assumptions - нет; relationships - FR-13001 (то же устройство окна), FR-14002; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).
- **verification:** испытание - `test/menu.test.ts` («меню «Расширения»»); демонстрация - `scripts/smoke.mjs` (окно закрыто без вызова, пункт меню открывает вкладку).
- **класс:** Functions. **origin:** source.

### FR-14002 Области «Сессия», «Проект», «Везде» и группы по месту записи

- **Требование:** переключатель области определяет, какие записи видны. «Везде» - только то, что действует во всех проектах и воркспейсах (пользователь, организация, claude.ai), с подписью об этом. «Проект» - то же и репозитории проекта, каждый своей группой («Проект · имя»), общее показано один раз. «Сессия» - общее, репозиторий сессии и её рабочий каталог (worktree и репозиторий запуска), затем группы «Доп. каталог · имя» с их скиллами, командами, агентами и плагинами, но без серверов MCP (D-02). Без сессии «Сессия» недоступна и действует «Проект»; выбор человека при этом не затирается. Запись несёт метку места: `везде`, `проект`, `локально`, `организация`, `claude.ai`, `плагин`. По умолчанию - «Сессия» при сессии, иначе «Проект» (D-01).
- **traced from:** BR-14001.
- **источник:** Issue #59 («согласовывалось с областью ответственности проектов, пространств»); D-01, D-02.
- **rationale:** reason - одно и то же расширение действует в разных границах, и человек должен видеть, где именно; assumptions - D-01: область по умолчанию; D-02: подхват `--add-dir` не проверен в живой сессии; relationships - FR-14003..FR-14005, BR-001; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).
- **verification:** испытание - `test/extensions-model.test.ts` («области», «вкладка «Установленные»», «вкладка «MCP»»); демонстрация - `scripts/smoke.mjs` (без сессии «Проект», с сессией «Сессия» и её рабочий каталог).
- **класс:** Functions. **origin:** source.

### FR-14005 Вкладка «MCP»: серверы по областям, без секретов

- **Требование:** вкладка показывает серверы пользователя (`~/.claude.json`), локальные (запись проекта в нём), проектные (`.mcp.json` репозитория, с состоянием «одобрен», «ждёт одобрения», «отключён»), организации (`managed-mcp.json`) и плагинов. Строка: имя, транспорт и подпись - имя программы без аргументов либо схема и хост без пути, запроса и учётных данных. ### FR-14006 Проверка связи серверов MCP - только по кнопке

- **Требование:** при открытии окна и чтении данных `claude mcp list` не вызывается. Кнопка «Проверить связь» (вкладка «MCP») запускает его в каталоге области (в «Сессии» - рабочий каталог сессии, в «Проекте» - каждый репозиторий, в «Везде» - вне репозиториев) и показывает рядом с сервером «подключён», «нужна авторизация», «не подключился» с причиной либо «ждёт одобрения»; подсказка кнопки предупреждает, что программы серверов запускаются. Коннекторы claude.ai появляются в списке только после проверки. Из вывода сохраняются имя, состояние и причина, но не строка запуска. Таймаут - 90 с.
- **traced from:** BR-14001.
- **источник:** Issue #59; проверка 2026-10-30: команда запускает серверы и ходит по сети.
- **rationale:** reason - связь серверов узнать нельзя, не запустив их, поэтому запуск - решение человека; assumptions - нет; relationships - FR-14005; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).
- **verification:** испытание - `test/extensions.test.ts` («проверка связи», «ничего не запускает, кроме чтения»), `test/extensions-model.test.ts` («подпись, одобрение и результат проверки связи»); демонстрация - `scripts/smoke.mjs`.
- **класс:** Functions. **origin:** source.

### FR-14007 Фильтр по имени и описанию: подстрока и регулярное выражение

Подстрока без учёта регистра; «Aa» учитывает регистр, «.*» включает регулярное выражение (те же проверки и пределы, что у поиска: до 200 знаков, без квантора над группой с квантором). Негодное выражение помечает поле `aria-invalid` и называет причину. Названия групп и сноски не ищутся. Показываются первые 1500 строк, остальное - «Показаны первые 1500, уточните запрос».

- **rationale:** reason - в магазине сотни плагинов, нужный находят по имени или описанию; assumptions - нет; relationships - FR-13003; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).
- **verification:** испытание - `test/extensions-model.test.ts` («фильтр и строки»); демонстрация - `scripts/smoke.mjs` (фильтр раскрыл ветку до скилла).
- **класс:** Functions. **origin:** source.

### FR-14009 Установка и удаление плагина

- **Требование:** у плагина подключённого магазина есть кнопка «Установить…», у установленного плагина областей `user`, `project`, `local` - «Удалить…». Кнопка открывает форму с последствиями: установка называет, что плагин запускает программы с правами пользователя, и просит выбрать область («Везде», «Локально», «Проект» - последняя пишет в `.claude/settings.json` репозитория и попадёт в коммит) и репозиторий; удаление называет область и репозиторий установки. Выполнение - `claude plugin install|uninstall <имя@магазин> --scope <область> --json` в каталоге репозитория (для «Везде» - вне репозиториев). `-y` и `--accept-command` не передаются никогда (D-10). Ответ Claude Code (поле `message`) показан в форме; после успеха данные перечитываются. Плагины организации и на сессию из окна не удаляются.
- **traced from:** BR-14001.
- **источник:** Issue #59 («скачивание с подключённых магазинов и удаление плагинов»); D-09, D-10.
- **rationale:** reason - установка и удаление без терминала, но с понятной областью и предупреждением о доверии; assumptions - D-09, D-10; relationships - FR-14003, FR-14012, FR-14014; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).
- **verification:** испытание - `test/extensions-act.test.ts` («validateAction», «actionArgs», «actionMessage», «createActionRunner»), `test/extensions-model.test.ts` («метки: область, выключен…»); демонстрация - `scripts/smoke.mjs` (установка и удаление: вызовы `claude plugin` с областью, без `-y`).
- **класс:** Functions. **origin:** source.

### FR-14010 Подключение и отключение магазина

- **Требование:** «Подключить магазин…» (вкладки «Магазины» и «Хабы») принимает адрес - `владелец/репозиторий` GitHub, https-адрес без логина и пароля, `git@хост:путь` или абсолютный путь на этом компьютере (не начинается с «-», без `..`, до 500 знаков) - и область, как у установки; выполняет `claude plugin marketplace add <адрес> --scope <область> --json`. Магазин, названный репозиторием, подключается кнопкой в строке. «Отключить…» у магазина выполняет `claude plugin marketplace remove <имя>`; форма называет установленные из него плагины, которые Claude Code удалит вместе с ним (D-11).
- **traced from:** BR-14001.
- **источник:** Issue #59 («подключения самих магазинов»); D-11; проверка 2026-10-30: `marketplace remove` удаляет плагины магазина.
- **rationale:** reason - магазин - источник плагинов, и подключение должно быть таким же осознанным, как установка; assumptions - D-11; relationships - FR-14009, FR-14011, FR-14012; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).
- **verification:** испытание - `test/extensions-act.test.ts` («marketplaceSourceProblem», «validateAction»), `test/extensions-model.test.ts` («у подключённого магазина «Отключить…»…»); демонстрация - `scripts/smoke.mjs` (подключение магазина из хаба).
- **класс:** Functions. **origin:** source.

### FR-14011 Хабы: список, встроенные хабы, добавление, отключение, удаление

- **Требование:** вкладка «Хабы» показывает хабы - списки магазинов, у каждого название, описание и, если он отключён, пометка. Встроенные хабы есть всегда, включены по умолчанию, их можно отключить и включить, удалить нельзя: «Anthropic» (официальный магазин, магазин сообщества, `anthropics/skills`, `anthropics/knowledge-work-plugins`), «DEX» (`dex-it/ai-kit`), «GitHub» (готовый пример: восемь самых звёздных магазинов с несколькими плагинами, со звёздами и числом плагинов на дату составления списка, D-15) и «GitHub: поиск по теме» (FR-14012). «Добавить хаб…» принимает название (до 60 знаков, без управляющих) и https-адрес JSON-файла без логина и пароля; повтор адреса и больше 20 своих хабов отклоняются с причиной. Свой хаб можно отключить, включить и удалить (с подтверждением). Список своих хабов и отключённые хранятся в `hubs.json` в папке настроек Cyborg, общий для всех воркспейсов; повреждённый файл не роняет окно (D-07, D-08).

- **источник:** Issue #59 («хабы тоже можно подключать и отключать»); D-07, D-08, D-13.
- **rationale:** reason - знакомых магазинов должно быть откуда выбирать, а список - под контролем человека; assumptions - D-07, D-08; relationships - FR-14012; design constraints - только чтение, подключает человек (ADR-0018).
- **verification:** испытание - `test/hubs.test.ts` («хранилище хабов»), `test/extensions-model.test.ts` («вкладка «Хабы»»); демонстрация - `scripts/smoke.mjs` (встроенные хабы, отключение и включение, http-адрес отклонён).
- **класс:** Functions. **origin:** source.

### FR-14012 Поиск магазина в хабах и подключение из хаба

- **Требование:** включённые хабы загружаются при открытии вкладки «Хабы». Встроенные списки («Anthropic», «DEX», «GitHub») не требуют сети. Хаб «GitHub: поиск по теме» ищет на GitHub репозитории с темой `claude-code-marketplace` (от 20 звёзд, без форков и архивных, по убыванию звёзд, 30 штук) и оставляет те, у которых есть `.claude-plugin/marketplace.json` с именем и списком плагинов; запись называется именем из каталога и показывает звёзды и число плагинов, отброшенные репозитории считаются; ответ держится в памяти 5 минут, «Обновить» читает заново; лимит запросов GitHub называется причиной. Файл своего хаба `{ "name", "marketplaces": [{ "name", "description", "source": { "source": "github" | "git" | "url", … } }] }` читается по https без учётных данных, не больше 1 МиБ, 500 записей и 10 с; запись с иным типом источника, адресом не по правилам FR-14010 или без имени отбрасывается, их число называется. Перенаправление не на https, статус не 2xx, превышение размера и таймаут показываются причиной в хабе. Фильтр (FR-14007) ищет магазины по имени и описанию. У записи кнопка «Подключить…» открывает форму подключения с готовым адресом; подключённые магазины (по совпадению адреса) помечены «подключён». Сам хаб ничего не подключает.
- **traced from:** BR-14001.
- **источник:** Issue #59 («поиск магазинов и подключение по известным хабам»); исследование 2026-10-30; D-07, D-08, D-13, D-14.
- **rationale:** reason - найти магазин по описанию и подключить без копирования адреса; assumptions - D-13, D-14: тема GitHub - заявление автора, поэтому каталог проверяется; relationships - FR-14010, FR-14011, FR-14007; design constraints - запрос без токена и учётных данных, ответ ограничен по размеру и времени.
- **verification:** испытание - `test/hubs.test.ts` («разбор хаба», «получение хаба», «каталог репозитория», «хаб по теме GitHub»), `test/extensions-model.test.ts` («вкладка «Хабы»», `sameSource`); демонстрация - `scripts/smoke.mjs`.
- **класс:** Functions. **origin:** source.

### FR-14013 Чтение настроек Claude Code: источники, пределы, отсутствие claude

- **Требование:** сводка берёт магазины и плагины у Claude Code (`claude plugin marketplace list --json`, `claude plugin list --json`: общий список и по разу из каждого репозитория проекта, не больше четырёх вызовов разом), состав плагина и скиллы - из файлов (`SKILL.md`, `commands/*.md`, `agents/*.md`, frontmatter `name` и `description`), серверы MCP - из `~/.claude.json`, `.mcp.json`, файлов настроек и `managed-mcp.json`, каталог магазина - из `.claude-plugin/marketplace.json` внутри клона (относительный путь плагина не выходит из клона). Каталог настроек переопределяется `CLAUDE_CONFIG_DIR`. Файлы читаются с пределами (8 МиБ, `~/.claude.json` 64 МиБ, 8 КиБ из начала `SKILL.md`, 2000 плагинов магазина, 200 компонентов плагина); повреждённый файл называется в строке состояния и не мешает остальному. Если `claude` не найден, окно показывает причину, а скиллы и серверы из файлов остаются. Неизвестные поля вывода игнорируются.

- **источник:** Issue #59; проверка 2026-10-30 (вывод `claude plugin list --json` зависит от каталога запуска только полем `enabled`); D-03, D-04; ADR-0018.
- **rationale:** reason - сводка не должна зависеть от формата файлов Claude Code там, где есть машиночитаемый вывод, и не должна выдавать секреты; assumptions - D-03, D-04; relationships - FR-14003..FR-14005, FR-14014; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).

### FR-14014 Каналы расширений проверяют аргументы и пути, действие одно за раз

- **Требование:** каналы `extensions:load`, `extensions:probe`, `extensions:act`, `extensions:usage`, `hubs:list`, `hubs:change`, `hubs:fetch` принимают только аргументы своей формы: список каталогов (не больше 32, каждый - репозиторий проекта либо каталог живой сессии), каталог или `null` для проверки связи, действие из четырёх видов (имя плагина `имя@магазин` и имя магазина не начинаются с «-», область из `user`, `project`, `local`, каталог только у `project` и `local` и только разрешённый), операция над хабом, идентификатор известного хаба; `extensions:usage` аргументов не берёт. Значения идут в `claude` отдельными аргументами, не строкой шелла. Одновременно выполняется одно действие: второе отклоняется («Другое действие ещё выполняется»). Таймаут действия - 3 минуты.
- **traced from:** BR-14001.
- **источник:** ADR-0002 (интерфейсу не доверяют); ADR-0018.
- **rationale:** reason - интерфейсу не доверяют: форма и пути проверяются до запуска чего-либо; assumptions - нет; relationships - FR-14009, FR-14010, FR-1017; design constraints - только чтение файлов Claude Code, запись вызовом `claude plugin` (ADR-0018).
- **verification:** испытание - `test/extensions-act.test.ts` («обработчики каналов расширений», «validateAction», «createActionRunner»).
- **класс:** Functions. **origin:** source.

### FR-14015 Статистика вызовов по журналам сессий

- **Требование:** на вкладке «Установленные» у плагина, его скилла, команды, агента и сервера MCP, у отдельного скилла, команды и агента и на вкладке «MCP» у сервера стоит «вызовов N · давность последнего» либо «не вызывался»; подсказка называет точное время последнего вызова. Счёт плагина - сумма по его составу и серверам; у плагина без скиллов, команд, агентов и серверов счёта нет. На вкладке «Магазины» счёт стоит только у состава плагина, установленного в выбранной области. Вызов - инструмент `Skill` (скилл или команда `/имя`), `Agent` или `Task` с `subagent_type` (агент), инструмент `mcp__<сервер>__…` (сервер; у сервера плагина `plugin_<плагин>_<сервер>`, знаки кроме букв, цифр, `_` и `-` заменены на `_`) в ответах модели и набранная человеком команда `<command-name>/имя</command-name>`. Источник - журналы `<CLAUDE_CONFIG_DIR>/projects/**/*.jsonl` этого компьютера, включая журналы субагентов, за всё время и во всех проектах; снимки запроса к API (`"type":"api-request…"`) и скиллы, которые агент подгружает себе сам (`<command-name>` без `/`), не считаются. Журналы только читаются. Подсчёт идёт после показа списка и его не задерживает; пока он идёт, строка состояния говорит «Считаю вызовы по журналам сессий…», ошибка чтения журнала называется там же. Прочитанное хранится в `extensions-usage.json` в папке настроек Cyborg: при следующем открытии дочитываются только дописанные журналы, журнал короче прочитанного читается заново (D-16).
- **traced from:** BR-14001.
- **источник:** просьба владельца 2026-10-31 («нужна статистика вызовов по установленным плагинам»); D-16.
- **rationale:** reason - видеть, какие расширения работают, а какие только занимают место; assumptions - D-16: формат журналов не обещан Claude Code, повторы истории в возобновлённых и ответвлённых сессиях считаются дважды; relationships - FR-14004, FR-14005, FR-1015; design constraints - журналы только читаются (ADR-0018).
- **verification:** испытание - `test/extensions-usage.test.ts` («вызовы в журнале сессии», «кэш статистики», «статистика вызовов в дереве», включая плагин без состава и состав в магазине), `test/static-guards.test.ts` (перечень пишущих файлов); демонстрация - собранное приложение на журналах `~/.claude`.
- **класс:** Functions. **origin:** source.
