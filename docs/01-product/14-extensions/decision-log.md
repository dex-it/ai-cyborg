# decision-log фичи 14 - окно «Расширения»

Решения прогона по Issue #59 (2026-10-30). Владелец поручил «разобраться и решить самому»: все решения - допущения составителя, исход «открыто» до подтверждения или правки владельцем. Проверено живьём в Claude Code 2.1.314 в изолированном `CLAUDE_CONFIG_DIR` и по документации code.claude.com.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Область по умолчанию - «Сессия», пока есть активная сессия, иначе «Проект»; выбор человека помнится и сильнее умолчания, а «Сессия» без сессии показывает «Проект», не затирая выбор | всегда «Проект»; область «Воркспейс» отдельно | сессия - то, что человек запускает и о чём спрашивает; «Везде» нужна, чтобы отделить общее от проектного | открыто |
| D-02 | Из каталогов `--add-dir` в область «Сессия» входят скиллы, команды, агенты и плагины (настройки `enabledPlugins`, `extraKnownMarketplaces`), серверы MCP и хуки - нет | показывать и MCP; не показывать доп. каталоги | документация Claude Code, раздел permissions («Additional directories grant file access, not configuration»); в запущенной сессии не проверялось | открыто: в живой сессии не проверено |
| D-03 | Список плагинов снимается `claude plugin list --json` один раз вне репозиториев и по разу в каждом репозитории проекта: команда отдаёт все установки машины, а `enabled` считает для каталога запуска (проверено); установки `project` и `local` чужих репозиториев отбрасываются по `projectPath` | один вызов в корне; чтение `installed_plugins.json` и настроек напрямую | формат файлов не обещан, у CLI есть `--json` | принято составителем: проверено живьём |
| D-04 | Серверы MCP читаются с диска (`~/.claude.json`, `.mcp.json`, плагины, `managed-mcp.json`), без `env`, `headers`, аргументов и пути адреса; `claude mcp list` вызывается только кнопкой «Проверить связь», потому что запускает программы серверов и печатает их аргументы | `claude mcp list` при открытии окна | проверено: команда запускает серверы и выводит аргументы запуска | открыто: одобрение серверов `.mcp.json` собрано из `~/.claude.json` и файлов настроек (состав источников в документации неполный); истину показывает проверка связи |
| D-05 | Меню «Расширения»: «Магазины…» с `CmdOrCtrl+Shift+X`, «Установленные плагины и скиллы…», «Серверы MCP…», «Хабы магазинов…»; доступны при выбранном проекте | пункты внутри «Воркспейс»; сочетание на каждый пункт | аналог расширений в редакторах; `Shift+X` свободно в приложении и в терминале Linux | открыто: на Linux живьём не проверено |
| D-06 | Плагины удалённых магазинов (`url`, `git-subdir`: 262 из 315 у официального) показываются по имени и описанию из `marketplace.json`, состав - «виден после установки»; клон ради списка скиллов не делается | скачивание плагинов для показа состава | сеть и место на диске ради просмотра; `plugin details` работает только для загруженных | открыто |
| D-07 | Хаб - понятие Cyborg: список магазинов, в котором ищут магазин и откуда подключают; хабы общие для всех воркспейсов (магазины Claude Code принадлежат пользователю), список своих хранится в `hubs.json`. Три вида: готовый список в приложении, поиск на GitHub и JSON-файл по https `{ name, marketplaces: [{ name, description, source: { source: github\|git\|url, … } }] }` для списков команды. Хаб только читается, магазин подключает человек | хаб как магазин Claude Code (у него нет понятия «магазин магазинов»); хранение хабов в файле воркспейса; локальные файлы как хабы | исследование 2026-10-30, D-13 | открыто |
| D-08 | Встроенные хабы (включены, отключаются, не удаляются): «Anthropic» - `claude-plugins-official`, `claude-community` (`anthropics/claude-plugins-community`), `anthropic-agent-skills` (`anthropics/skills`), `knowledge-work-plugins` (список с code.claude.com/docs/en/plugins/anthropic-marketplaces, репозитории проверены 2026-10-30; `anthropics/claude-code` объявлен устаревшим и не включён); «dex-it» - `dex-it/ai-kit`; «GitHub: claude-code-marketplace» - D-14. Читаются не больше 500 записей и 1 МиБ у файла хаба, 10 с, https без учётных данных, чужие типы источников отбрасываются со счётчиком | пустой встроенный хаб; список сторонних каталогов | исследование D-13 | открыто: состав встроенных списков |
| D-09 | Область установки и подключения по умолчанию: «Везде» в области «Везде», иначе «Локально» (личные настройки репозитория, репозиторий не меняется); «Проект» пишет в `.claude/settings.json` репозитория, и форма это говорит | «Везде» всегда; «Проект» по умолчанию | локальная область не создаёт изменений в коммите | открыто |
| D-10 | Установка идёт без `-y` и `--accept-command`: магазин, объявляющий команду установки, отказывает, и окно показывает отказ Claude Code; подтверждение остаётся за терминалом | передавать `-y` | чужая команда выполнялась бы без глаз человека | принято составителем |
| D-11 | Отключение магазина (`marketplace remove`) удаляет и все плагины из него (проверено); форма называет их | отключать магазин без предупреждения | деструктивное следствие, не очевидное из названия | принято составителем: проверено живьём |
| D-12 | Включение и выключение плагинов, правка серверов MCP и вставка вызова скилла в сессию в фичу не входят | включение плагина (`plugin enable|disable`); кнопка «вставить в промпт» | не просили; последнее - первая запись окна в терминал сессии | открыто |
| D-13 | Исследование хабов 2026-10-30. Каталоги магазинов есть, но не как данные для программы: claudemarketplaces.com (3126 магазинов, независимый, `/llms.txt` с топом, API нет, `/api/` закрыт для роботов) и claudemarket.ai (около 1000 магазинов, REST API с OpenAPI, но он отдаёт плагины, а не магазины: адрес репозитория виден только в карточке плагина). Документированный и стабильный источник списка магазинов - поиск GitHub по теме `claude-code-marketplace` (592 репозитория) и собственный список Anthropic. Они и стали хабами; веб-каталоги в хабы не входят | хаб из скрейпинга claudemarketplaces.com (HTML, `/api/` запрещён robots.txt, платная приоритетная проверка); хаб из claudemarket.ai (сборка магазинов из 3300 плагинов, по запросу на плагин) | проверка 2026-10-30 | открыто |
| D-14 | Хаб по теме GitHub: поиск `topic:claude-code-marketplace fork:false archived:false stars:>=20`, по убыванию звёзд, 30 репозиториев; каждый проверяется чтением `.claude-plugin/marketplace.json` (имя магазина и число плагинов оттуда), репозитории без каталога отбрасываются и считаются. Ответ держится в памяти 5 минут («Обновить» сбрасывает), запрос без токена (лимит поиска 10 в минуту), каталог до 4 МиБ. Тема - заявление автора: среди репозиториев с ней были заведомо не магазины и приманки («Desktop Client» для Windows и macOS), отсев по каталогу и звёздам их убирает; подпись хаба предупреждает, что Anthropic эти магазины не проверяет | без проверки каталога: в списке спам; вход через `gh` для большего лимита: хаб должен работать без входа; поиск по содержимому кода GitHub (`path:.claude-plugin/marketplace.json`): требует вход | проверка 2026-10-30: в первой тридцатке 26 настоящих магазинов, 4 отброшены | открыто: порог звёзд, размер выборки, включён по умолчанию |
