# ST-12007 Модель предлагает кнопки по ходу работы

Как разработчик, я хочу, чтобы Claude сам предлагал кнопки под ситуацию, чтобы не набирать очевидный следующий запрос руками и не писать для него заранее кнопку.

## Acceptance Criteria

- **AC-1.** Дано: новая сессия. Когда запускается `claude`. Тогда к системному промту добавлена инструкция предлагать кнопки комментарием `<!-- cyborg-buttons: [...] -->` в конце ответа и не писать его, когда шаги неочевидны. [FR-12007]
- **AC-2.** Дано: ответ модели оканчивается комментарием с 1-2 кнопками. Когда завершается ход (`Stop`). Тогда на полосе после заданных кнопок появляются кнопки модели. [FR-12007] [FR-12008]
- **AC-3.** Дано: в предложении есть `hotkey` и `disabled`. Когда ход завершается. Тогда сочетание и отключение не действуют. [FR-12007] [FR-12008]
- **AC-3a.** Дано: предложение с `"submit": true` и другое без `submit`. Когда я нажимаю первую, затем вторую. Тогда первая вставляет текст и нажимает Enter, вторая только вставляет текст. [FR-12007] [FR-12008]
- **AC-3b.** Дано: у предложенной кнопки `submit` не булево (`"true"`, `1`). Когда ход завершается. Тогда кнопка отброшена. [FR-12007]
- **AC-3c.** Дано: в предложении реплика начинается с «!» либо с «/». Когда ход завершается. Тогда реплика с «!» отброшена (Claude Code выполнил бы её командой оболочки), с «/» кнопка есть, но текст только вставляется, Enter не нажимается даже при `submit: true`. [FR-12007] [FR-12008]
- **AC-4.** Дано: комментарий не в конце ответа, не JSON, не массив либо записи негодны (пустая подпись, текст в две строки, длиннее пределов). Когда ход завершается. Тогда негодное отброшено, при отсутствии годных кнопок полоса не меняется. [FR-12007]
- **AC-5.** Дано: в предложении больше двух кнопок или повтор подписи. Когда ход завершается. Тогда показаны первые две без повторов. [FR-12007]
- **AC-6.** Дано: на полосе предложенные кнопки. Когда приходит новое предложение. Тогда прежние заменены. [FR-12008]
- **AC-7.** Дано: на полосе предложенные кнопки. Когда я отправляю следующий запрос (`UserPromptSubmit`). Тогда они исчезают. [FR-12008]
- **AC-8.** Дано: текст предложенной кнопки с `{branch}`. Когда я нажимаю её. Тогда подстановка раскрывается как у обычной кнопки; нет значения - текст не уходит, причина названа. [FR-12008] [FR-12003]
- **AC-9.** Дано: на полосе предложенные кнопки. Когда ход завершается без хвоста с кнопками. Тогда предложения остаются как были, пока я не задам следующий запрос. [FR-12008]
- **AC-10.** Дано: на полосе предложенная кнопка с `submit`. Когда модель снова работает без моего запроса (`PostToolUse`) либо стоит на запросе разрешения. Тогда предложение снято. [FR-12008]
