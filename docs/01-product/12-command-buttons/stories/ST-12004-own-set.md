# ST-12004 Свой набор кнопок в файле воркспейса

Как разработчик, я хочу держать свои кнопки в файле воркспейса, чтобы они жили вместе с проектом и переносились с ним.

## Acceptance Criteria

- **AC-1.** Дано: файл воркспейса без поля `commands`. Когда я открываю сессию. Тогда видны только встроенные кнопки. [FR-12005]
- **AC-2.** Дано: в `commands` кнопка `Приберись` (регистр не важен) с другим текстом. Когда набор строится. Тогда она заменяет встроенную на её месте, прочие кнопки воркспейса идут следом. [FR-12005]
- **AC-3.** Дано: кнопка без `submit`. Когда она нажимается. Тогда Enter не нажимается (по умолчанию `false`). [FR-12005] [FR-12002]
- **AC-4.** Дано: в файле, правленном вручную, кнопка без `text`, с `text` в две строки, с `label` длиннее 40 знаков, `submit: "да"` либо не объект. Когда набор загружается. Тогда негодная кнопка пропущена, остальные показаны, у полосы «Кнопки: замечаний N» с номером кнопки и причиной в подсказке. [FR-12005]
- **AC-5.** Дано: опечатка `submt: true`. Когда набор загружается. Тогда кнопка остаётся (без Enter), названо неизвестное поле. [FR-12005]
- **AC-6.** Дано: `commands` не массив либо кнопок больше 30. Когда набор загружается. Тогда набор встроенный либо лишние кнопки пропущены, замечание названо. [FR-12005]
- **AC-7.** Дано: я сохраняю проекты (создал проект, сменил последний выбранный). Когда файл записывается. Тогда поле `commands` и прочие поля файла остаются; запись кнопок, в свою очередь, не трогает проекты, а повреждённый файл не затирает. [FR-12005]
