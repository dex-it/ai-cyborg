# ST-12009 Промпты кнопок запуска сессий видны и правятся в окне «Кнопки»

Как разработчик, я хочу видеть и править промпты кнопок «Ревью», «Доработать», «CI», «Взять в работу» и сессии по задаче Jira, чтобы они работали по моим правилам.

## Acceptance Criteria

- **AC-1.** Дано: открыт воркспейс либо воркспейса нет. Когда я открываю «Воркспейс → Кнопки…» в слое «Все воркспейсы». Тогда в группах «Карточка MR», «Задача GitHub / GitLab», «Задача Jira» пять встроенных кнопок запуска с промптами и описаниями, их можно править. [FR-12010]
- **AC-2.** Дано: открыт слой «Этот воркспейс». Когда я выбираю кнопку запуска. Тогда она только для чтения с пометкой «правятся во всех воркспейсах»; выключить встроенную кнопку запуска нельзя ни в одном слое. [FR-12010]
- **AC-3.** Дано: в промпте неизвестная подстановка (`{jira_kye}`), чужая подстановка (`{task_url}` у «Ревью»), текст в две строки либо начинающийся с «-». Когда я сохраняю. Тогда окно остаётся открытым, отказ называет промпт и причину, файл не меняется. [FR-12010] [FR-12009]
- **AC-4.** Дано: корректная правка. Когда я сохраняю. Тогда окно закрывается, запись лежит в `prompts.json` в userData, файл воркспейса (проекты, кнопки полосы) не затронут. [FR-12010] [FR-12009]
- **AC-5.** Дано: промпт встроенной кнопки изменён. Когда я нажимаю «Вернуть встроенный промпт» и сохраняю. Тогда записи этого промпта в `prompts.json` нет, действует встроенный текст. [FR-12010] [FR-12009]
- **AC-6.** Дано: сохранены проекты (создал проект) либо кнопки полосы. Когда файл воркспейса записывается. Тогда `prompts.json` не меняется и промпты остаются. [FR-12009]
