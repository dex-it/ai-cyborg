# ST-12005 Правка набора в окне «Кнопки» без перезапуска

Как разработчик, я хочу править кнопки в одном окне формой и сразу видеть результат, не перезапуская Cyborg и не правя JSON.

## Acceptance Criteria

- **AC-1.** Дано: открыт воркспейс либо воркспейса нет. Когда я выбираю «Воркспейс → Кнопки…» либо нажимаю ⚙ в конце полосы. Тогда открыто окно «Кнопки» со списком кнопок по местам (полоса сессии, карточка MR, задача GitHub / GitLab, задача Jira), у каждой происхождение; без воркспейса слой «Этот воркспейс» недоступен, пунктов «Кнопки команд…» и «Промпты кнопок…» в меню нет. [FR-12006] [FR-12001]
- **AC-2.** Дано: в форме негодная правка (пустой текст, сочетание, уже заданное другой кнопке того же слоя). Когда я нажимаю «Сохранить». Тогда окно остаётся открытым, отказ виден у кнопки и поля, файл не меняется. [FR-12006] [FR-12005]
- **AC-3.** Дано: корректная правка. Когда я сохраняю. Тогда окно закрывается, новые кнопки видны на полосе без перезапуска, проекты в файле не затронуты. [FR-12006] [FR-12005]
- **AC-4.** Дано: в окне несохранённая правка. Когда я закрываю окно либо переключаю слой. Тогда Cyborg спрашивает подтверждение. [FR-12006]
- **AC-5.** Дано: файл воркспейса правят другим редактором. Когда окно Cyborg снова получает фокус. Тогда полоса показывает новый набор (если поле не менялось, она не перерисовывается); открытое окно «Кнопки» без несохранённой правки перечитано, с правкой - спрашивает «Перечитать их и потерять несохранённую правку?». [FR-12006]
- **AC-6.** Дано: сохранение сочетания, годного только на этой системе (`CmdOrCtrl+K` на macOS). Когда я сохраняю. Тогда отказ называет систему и причину: файл переносится между системами. [FR-12006] [FR-12004]
- **AC-7.** Дано: окно открыто, а файл слоя после этого записал инструмент сессии. Когда я сохраняю. Тогда отказ «Кнопки изменились на диске после открытия окна», запись инструмента не затёрта. [FR-12006]
- **AC-8.** Дано: в файле, правленном руками, запись без `text` с подписью, которой ниже нет. Когда я открываю окно. Тогда запись видна строкой «Запись негодна» с причиной; пока я её не поправлю или не удалю, сохранение слоя отказывает. [FR-12006] [FR-12005]
