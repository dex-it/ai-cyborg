# ST-12005 Правка набора в Monaco без перезапуска

Как разработчик, я хочу править кнопки из меню и сразу видеть результат, не перезапуская Cyborg.

## Acceptance Criteria

- **AC-1.** Дано: открыт воркспейс. Когда я выбираю «Воркспейс → Кнопки команд…». Тогда открыт диалог с Monaco, в котором действующий набор (встроенные кнопки и записи `commands`, ST-12006), подсказка по полям и подстановкам и замечания к текущему файлу; без воркспейса пункт недоступен. [FR-12006]
- **AC-2.** Дано: в редакторе негодный текст (не JSON, не массив, кнопка без `text`, повтор сочетания). Когда я нажимаю «Сохранить» или Cmd/Ctrl+S. Тогда диалог остаётся открытым, ошибка называет кнопку и поле, файл не меняется. [FR-12006]
- **AC-3.** Дано: корректный текст. Когда я сохраняю. Тогда диалог закрывается, новые кнопки видны на полосе без перезапуска, проекты в файле не затронуты. [FR-12006] [FR-12005]
- **AC-4.** Дано: в редакторе несохранённая правка. Когда я закрываю диалог кнопкой или Escape. Тогда Cyborg спрашивает подтверждение. [FR-12006]
- **AC-5.** Дано: файл воркспейса правят другим редактором. Когда окно Cyborg снова получает фокус. Тогда полоса показывает новый набор; если поле не менялось, она не перерисовывается. [FR-12006]
- **AC-6.** Дано: сохранение сочетания, годного только на этой системе (`CmdOrCtrl+K` на macOS). Когда я сохраняю. Тогда отказ называет систему и причину: файл переносится между системами. [FR-12006] [FR-12004]
