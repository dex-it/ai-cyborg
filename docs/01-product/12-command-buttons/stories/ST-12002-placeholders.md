# ST-12002 Команда с веткой, PR и задачей сессии

Как разработчик, я хочу, чтобы в тексте кнопки подставлялись ветка, PR и задача моей сессии, чтобы не дописывать их руками.

## Acceptance Criteria

- **AC-1.** Дано: кнопка с текстом `ветка {branch}`, сессия на ветке `feat/x-1`. Когда я нажимаю её. Тогда в сессию уходит `ветка feat/x-1` с веткой на момент нажатия (а не на момент старта сессии). [FR-12003]
- **AC-2.** Дано: сессия начата из PR/MR («Ревью», «Доработать»). Когда я нажимаю кнопку с `{pr}`. Тогда подставляется ссылка этого PR/MR без запроса к трекеру. [FR-12003]
- **AC-3.** Дано: у ветки сессии один открытый PR/MR в репозиториях проекта. Когда я нажимаю кнопку с `{pr}`. Тогда подставляется его ссылка; свой PR приоритетнее чужого, чужой берётся, если своего нет. [FR-12003]
- **AC-4.** Дано: у ветки нет открытого PR/MR, либо их несколько, либо в проекте не включены GitHub и GitLab, либо список не получен. Когда я нажимаю кнопку с `{pr}`. Тогда ничего не уходит в сессию, у полосы на несколько секунд названа подстановка и причина. [FR-12003]
- **AC-5.** Дано: сессия начата из задачи Jira `DEX-12` либо из задачи трекера. Когда я нажимаю кнопку с `{task}`. Тогда подставляется ключ `DEX-12` либо ссылка задачи; у сессии не из задачи текст не уходит с причиной. [FR-12003]
- **AC-6.** Дано: имя ветки содержит пробел, `;`, обратную кавычку или `$(`. Когда я нажимаю кнопку с `{branch}`. Тогда текст не уходит, названо, что значение содержит недопустимые знаки. [FR-12003]
- **AC-7.** Дано: текст `git log {1..3} {foo}`. Когда я нажимаю кнопку. Тогда чужие фигурные скобки остаются как есть, значения не ищутся. [FR-12003]
