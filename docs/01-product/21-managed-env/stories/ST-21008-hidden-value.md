# ST-21008 Секрет не виден без «Показать значение»

Как разработчик, я хочу, чтобы ключ не был виден на экране, пока я сам его не раскрою.

## Acceptance Criteria

- **AC-1.** Дано: выбрано выражение, значение вычислено. Тогда окно, индикатор и логи значения не показывают. Когда я нажимаю «Показать значение». Тогда окно показывает значение, которое получают процессы, команда при этом не исполняется. [FR-21015] [NFR-21002]
- **AC-2.** Дано: значение раскрыто. Когда я закрываю окно, меняю состояние переменной или правлю текст выбранного кандидата. Тогда значение снова скрыто. [FR-21015]
- **AC-3.** Дано: переменная выбрана, но значения нет. Тогда кнопки «Показать значение» у неё нет. [FR-21015]
