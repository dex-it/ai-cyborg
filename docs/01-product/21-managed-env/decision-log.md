# decision-log фичи 21 - управляемое окружение

Решения по цели `cyborg-env` (2026-11-21). D-01..D-11 - ответы оператора в разговоре 2026-11-21, «Основание» - цитата ответа, исход «принято владельцем». D-12 - решение главного потока по поручению оператора «бери в работу автономно», исход «принято по поручению владельца». D-13..D-21 - допущения постановки цели, исход «открыто»: подтверждает или меняет владелец продукта. D-22..D-37 - решения прогона разработки с отвергнутыми альтернативами, исход «решение прогона». D-38..D-42 - неверное во входе: пункт цели расходится с устройством среды или корпуса, решение следует коду и корпусу. D-43..D-45 - открытые пункты.

| D-01 | Переменная - имя и список кандидатов; кандидат - литерал либо выражение | одно значение на переменную | оператор: «значение может быть либо литералом, либо вычисляемым выражением» | принято владельцем |

| D-03 | Выбор и снятие переживают перезапуск Cyborg; при старте выражения выбранных вычисляются заново | хранить вычисленное значение; забывать выбор при выходе | оператор: «Помнить выбор, вычислять при старте» | принято владельцем |

| D-07 | Вычисленное значение не показывается; по кнопке его можно посмотреть | показ значения в списке | оператор: «вычисленное значение не показываю… по кнопочке посмотреть иногда нужно» | принято владельцем |
| D-08 | Переменную можно снять: у процессов её нет, даже если Cyborg унаследовал её при запуске | только выбор значения | оператор: «включить переменную… мне нужно её снять»; «фиксируй требование» на предложение снимать и унаследованную | принято владельцем |
| D-09 | Идущее вычисление отменяется кнопкой, процессы выражения снимаются | ждать конца вычисления | оператор: «Видимо, да» | принято владельцем |
| D-10 | Выражение выполняется `/bin/sh -c` с PATH логин-оболочки пользователя | логин-оболочка пользователя целиком | оператор: «фиксируй требование» на предложение в разговоре | принято владельцем |
| D-11 | Выбор получают все дочерние процессы, которые запускает главный процесс Cyborg, через одну сборку окружения | только сессии Claude | оператор: «все дочерние процессы её получают» | принято владельцем |
| D-12 | Собственные значения Cyborg для вызова (служебные переменные сессии, `GH_PROMPT_DISABLED`, `NO_COLOR`, снятие токенов при сборе доступов, `SSH_ASKPASS_REQUIRE`, доступы хостинга на хосте) берут верх над управляемыми, ADR-0020 п.14 не меняется; исключение - `CLAUDE_CODE_OAUTH_TOKEN` на хостах: выбранная заменяет токен «Вход Claude на хостах…», снятая убирает его; имя, которое Cyborg перебивает лишь в части вызовов, принимается с пометкой в окне | управляемое сильнее собственного; запрет таких имён | расхождение цели с ADR-0020 п.14 снято в пользу ADR-0020 п.14 решением главного потока, 2026-11-21 | принято по поручению владельца |
| D-13 | Вид кандидата задан явно; литерал, похожий на команду, не исполняется | распознавать команду по тексту | допущение постановки: иначе литерал-секрет исполнится как команда | открыто |
| D-14 | Три состояния - не тронута, выбрана, снята; снятие сохраняет кандидатов и годится для имени без кандидатов | снятие как удаление переменной | допущение постановки | открыто |
| D-15 | Запуски процессов ждут конца стартового вычисления выражений | запуск без ожидания | допущение постановки: иначе первые процессы пойдут без ключа | открыто |
| D-16 | Выражение: stdin - /dev/null, cwd - домашний каталог, значение - stdout без одного завершающего \n или \r\n, stdout с NUL отклоняется, stdout до 64 КиБ, срок 60 с | - | допущение постановки | открыто |
| D-17 | Отмена и таймаут снимают всю группу процессов выражения | снять только `/bin/sh` | допущение постановки | открыто |
| D-18 | Новый выбор, снятие, «Не трогать» и удаление той же переменной отменяют её идущее вычисление: побеждает последнее действие | дождаться результата | допущение постановки: иначе устаревший результат перезапишет поздний выбор | открыто |
| D-19 | «Показать» раскрывает значение, которое получают процессы, из памяти, без нового вычисления, до закрытия окна | вычислить заново при показе | допущение постановки | открыто |
| D-20 | Сессия, запущенная до изменения, помечается, если изменение задело её окружение; перезапуск - по действию человека, `claude --resume` того же разговора с тем же cwd, каталогами и открывшей; сессия в ходе просит подтверждения; без разговора перезапуска нет | менять окружение живого процесса; перезапуск без человека | допущение постановки: окружение живого процесса не меняется | открыто |
| D-21 | Граница: собственные сетевые запросы главного процесса окружения не получают; импорта из cc-sw и пресетов нет; перебивание профилем логин-оболочки не исправляется; «Вход Claude на хостах…» остаётся | - | допущения постановки: оператор говорил о дочерних процессах и этого не просил | открыто |
| D-22 | Окружение главного процесса Cyborg (`process.env`) не меняется; управляемое накладывается при сборке окружения каждого запуска | менять `process.env`, чтобы внутренние запуски Electron унаследовали выбор | это задело бы сам Cyborg (`HOME`, `TMPDIR`, `TZ`, `CLAUDE_CONFIG_DIR`, `GIT_CONFIG_COUNT`, процессы Chromium) и сделало бы порядок слоёв неявным | решение прогона |
| D-23 | Ожидание готовности окружения - у вызывающих (обработчики IPC, подключение к хосту), в месте запуска сборка синхронная | асинхронная сборка в каждом синхронном месте запуска | иначе создание сессии и открытие ssh сменили бы контракт для всех потребителей и тестов | решение прогона |
| D-24 | Терминал «Запустить» получает управляемое окружение файлом 0600 в каталоге 0700, который скрипт запуска подключает и удаляет; в аргументах - только путь | окружение эмулятора; значения в аргументах; значения через stdin | окружение сервера эмулятора не наше, аргументы видны всем пользователям машины, stdin эмулятора не наш | решение прогона |
| D-25 | Номер протокола демона не поднимается: поле `vars` необязательное, `hello` несёт перечень возможностей (`vars`, `sleep`); без `vars` вкладка получает заметку, без `sleep` удалённый перезапуск отказывает с причиной | поднять `PROTO` | демон с бодрствующими сессиями и другой `PROTO` отказывает в подключении (ADR-0020 п.3): удалённая работа остановилась бы до конца всех сессий хоста | решение прогона |
| D-26 | Стартовые выражения вычисляются по одному, в порядке списка | параллельно | `pass` через один `gpg-agent` поднял бы несколько `pinentry` сразу, а окружение выражения зависело бы от гонки | решение прогона |
| D-27 | Открытие адреса и файла: на Linux - `xdg-open` с управляемым окружением, на macOS - `open`; нет программы - средствами Electron | заменить открытие своим `open --env` на macOS | LaunchServices запускает приложение не потомком вызывающего, а `open --env` положил бы значения в аргументы | решение прогона |
| D-28 | Пустой вывод выражения после снятия завершающего перевода строки - неудача | пустое значение | пустой вывод `pass` - признак сбоя; для пустого значения есть литерал | решение прогона |
| D-29 | Неудачное стартовое вычисление оставляет переменную выбранной, но не поставленной: процессы получают унаследованное значение, следующий старт пробует снова | считать снятой | снятие молча стёрло бы унаследованное значение, а цель говорит «не ставится» | решение прогона |
| D-30 | Правка текста выбранного литерала действует сразу; правка текста выбранного выражения и удаление выбранного кандидата возвращают переменную в «не тронута» | вычислять правленое выражение заново; оставлять прежнее значение | значение прежней команды не подмешивается молча | решение прогона |
| D-31 | Пределы: имя до 128 знаков, до 128 переменных, до 32 кандидатов, текст кандидата и вывод выражения до 64 КиБ, файл выбора до 8 МиБ; хвост stderr - 4 КиБ | без пределов | правило имени демона, предел вывода из D-16, запас к `ARG_MAX`, чтобы запуск не упал с `E2BIG` | решение прогона |
| D-32 | Оболочку `-lc` для сессий и проверок выбирает унаследованная `SHELL`; управляемая `SHELL` уходит только в окружение процесса | брать оболочку из собранного окружения | выбор оболочки - решение Cyborg, выбранная переменная не подменяет оболочку запуска | решение прогона |
| D-33 | Процессы демона на хосте со своими доступами (`git clone`, `ls-remote`, установка плагинов) переменных не получают | отдавать `vars` и им | цель говорит о сессиях | решение прогона |
| D-34 | Порядок слоёв: унаследованное, затем снятые и выбранные управляемые, затем собственные снятия и значения Cyborg; одно имя в собственных снятиях и значениях - побеждает значение | - | сохраняет прежнюю семантику окружения сессии | решение прогона |
| D-35 | Отметка устаревания сессии - свёртки sha256 действующих значений управляемых имён без собственных имён Cyborg, отдельно для локальных и удалённых; значения не хранятся | хранить значения на момент запуска | значения в памяти отметки были бы второй копией секрета | решение прогона |
| D-36 | Во время вычисления список кандидатов и кнопка окна доступны; список стоит на вычисляемом кандидате, кнопка вычисляет его заново; вычисляемого кандидата называет главный процесс в статусе | блокировать список на время вычисления; менять только подпись кнопки | блокировка не даёт выбрать другого (D-18), а список на прежнем выборе расходится с действием кнопки; память окна теряется при повторном открытии | решение прогона |
| D-37 | Собственные чтения Cyborg каталога настроек Claude (окно «Расширения», зеркало настройки и память для хостов, редактор глобального `CLAUDE.md`) берут `CLAUDE_CONFIG_DIR` из унаследованного окружения; окно называет это пометкой | читать управляемое значение | собственные чтения главного процесса - не дочерние процессы (D-22) | решение прогона |
| D-38 | Неверное во входе: «снимается вся группа процессов выражения, включая pinentry». `pinentry` запускает `gpg-agent` в своей сессии вне группы выражения; снятие группы убирает `sh`, `pass` и `gpg`, `gpg-agent` Cyborg не трогает | `gpgconf --kill` | сброс кэша паролей всех программ пользователя | решение прогона |
| D-39 | Неверное во входе: `GIT_TERMINAL_PROMPT` и `GIT_SSH_COMMAND` в окружении сессии на хосте - нижний слой умолчаний, а не собственные значения поверх управляемых; собственными они являются только для процессов демона (D-33). В сессии действует выбранное значение | поднять их над управляемыми | слой сохранён как в коде демона (ADR-0020) | решение прогона |
| D-40 | Неверное во входе: цель ссылается на ADR-0004 п.2, а ADR-0004 отменён; атомарная запись следует ADR-0014 п.2 | ADR-0004 п.2 | ADR-0004 - `superseded` | решение прогона |
| D-41 | Неверное во входе: «открытие через shell» не передаёт окружение уже запущенному обработчику (браузер, открытый редактор), а на macOS приложение запускает LaunchServices; окружение получает процесс `xdg-open` на Linux и то, что он запускает заново | - | у открытия средствами Electron нет параметра окружения | решение прогона |
| D-42 | Неверное во входе: «с тем же родителем» для удалённой сессии `spawn_agent` недостижимо: пробуждение делает её ведомой человеком и снимает таймеры (FR-17014), а выход `claude` на хосте равен закрытию с уборкой (ADR-0020 п.9). Перезапуск удалённой - только для вкладки, открытой человеком; вкладка `spawn_agent` помечается без кнопки | перезапуск `spawn_agent` через сон и пробуждение | потеря связи с вызвавшей и уборка клонов | решение прогона |
| D-43 | Открыто: перезапуск дочерней вкладки, у которой продолжение отказало после завершения процесса (журнал не найден, некорректное продолжение), оставляет открывшую без сообщения о выходе дочерней | - | находка ревью F15; оператор вынес исправление в отдельную цель | открыто |
| D-44 | Открыто: суммарного предела объёма выбранных значений нет; решение прогона о 256 КиБ в код не вошло, требование его не несёт | - | сверка кода на HEAD фиксации | открыто |

| D-46 | Быстрый вход - значок `{x}` со счётчиками в полосе сессий рядом с кнопками «Задачи» и «MR/PR»; отдельной нижней строки окна нет. Уточняет место индикатора из D-05 | текстовый индикатор в отдельной нижней строке окна | оператор: «целая панель ради кнопки окружение - не думаю что это хорошо; предлагаю общепринятую иконку и на уровне с кнопками» | принято владельцем |
| D-47 | Поле нового имени в окне «Окружение» подсказывает по мере ввода имена унаследованного окружения Cyborg (то, что получают сессии); значения в окно не передаются, служебные и уже заведённые имена не предлагаются | ввод имени без подсказки | оператор: «когда пользователь набирает в строке поиска в имени переменную, он подсказывает имена из тех, что есть в сессии» | принято владельцем |
