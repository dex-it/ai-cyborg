# decision-log фичи 09 - изоляция сессий

Решения и допущения прогона по Issue #10 (2026-10-26). Исход «открыто» - допущение, принятое за постановщика без владельца
(рекомендации Issue #10, владелец поручил решать по качеству); подтверждает либо меняет владелец продукта.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Изоляция - принятая возможность продукта: BRD раздел 11 («только хуки и начальный промпт») и ADR-0003, п.9 расширены инструкцией изоляции и `--resume` (ADR-0012); требования - в отдельной фиче 09 | убрать инструкцию из кода; описать её внутри фичи 01 | Issue #10, вопросы 1 и 4; прогон на настоящем Claude Code 26.10.2026 | открыто |
| D-02 | Системный промпт сессии отличается от терминального запуска (добавка `--append-system-prompt`): отступление от драйвера нативности ADR-0003 принято ради изоляции; решение владельца нужно | убрать инструкцию: параллельные сессии конфликтуют; заменить созданием worktree самим Cyborg: меняет репозиторий без запроса (FR-1016) | ADR-0012, п.1; прогон: две сессии ушли в worktree | открыто |
| D-03 | Инструкция добавляется каждой сессии, включая продолженную и начатую из задачи либо MR; текст фиксирован в коде и в корпус не копируется целиком, кроме ADR-0012 | инструкция только новой сессии: продолженная работала бы без изоляции | код `claudeArgs`, тесты | открыто |
| D-04 | `EnterWorktree`, а не `git worktree add`: инструмент меняет cwd сессии, и дерево Cyborg переходит в worktree по событию хука | `git worktree add` из шелла сессии: cwd остаётся прежним, дерево не следует | комментарий в `claude-args.ts`; прогон 26.10.2026 | открыто |
| D-05 | Версия `claude` без `EnterWorktree` либо модель, не последовавшая инструкции: сессия работает без изоляции, Cyborg ничего не блокирует и не сообщает; случай не проверялся | блокировать сессию без worktree: Cyborg не может проверить намерение модели | границы FR-9003 | открыто |
