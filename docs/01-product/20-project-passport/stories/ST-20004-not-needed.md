# ST-20004 Способность не нужна проекту

Как разработчик, я хочу снять с паспорта способность, которая моему проекту не нужна, чтобы она не маячила пробелом.

## Acceptance Criteria

- **AC-1.** Дано: у способности пробел. Когда я нажимаю «Не нужно». Тогда способность серая с пометкой «не нужно», число в точке меньше на единицу сразу, без новой проверки, пробой она не проверяется, файлы способностей без изменений, git status показывает только запись отказа в `.cyborg/passport/`. [FR-20008]
- **AC-2.** Дано: способность снята. Когда я нажимаю «Нужно». Тогда она снова считается по последним результатам проверки файлов и пробы. [FR-20008]
- **AC-3.** Дано: я снял все двенадцать способностей. Когда я смотрю точку. Тогда у проекта из одного репозитория «✓», а у проекта из нескольких остаются только пробелы указателя неглавных репозиториев, если они есть. [FR-20008] [FR-20004] [FR-20009]
- **AC-4.** Дано: я снял способность и перезапустил Cyborg. Когда я открываю окно. Тогда отказ на месте; у проекта из нескольких репозиториев он действует на техническую способность во всех репозиториях. [FR-20008]
- **AC-5.** Дано: я снял способность верхней группы, а у способности нижней группы есть пробел. Когда я смотрю точку и окно. Тогда способность нижней группы по-прежнему пробел и входит в число, её кнопки доступны. [FR-20008]
