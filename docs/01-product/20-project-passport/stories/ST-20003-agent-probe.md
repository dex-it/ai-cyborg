# ST-20003 Проба агента показывает, что он находит, а что выдумывает

Как разработчик, я хочу по кнопке узнать, находит ли агент ответ с источником по каждой способности, чтобы знать, где он выдумывает, даже если все файлы на месте.

## Acceptance Criteria

- **AC-1.** Дано: у проекта есть `claude`. Когда я нажимаю «Проверить агентом». Тогда у каждой способности, не снятой «Не нужно», один из трёх исходов: «нашёл с источником», «выдумывает», «не знает»; рабочая копия проекта после пробы без изменений. [FR-20006]
- **AC-2.** Дано: идёт проба проекта, общая либо повторная по одной способности. Когда я пытаюсь нажать «Проверить агентом» либо «Повторить пробу» у любой способности этого проекта ещё раз. Тогда кнопки отключены, подпись «Проба идёт…», вторая проба не стартует. Когда в это время идёт проба другого проекта. Тогда они не мешают друг другу. [FR-20006]
- **AC-3.** Дано: проба прервана либо упала. Когда я смотрю окно. Тогда прежние исходы на месте, причина названа. Когда я закрыл окно либо сменил проект до конца пробы. Тогда исход записан к проекту, для которого проба запущена. [FR-20006]
- **AC-4.** Дано: агент сослался на несуществующий файл, на строку за концом файла, на каталог либо на путь вне рабочей копии проекта. Когда проба завершилась. Тогда во всех четырёх случаях исход «выдумывает». [FR-20007]
- **AC-5.** Дано: смысловая способность (например, «Зачем и для кого») найдена с источником, ссылка разрешилась. Когда я смотрю окно и точку. Тогда у способности «ждёт подтверждения», она считается пробелом; ответ агента и источник видны текстом. Когда я нажимаю «Подтвердить». Тогда пробела нет. Когда я нажимаю «Не то». Тогда исход «выдумывает», пробел остаётся. [FR-20007]
- **AC-6.** Дано: несмысловая способность (например, «Архитектура») найдена с разрешившимся источником. Когда я смотрю окно. Тогда способность пробелом не считается, подтверждать её не требуется. [FR-20007]
- **AC-7.** Дано: на машине нет `claude`. Когда я открываю окно. Тогда «Проверить агентом», «Исправить» и «Повторить пробу» отключены, названа причина «Нет CLI claude: проба и исправление недоступны»; точка показывает число по проверке файлов, «Не нужно» и подтверждения работают. [FR-20013] [FR-20003]
- **AC-8.** Дано: `claude` поставили при открытом окне. Когда я открою окно заново либо выберу проект. Тогда кнопки доступны. [FR-20013]
- **AC-9.** Дано: смысловая способность подтверждена кнопкой «Подтвердить». Когда я запускаю новую пробу, и она снова находит ответ с источником. Тогда подтверждение снято, у способности снова «ждёт подтверждения», она считается пробелом. [FR-20007]
- **AC-10.** Дано: файла способности нет, а агент нашёл ответ в коде с источником. Когда проба завершилась. Тогда исход «нашёл с источником», но пробел по файлу остался и в точке сосчитан. [FR-20006] [FR-20002]
- **AC-11.** Дано: у способности нет файла и проба дала «не знает». Когда я смотрю точку. Тогда способность сосчитана один раз, а не дважды. [FR-20004]
