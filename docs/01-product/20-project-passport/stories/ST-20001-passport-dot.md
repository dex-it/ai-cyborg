# ST-20001 Готовность проекта видна точкой в строке проекта

Как разработчик, у которого несколько проектов, я хочу видеть по точке в строке проекта, сколько пробелов у его паспорта, чтобы не открывать окно и не нажимать проверку.

## Acceptance Criteria

- **AC-1.** Дано: проект без каталога паспорта. Когда я выбираю проект. Тогда без нажатий точка в его строке показывает число пробелов по проверке файлов (все двенадцать способностей). [FR-20003] [FR-20004]
- **AC-2.** Дано: я поправил файл паспорта на диске и проект не выбирал. Когда проходит время. Тогда точка не изменилась. Когда я выбираю проект заново либо открываю окно «Паспорт проекта». Тогда точка показывает новое число; таймера и наблюдения за файлами нет. [FR-20003]
- **AC-3.** Дано: все файлы паспорта на месте, без пробелов, пробу не запускали. Когда я смотрю на точку. Тогда вместо числа «✓»; клик по точке открывает окно, пробу из него запустить можно. Дано: затем проба нашла ответы с источником у всех способностей. Когда я смотрю на точку. Тогда в ней 6 - шесть смысловых способностей ждут подтверждения; после «Подтвердить» у всех шести - «✓». [FR-20004] [FR-20007]
- **AC-4.** Дано: у проекта 99 пробелов, затем 100 и больше. Когда я смотрю на точку. Тогда у 99 в точке «99», от 100 - «99+»; у проекта с нулём пробелов - «✓». [FR-20004]
- **AC-5.** Дано: проект ни разу не проверяли. Когда я смотрю на точку. Тогда в ней «–» на сером, подсказка «Паспорт не проверен». Когда идёт проверка файлов. Тогда в ней «…» на синем, подсказка «Проверка паспорта…». [FR-20004]
- **AC-6.** Дано: проект не выбран в списке, Cyborg перезапущен. Когда я смотрю на точку проекта. Тогда она показывает последний сохранённый результат, а не «–». [FR-20003] [FR-20004]
- **AC-7.** Дано: PR с исправлением паспорта слит, проект я не выбирал. Когда я смотрю на точку. Тогда число прежнее. Когда я выбираю проект. Тогда число уменьшилось. [FR-20003] [FR-20004]
- **AC-8.** Дано: фокус на точке (Tab). Когда я нажимаю Enter либо пробел. Тогда открывается окно «Паспорт проекта»; другого входа в окно нет (ни пункта меню, ни кнопки на полосе сессий). [FR-20004]
- **AC-9.** Дано: идёт проверка файлов проекта с большими файлами паспорта. Когда я печатаю в терминале сессии, переключаю проекты и нажимаю кнопки. Тогда интерфейс отвечает без заметной задержки, а в точке «…». [NFR-20001]
