# ST-20007 Скиллы усиливают исправление, но не обязательны

Как разработчик, я хочу, чтобы сессия исправления использовала подходящие скиллы, но ничего не ставила без моего слова, чтобы результат был полнее и решение оставалось за мной.

## Acceptance Criteria

- **AC-1.** Дано: у проекта включены плагины и подключён магазин. Когда я нажимаю «Исправить». Тогда кандидаты в скиллы идут сессии в начальном промпте, а сессия выбирает скиллы и объясняет выбор в плане. [FR-20012]
- **AC-2.** Дано: сессии нужен скилл, которого нет. Когда сессия просит его. Тогда установку решаю я - в окне «Расширения» либо в штатном запросе разрешения Claude Code. Когда я отказываю. Тогда сессия работает со встроенным поручением без скилла. [FR-20012]
- **AC-3.** Дано: кандидатов нет либо магазин недоступен. Когда я нажимаю «Исправить». Тогда сессия стартует, план без скиллов. [FR-20012]
- **AC-4.** Дано: сессия идёт в режиме без запроса разрешений. Когда ей нужен неустановленный скилл. Тогда решает моя настройка; Cyborg режим не меняет, разрешений не выдаёт и файлы настроек Claude Code не пишет. [FR-20012]
