# ST-20005 Проект из нескольких репозиториев и главный репозиторий

Как разработчик проекта из нескольких репозиториев, я хочу один раз отметить главный репозиторий, чтобы проектная часть паспорта проверялась там, а техническая - в каждом.

## Acceptance Criteria

- **AC-1.** Дано: проект из двух репозиториев, главный не отмечен. Когда я открываю окно. Тогда оно просит «Отметьте главный репозиторий» со списком репозиториев, проектные способности не проверены и пробой не проверяются; точка показывает только технические пробелы, а при нуле - «–», не «✓». [FR-20009]
- **AC-2.** Дано: я отметил главный репозиторий. Когда проверка идёт. Тогда проектные способности проверены в главном, технические - в каждом, у технической способности строка по каждому репозиторию; число - сумма по репозиториям. [FR-20009]
- **AC-3.** Дано: главный репозиторий `backend` отмечен, в `index.md` неглавного репозитория есть ссылка `[Паспорт проекта](../../../backend/.cyborg/passport/index.md)`. Когда я смотрю число. Тогда пробела по указателю нет. Дано: в `index.md` неглавного нет ссылки (только текст «см. backend»), либо ссылка ведёт в несуществующий путь (`../../../old-backend/.cyborg/passport/index.md`), либо в другой файл (`../../../backend/README.md`), либо в репозиторий, не отмеченный главным. Когда я смотрю число. Тогда это один пробел этого репозитория. [FR-20009]
- **AC-4.** Дано: я сменил главный репозиторий. Когда проверка идёт заново. Тогда проектные пробелы считаются по новому главному. Когда я удалил главный из проекта. Тогда отметка снята и окно снова просит отметить. [FR-20009]
- **AC-5.** Дано: проект из одного репозитория. Когда я открываю окно. Тогда отмечать главный не нужно, указатель не нужен. [FR-20009]
- **AC-6.** Дано: главный не отмечен, а в `index.md` неглавного репозитория нет указателя. Когда я смотрю число. Тогда пробела по указателю нет; после того как я отметил главный, он появился. [FR-20009]
