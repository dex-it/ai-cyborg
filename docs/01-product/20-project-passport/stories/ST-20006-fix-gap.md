# ST-20006 Пробел закрывает сессия по слову разработчика

Как разработчик, я хочу по нажатию запустить сессию, которая исправит пробел паспорта по плану, и проверить результат повторной пробой, чтобы закрыть пробел, не составляя тексты руками.

## Acceptance Criteria

- **AC-1.** Дано: у способности пробел и есть `claude`. Когда я нажимаю «Исправить». Тогда открывается сессия проекта с поручением на всю настройку паспорта, начинающимся с этого пункта; по пункту она начинается с плана (что выяснить, какие файлы править, какие скиллы и почему), и до моего подтверждения в сессии файлы не правятся. [FR-20010] [FR-20011]
- **AC-2.** Дано: поручение одно для любого пункта. Когда я нажимаю «Исправить» у любой способности. Тогда первое сообщение сессии - встроенное поручение на всю сессию, начинающееся с этой способности, с названием инструментов списка и закрытия пунктов; у проекта без скиллов оно то же, без перечня кандидатов; у проекта из нескольких репозиториев оно называет репозиторий файла. [FR-20011]
- **AC-3.** Дано: сессия ушла в worktree. Когда я после правок нажимаю «Повторить пробу». Тогда проба идёт по worktree сессии и показывает исход у способности отдельной строкой «по дереву исправления»; исходы пробы проекта и рабочая копия проекта не затронуты. [FR-20010]
- **AC-4.** Дано: я вёл сессию в текущей ветке. Когда я нажимаю «Повторить пробу». Тогда проба идёт по рабочей копии, Cyborg запись не навязывает; пробел по файлам исчезает из точки при следующем выборе проекта либо открытии окна, без слияния, а пробел по пробе - только при новой пробе проекта; исход повторной пробы виден у способности строкой «по дереву исправления». [FR-20010] [FR-20004]
- **AC-5.** Дано: повторная проба дала «не знает» либо «выдумывает». Когда я смотрю окно. Тогда пробел остаётся, «Повторить пробу» можно нажать снова. [FR-20010]
- **AC-6.** Дано: исправление готово. Когда я смотрю историю git ветки сессии. Тогда в ней только коммиты сессии либо мои, Cyborg не коммитит и не сливает; PR я сливаю как обычно. [FR-20010]
- **AC-7.** Дано: нет `claude`. Когда я смотрю «Исправить» и «Повторить пробу». Тогда они отключены с названной причиной. [FR-20010] [FR-20013]
- **AC-8.** Дано: у способности «Архитектура» файлы на месте, а проба проекта дала «выдумывает»; сессия исправила её в worktree, повторная проба по worktree дала «нашёл с источником», PR не слит. Когда я смотрю точку. Тогда число прежнее, а у способности виден исход «нашёл с источником» по дереву исправления. Когда worktree убрали без слияния. Тогда число по-прежнему прежнее. Когда PR слит и я нажимаю «Проверить агентом». Тогда проба проекта дала «нашёл с источником», пробел закрыт, число уменьшилось. [FR-20010] [FR-20004] [FR-20006]
- **AC-9.** Дано: у смысловой способности повторная проба по worktree дала «нашёл с источником». Когда я смотрю окно. Тогда подтверждения эта строка не требует и не заменяет; «ждёт подтверждения» появится после пробы проекта (FR-20007). [FR-20010] [FR-20007]
- **AC-10.** Дано: сессию настройки закрыли и Cyborg перезапустили, worktree на месте. Когда я открываю окно. Тогда «Повторить пробу» доступна и идёт по тому же worktree. Дано: worktree убран. Тогда «Повторить пробу» отключена с причиной «Дерево исправления убрано». Дано: «Исправить» у способности не нажимали. Тогда отключена с причиной «Исправление не запускали». Дано: идёт проба проекта, общая либо повторная по любой способности. Тогда отключена с причиной «Идёт проба». [FR-20010]
- **AC-11.** Дано: сессия настройки паспорта проекта жива. Когда я нажимаю «Исправить» у любого пункта проекта, у того же или у другого. Тогда вторая сессия не открывается, окно переходит к вкладке первой. Когда я закрыл первую сессию и снова нажал «Исправить». Тогда открывается новая сессия, и повторная проба идёт по её дереву. [FR-20010]
- **AC-12.** Дано: идёт повторная проба способности «Архитектура». Когда я пытаюсь нажать «Повторить пробу» у «Архитектуры», у другой способности либо «Проверить агентом». Тогда все три отключены, у «Повторить пробу» причина «Идёт проба», вторая проба не стартует; число в точке не меняется. Когда повторная проба завершилась. Тогда кнопки снова доступны, а исход виден у «Архитектуры» отдельной строкой «по дереву исправления». Когда проба оборвана либо упала. Тогда прежняя строка «по дереву исправления» на месте, причина названа. [FR-20010] [FR-20006] [FR-20004]
- **AC-13.** Дано: сессия настройки жива и я веду её по пунктам. Когда сессия просит список. Тогда она получает открытые пункты проекта так, как их считает точка (способности с пробелом без «Не нужно», пробелы указателя неглавных репозиториев, заметки человеку); когда пунктов нет - «Открытых пунктов нет.». Вкладка, не являющаяся сессией настройки, этих инструментов не получает. [FR-20010]
- **AC-14.** Дано: я согласился словами с итогом по пункту, и информации в документах достаточно. Когда сессия закрывает пункт. Тогда Cyborg после механических проверок пишет закрытие с хешем файла способности из дерева сессии в состояние рабочей копии, а сессия сама предлагает следующий открытый пункт. Когда сессия ведётся в текущей ветке. Тогда точка уменьшается и строка пункта в окне показывает «закрыт в сессии» сразу. Когда сессия ушла в worktree. Тогда точка и строка меняются после слияния (D-59, FR-20004), а список пунктов самой сессии пункт уже не содержит. Когда проверки не прошли. Тогда закрытие отклонено с названной причиной и ничего не записано. Когда файл способности изменили. Тогда закрытие снято и пункт снова открыт. Когда запущена новая проба проекта. Тогда закрытия снятых ею способностей сняты. [FR-20010] [FR-20004]
- **AC-15.** Дано: я отказался от пункта в сессии либо сказал «стоп». Когда сессия продолжает. Тогда отказанный пункт до конца сессии не предлагается, закрытие по нему не вызывается и «Не нужно» не ставится; «стоп» заканчивает обход кратким итогом. [FR-20011]
