# BRD фичи 13 - окно поиска по файлам, содержимому и изменениям

Источник: Issue #55 (2026-10-29): «поиск по содержимому диффа, чтобы поиск не показывался сразу, а вызывался стандартным хоткеем или из меню, как по имени, так и по содержимому, отдельными выборами, как в продуктах JetBrains»; дополнение владельца: поиск регулярным выражением. Ответы владельца на вопросы Issue (2026-10-29) - `decision-log.md`, D-01..D-03, D-05. Фича заменяет постоянное поле «Найти файл» над деревом (PR #54).

## 1. BRS overview

Найти нужный файл в большом репозитории раскрытием каталогов долго, а поля поиска по содержимому нет совсем. Фича даёт окно поиска, которое не занимает места на экране и вызывается меню «Поиск» и сочетанием клавиш; режимы выбираются отдельно: по имени файла, по содержимому файлов, по содержимому изменений (дифф рабочего дерева против HEAD). Запрос - подстрока или регулярное выражение. Адресована владельцу продукта и составителям SRS.

## 2. Business purpose

Открыть файл или место в коде за несколько нажатий клавиш, не раскрывая дерево и не занимая экран постоянным полем.

## 3. Business scope

Внутри границы: окно поиска и пункт меню «Поиск»; режим «Файлы» (по имени); режимы «Текст» (по содержимому файлов) и «Изменения» (по строкам диффа против HEAD), реализуются следующими шагами Issue #55; переключатели регистра и регулярного выражения; поиск по корням, которые человек видит в дереве (корни активной сессии, без сессии - репозитории проекта).

`non-goals`:

- замена по найденному;
- поиск по истории коммитов и по диффу ветки против базы MR (D-01);
- индексация и кэш содержимого;
- поиск по выводу терминала.

## 7. Mission, goals and objectives

### BR-13001 Найти файл или место в коде без раскрытия дерева

- **Требование:** разработчик по команде (меню или сочетание клавиш) открывает окно поиска, находит файл по части имени или по регулярному выражению в корнях, которые он видит в дереве, и открывает его с клавиатуры; окно не занимает экран, пока не вызвано.
- **traced from:** BR-003.
- **rationale:**
  - reason: в большом репозитории нужный файл не найти раскрытием каталогов; постоянное поле над деревом занимает место;
  - assumptions: корни и файлы те же, что видит дерево сессии (D-05);
  - relationships: сценарий 2 раздела 17 BRD продукта (изменённый файл читается на месте); фича `04-session-tree` (корни, файлы), `07-branch-switch` не затронута;
  - design constraints: только чтение, git только читающими командами (ADR-0005), проверка путей каналов (ADR-0002).
- **MOE:** нужный файл открывается из окна поиска, вызванного с клавиатуры, без мыши и без раскрытия каталогов (качественная).
