# decision-log фичи 13 - окно поиска

Решения прогона по Issue #55 (2026-10-29). Исход «принято» - ответ владельца продукта на вопрос Issue; «открыто» - допущение, принятое за постановщика, подтверждает либо меняет владелец.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | «Дифф» - то, чем оперирует Cyborg: изменения рабочего дерева против HEAD, как их показывает просмотр файла | дифф ветки против базы MR, поиск по истории `git log -S/-G` | ответ владельца на вопрос 1 Issue #55 | принято |
| D-02 | Постоянное поле «Найти файл» над деревом (PR #54) убрано; поиск по имени живёт в окне поиска | оставить поле скрытым за `Cmd/Ctrl+F` в дереве | ответ владельца на вопрос 2 | принято |
| D-03 | Окно вызывается отдельным верхним пунктом меню «Поиск»: «Найти файл…» с `Cmd+P` на macOS и `Ctrl+Shift+P` на Linux; для содержимого и изменений - `Cmd/Ctrl+Shift+F` (следующие шаги) | `Cmd/Ctrl+Shift+N` как в JetBrains: занят новой сессией; `Ctrl+P` на Linux: клавиша readline в терминале | ответ владельца на вопрос 3 («устраивают») | принято |
| D-04 | Запрос - подстрока; переключатель «.*» включает регулярное выражение. В режимах «Файлы» и «Изменения» это `RegExp` JavaScript, в режиме «Текст» - `git grep -P` (PCRE2, тот же синтаксис). От зависания защищают: предел 200 знаков, отказ для выражений с квантором над группой с квантором, строки диффа до 1000 знаков, таймаут `git grep` | `git grep -E`: ERE системной библиотеки не знает `\b` и `\w` (проверено на macOS); разбор выражения в отдельном потоке с таймаутом: тяжелее, чем нужно для окна поиска | ответ владельца на вопрос 4; проверка 2026-10-29 | открыто: отказ по виду выражения не ловит все патологические случаи |
| D-05 | Ищется по корням дерева: корни активной сессии, без сессии - репозитории проекта | только корень сессии; все репозитории проекта независимо от дерева | ответ владельца на вопрос 5 | принято |
| D-06 | Режим «Файлы» ищет в имени, не в пути; вперёд идут имена, начинающиеся с совпадения, затем короткие пути, затем по алфавиту; показаны первые 500 результатов и число найденного; запрос и переключатели помнятся до закрытия приложения | нечёткое совпадение; поиск по пути; показ всех результатов (DOM не потянет) | перенос поведения PR #54 (подстрока без регистра, 500) и практика поиска файла в редакторах | открыто: владелец подтверждает подстроку вместо нечёткого поиска, предел и порядок |
| D-07 | На Linux окно вызывается `Ctrl+Shift+P`, и сочетание не проверено живьём: Linux-сборка прогонялась только смоуком | `Ctrl+P` | D-03; проверки на Linux живьём не было | открыто |
