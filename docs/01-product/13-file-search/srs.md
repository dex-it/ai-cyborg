# SRS фичи 13 - окно поиска по файлам, содержимому и изменениям

## 1. SRS overview

Требования к окну поиска, пункту меню «Поиск», режиму поиска файла по имени, регулярному выражению в запросе и каналу списка файлов. Вход - BRD фичи (`brd-feat.md`, BR-13001), код `src/renderer/search-dialog.ts`, `src/renderer/search-model.ts`, `src/main/menu.ts`, `src/main/files.ts`, `src/main/git.ts`. Основания решений - `decision-log.md` (D-NN). Режимы «Текст» и «Изменения» (Issue #55, шаги 2 и 3) получат свои требования при реализации.

## 2. Purpose

Задать наблюдаемое поведение поиска так, чтобы правка проверялась по требованию, а не по коду.

## 3. Scope

Окно поиска, меню «Поиск», режим «Файлы», переключатели регистра и регулярного выражения, канал `fs:files`. Вне фичи: замена по найденному, история коммитов, дифф ветки против базы MR, индексация, поиск по выводу терминала (`brd-feat.md`, раздел 3).

## 4. Product perspective

Окно поверх интерфейса (`<dialog>`), вызывается из меню приложения; файлы открываются тем же путём, что клик в дереве (вкладка сессии либо просмотр без сессии). Список файлов отдаёт главный процесс (ADR-0005, ADR-0002).

## 5. Product functions

Вызов окна; поиск файла по части имени и по регулярному выражению; открытие найденного; список файлов корня.

## 6. User characteristics

`inherited`: BRD продукта, раздел 5.

## 7. Limitations

Только чтение; git - только читающие команды. Новых npm-зависимостей нет.

## 8. Assumptions and dependencies

## 9. Apportioning of requirements

## 12. Functions

### FR-13001 Окно поиска вызывается из меню и сочетанием, на экране его нет

- **Требование:** в меню приложения есть пункт верхнего уровня «Поиск» с пунктом «Найти файл…» (`Cmd+P` на macOS, `Ctrl+Shift+P` на остальных системах). Пункт доступен, когда выбран проект, и открывает окно поиска; пока окно не вызвано, на экране нет ни окна, ни поля поиска (над деревом поля нет). `Esc` и клик по затемнению закрывают окно, фокус возвращается туда, где он был. Повторный вызов при открытом окне ставит фокус в поле и выделяет набранное. Запрос и переключатели помнятся до закрытия приложения.
- **traced from:** BR-13001.
- **источник:** Issue #55 («не показывался сразу, а вызывался стандартным хоткеем или из меню»); D-02, D-03, D-07.
- **rationale:** reason - постоянное поле занимает место; assumptions - D-03, D-07; relationships - FR-4006 (дерево с клавиатуры); design constraints - сочетание `Ctrl+P` в терминале Linux принадлежит readline, поэтому там `Ctrl+Shift+P`.
- **verification:** испытание - `test/menu.test.ts` («меню «Поиск»»); демонстрация - `scripts/smoke.mjs` (окно закрыто без вызова, пункт меню открывает окно, `Enter` закрывает его).
- **класс:** Functions. **origin:** source.

### FR-13002 Поиск файла по части имени

- **Требование:** в режиме «Файлы» окно показывает файлы, в имени которых есть набранная часть слова без учёта регистра (переключатель «Aa» включает учёт регистра); ищется в имени файла, не в пути. Область поиска - корни дерева: корни активной сессии, а без сессии - репозитории проекта (D-05), включая свёрнутые корни и нераскрытые каталоги; игнорируемые `.gitignore` файлы не входят (FR-13005). Порядок: имена, начинающиеся с совпадения, затем короткие пути, затем по алфавиту. Строка результата - имя с подсвеченной совпавшей частью и каталог (при нескольких корнях - с именем корня) серым. Показываются первые 500 результатов; подпись под полем: «Найдено N» либо «Найдено N, показаны первые 500»; без совпадений - «Нет совпадений»; пустой запрос - число файлов; нет проекта - «Нет проекта с репозиториями». `Enter` и клик открывают файл: вкладкой активной сессии, а без сессии - просмотром, и закрывают окно.
- **traced from:** BR-13001.
- **источник:** Issue #55; перенос поведения поля из PR #54; D-05, D-06.
- **rationale:** reason - найти файл, не раскрывая дерево; assumptions - D-06; relationships - FR-13005, FR-4001 (дерево), BR-003 (просмотр файла); design constraints - предел 500 строк DOM без задержки на нажатие.
- **verification:** испытание - `test/search-model.test.ts` («compileMatcher: подстрока», «matchFiles», «resultSummary и moveActive»); демонстрация - `scripts/smoke.mjs` (часть имени без учёта регистра, подсветка, «нет совпадений», `Enter` открывает файл).
- **класс:** Functions. **origin:** source.

### FR-13003 Запрос регулярным выражением

- **Требование:** переключатель «.*» включает разбор запроса как регулярного выражения JavaScript (в режиме «Файлы» - по имени файла; с учётом переключателя «Aa»). Негодное выражение не бросает исключение: поле помечено `aria-invalid`, подпись называет причину («Выражение не разобрано: …»), список пуст. Не принимаются и показывают причину выражение длиннее 200 знаков и выражение с квантором над группой, внутри которой тоже есть квантор (`(a+)+`, `(.*)*`): у `RegExp` JavaScript нет таймаута, и такое выражение вешает окно.
- **traced from:** BR-13001.
- **источник:** просьба владельца добавить поиск регулярным выражением (Issue #55); D-04.
- **rationale:** reason - искать по шаблону имени; assumptions - D-04: отказ по виду выражения не ловит все патологические случаи; relationships - FR-13002; design constraints - `RegExp` не прерывается по таймауту.
- **verification:** испытание - `test/search-model.test.ts` («compileMatcher: регулярное выражение»); демонстрация - `scripts/smoke.mjs` (выражение находит файл, `(` называет ошибку).
- **класс:** Functions. **origin:** source.

### FR-13004 Окно поиска управляется с клавиатуры

- **Требование:** поле запроса - `combobox` (`aria-controls` на список, `aria-activedescendant` на активную строку), список - `listbox` с подписью «Найденные файлы», строка - `option` с `aria-selected`; переключатели «Aa» и «.*» - кнопки с `aria-pressed` и подписью. Фокус при открытии стоит в поле. `ArrowDown` и `ArrowUp` переводят активную строку по кругу, активная прокручивается в видимую часть, `Enter` открывает её; сочетания с `Ctrl`, `Alt` и `Cmd` поле не перехватывает.
- **traced from:** BR-13001.
- **источник:** Issue #55 («с клавиатуры»); практика WAI-ARIA combobox с `aria-activedescendant`.
- **rationale:** reason - фокус должен оставаться в поле, пока набирается запрос; assumptions - нет; relationships - FR-13002, FR-4006; design constraints - `<dialog>` с `aria-labelledby` (как другие окна).
- **verification:** испытание - `test/search-model.test.ts` («moveActive»), `test/static-guards.test.ts` (подпись окон); демонстрация - `scripts/smoke.mjs` (`Enter` на активной строке).
- **класс:** Functions. **origin:** source.

### FR-13005 Список файлов корня

- **Требование:** канал `fs:files` отдаёт пути файлов под корнем относительно него. В git-корне это `git ls-files -z --cached --others --exclude-standard` (отслеживаемые и новые, без игнорируемых `.gitignore`), вне git - обход каталога без `.git` не больше чем по 50 000 файлов. Путь корня проверяется так же, как в других каналах `fs:*`: корень вне репозиториев проектов и каталогов живых сессий отклоняется.
- **traced from:** BR-13001.
- **источник:** Issue #55; перенос канала из PR #54; ADR-0002, ADR-0005.
- **rationale:** reason - окну нужен весь набор файлов корня, а не раскрытые каталоги; assumptions - нет; relationships - FR-13002, FR-1017 (проверка путей); design constraints - git только читающей командой, обход ограничен.
- **verification:** испытание - `test/file-list.test.ts` (`gitFiles`, `walkFiles`), `test/allowed-paths.test.ts` (канал вне разрешённых путей).
- **класс:** Functions. **origin:** source.
