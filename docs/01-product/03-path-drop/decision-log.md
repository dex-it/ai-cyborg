# decision-log фичи 03 - путь файла в промпт сессии перетаскиванием

Решения и допущения прогона цели `tree-drag-path` (2026-10-24). Исход «открыто» - допущение, принятое за
постановщика без оператора; подтверждает либо меняет владелец продукта.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Зоны броска - видимый терминал сессии и её вкладка «Claude»; бросок на вкладку вставляет путь и показывает терминал, при открытом файле переключает с него | - | цель, критерии 1, 5 (ответ оператора) | принято |
| D-02 | Строка корня дерева перетаскивается наравне со строками файла и каталога | - | цель, критерий 1 (допущение: корень тоже путь) | открыто |
| D-03 | Путь без кавычек - только если все символы из `[A-Za-z0-9_@%+=:,./-]`; иначе в одинарных кавычках, внутренняя кавычка - `'\''`, как `shlex.quote` с классом ASCII: путь с кириллицей идёт в кавычках | - | цель, критерий 2 (ответ оператора - кавычки при пробеле; набор символов и экранирование - допущение по POSIX shell-quoting) | открыто: набор символов без кавычек |
| D-04 | Несколько путей - через пробел, после последнего пробел; файл ОС без пути на диске пропускается молча; пропущены все - ни вставки, ни показа терминала | показывать терминал и при пустом результате: оператор видел бы реакцию без вставки | цель, критерий 4 (ответ оператора; пропуск - допущение) | открыто: пропуск файла без пути |
| D-05 | Превью перетаскивания - стандартное браузера, `setDragImage` нет | - | цель, граница (допущение) | открыто |
| D-06 | Вставка - `term.paste` xterm, как Ctrl+Shift+V; bracketed paste xterm ставит сам по режиму процесса | запись в pty через ввод сессии с ручной обёрткой `ESC[200~`: повтор логики xterm и слежение за режимом 2004 своими силами | цель, критерий 3; прогон, дизайн | принято |
| D-07 | Строка дерева отдаёт путь только собственным типом `application/x-cyborg-path`, разрешено только копирование; `text/plain` не кладётся | путь в `text/plain`: его можно бросить в любое текстовое поле, в том числе в просмотр файла, и бросок дерева не отличить от файла ОС | прогон, дизайн; цель, граница (Monaco вне фичи) | принято |
| D-08 | Пути с управляющими символами (`\x00-\x1f`, `\x7f`) отбрасываются до вставки, для дерева и для файлов ОС | вставлять как есть: при вставке без bracketed paste CR, LF, ESC в имени файла отправили бы ввод в процесс сессии | прогон, решение кодера по замечанию security-хука | принято |
| D-09 | Бросок файла ОС вне зон подавляется в интерфейсе сторожем на документе: `dragover` и `drop` отменяются, курсор - «нельзя» (`dropEffect: none`); окно не уходит на `file://` | подавление навигации в главном процессе (`will-navigate`): граница цели запрещает менять главный процесс; сторож, всегда показывающий «копировать»: курсор обещал бы бросок там, где его нет | цель, критерий 6 (ответ оператора), граница; прогон, дизайн | принято |
| D-10 | Путь файла ОС даёт функция preload `pathForFile` поверх `webUtils.getPathForFile`, синхронно и без IPC; ADR-0002 п.3 расширен четвёртым видом вызова моста | `File.path`: снят в Electron с версии 32, у проекта Electron 45 | цель, граница; прогон, неверное во входе (версия снятия) | принято |
| D-11 | Бросок в завершённую сессию ничего не вставляет и терминал не показывает; курсор над её зонами - «нельзя» | - | цель, критерий 7 (допущение: писать некому) | открыто |
| D-12 | После броска фокус в терминале - как при показе терминала | - | цель, критерий 8 (допущение) | открыто |
| D-13 | Строка удалённого файла (git-статус D) перетаскивается так же: строка есть путь, существование файла не проверяется | - | прогон, решение по практике: требование о проверке молчит | открыто |
| D-14 | Правки корпуса вне фичи, род - расширение области: BRD продукта, раздел 3 и сценарий 6 раздела 17 - вставка пути перетаскиванием; ADR-0002 п.3 - локальная функция preload без IPC | новый BR продукта: предмет - работа с деревом и сессией, его несут BR-001 и BR-002 | прогон фиксации, раскладка | принято |
