# SRS фичи 04 - дерево файлов сессии

## 1. SRS overview

Требования системы к корням дерева сессии и к раскрытию его узлов. Вход - BRD фичи (`brd-feat.md`, BR-4001), цель
трека `tree-expand-independent` и её критерий «готово». Основания решений и допущений - `decision-log.md` (D-NN).

## 2. Purpose

Задать наблюдаемое поведение раскрытия дерева и состав его корней так, чтобы правка проверялась по требованию, а не
по коду.

## 3. Scope

Специфицируется часть интерфейса Cyborg: корни дерева сессии, их подписи и подсказки, раскрытие и сворачивание
каталогов и корней. Вне фичи: открытие и выделение файла, git-статус и бейджи, перетаскивание (цель `tree-drag-path`).

## 4. Product perspective

Дерево - интерфейс (renderer); корни строятся по сессии и репозиториям проекта, смена рабочего каталога приходит
событием сессии из главного процесса (ADR-0003).

## 5. Product functions

Корни дерева сессии; раскрытие каталога; сворачивание корня; изоляция раскрытия по сессии.

## 6. User characteristics

`inherited`: BRD продукта, раздел 5.

## 7. Limitations

Главный процесс и preload не меняются, зависимости не добавляются (цель, граница).

## 8. Assumptions and dependencies

Допущение D-02 открыто до подтверждения владельцем.

## 9. Apportioning of requirements

## 12. Functions

### FR-4001 Раскрытие каталога только по клику на него

- **Требование:** клик по каталогу дерева раскрывает его, если он свёрнут, и сворачивает, если раскрыт; прочие
  каталоги - соседние, вложенные, одноимённые в других корнях - остаются как были. Раскрытые внутри свёрнутого
  каталога подкаталоги при следующем его раскрытии видны раскрытыми.
- **traced from:** BR-4001.
- **источник:** формулировка оператора; цель, критерии 1-2 (критерий 1 - ответ оператора); D-01.
- **rationale:** reason - клик раскрывал одноимённый каталог в дубле корня; assumptions - нет; relationships -
  FR-4004; design constraints - нет.
- **verification:** испытание - `test/tree.test.ts` («клик по каталогу раскрывает только его…», «повторный клик
  сворачивает только этот каталог…», «cwd сессии в другом репозитории проекта: клик по каталогу раскрывает одну
  строку…»).
- **класс:** Functions. **origin:** source.

### FR-4002 Сворачивание корня

- **Требование:** клик по строке корня сворачивает либо разворачивает только этот корень.
- **traced from:** BR-4001.
- **источник:** цель, критерий 3.
- **rationale:** reason - при дубле корня клик сворачивал обе копии; assumptions - нет; relationships - FR-4004;
  design constraints - нет.
- **verification:** испытание - `test/tree.test.ts` («корень с повторным путём: клик по корню сворачивает один
  корень…»).
- **класс:** Functions. **origin:** source.

### FR-4003 Раскрытие изолировано по сессии

- **Требование:** раскрытие каталогов и корней одной сессии не меняет дерево другой сессии.
- **traced from:** BR-4001; BRD продукта, раздел 11.
- **источник:** цель, критерий 4.
- **rationale:** reason - сессия - изолированное рабочее пространство; assumptions - нет; relationships - нет;
  design constraints - нет.
- **verification:** испытание - `test/tree.test.ts` («раскрытие не делится между сессиями»).
- **класс:** Functions. **origin:** source.

### FR-4004 Корни дерева сессии без повтора пути

- **Требование:** дерево сессии показывает свой корень первым, затем прочие репозитории проекта; путь корня в
  дереве не повторяется. Свой корень - текущий корень сессии: стартовый репозиторий, его worktree либо другой
  репозиторий проекта, куда ушёл рабочий каталог. Стартовый репозиторий среди прочих корней стоит, только когда свой
  корень - другой репозиторий проекта; при корне - стартовом репозитории либо его worktree прочие корни - остальные
  репозитории проекта.
- **traced from:** BR-4001.
- **источник:** цель, критерий 1; D-02, D-03.
- **rationale:** reason - репозиторий в дереве дважды делил одно состояние раскрытия и сворачивания на обе копии;
  assumptions - D-02 (стартовый репозиторий показывается, открыто); relationships - FR-4001, FR-4002; design
  constraints - повтор отсекается и при построении корней, и при установке их в дерево (D-03).
- **verification:** испытание - `test/roots.test.ts` («cwd ушёл в другой репозиторий проекта: свой корень, затем
  стартовый репозиторий, без дубля», «worktree репозитория…», «корень совпадает со стартовым репозиторием…»),
  `test/tree.test.ts` («корень с повторным путём…»).
- **класс:** Functions. **origin:** source.

### FR-4005 Подпись и подсказка корня после ухода рабочего каталога

- **Требование:** когда рабочий каталог сессии ушёл в другой репозиторий проекта, свой корень подписан именем этого
  репозитория с подсказкой «другой репозиторий проекта, куда перешёл рабочий каталог сессии», а стартовый
  репозиторий - подсказкой «репозиторий, где сессия была запущена»; подпись своего корня идёт и во вкладку сессии
  без задачи и MR. Worktree стартового репозитория подписан «стартовый ⎇ worktree» с подсказкой «worktree
  репозитория …», как прежде.
- **traced from:** BR-4001.
- **источник:** D-04.
- **rationale:** reason - прежняя подпись называла отдельный репозиторий worktree стартового, а стартовый
  репозиторий - каталогом из `--add-dir`; assumptions - нет; relationships - FR-4004; design constraints - нет.
- **verification:** испытание - `test/roots.test.ts` («при перешедшем cwd стартовый репозиторий назван
  репозиторием запуска, а корень не worktree», «worktree сохраняет подпись и подсказку про worktree»).
- **класс:** Functions. **origin:** source.
