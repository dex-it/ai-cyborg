# BRD фичи 08 - прошлые сессии Claude Code проекта

> Реконструировано из кода (`src/main/history.ts`, `src/renderer/app.ts`) и прогона на настоящем Claude Code 2.1.310, не
> согласовано: постановки от владельца нет. Фича шипится; BRD продукта числил «восстановление сессий» в non-goals и сообщал
> «история сессий внутри Cyborg отсутствует» (правка - D-01).

## 1. BRS overview

Закрытое окно уносит с собой терминалы сессий, а разговор остаётся в журнале Claude Code. Фича показывает прошлые сессии проекта
во вкладке «Сессии», продолжает выбранную и удаляет ненужную. Адресована владельцу продукта и составителям SRS.

## 2. Business purpose

Вернуться к прошлой сессии проекта в том же репозитории за один клик, не помня её идентификатора и не храня вторую копию истории.

## 3. Business scope

Внутри границы: список интерактивных сессий репозиториев проекта (в том числе ушедших в worktree - фича `05-macos-support`,
FR-5008); продолжение выбранной (`claude --resume`); удаление выбранной.

`non-goals`:

- автоматическое восстановление вкладок и процессов сессий при запуске Cyborg;
- собственное хранилище истории: источник - журналы Claude Code;
- правка журналов; поиск по содержимому сессий; сессии SDK и `claude -p`.

## 7. Mission, goals and objectives

### BR-8001 Вернуться к прошлой сессии проекта

- **Требование:** разработчик видит прошлые интерактивные сессии репозиториев проекта, свежие первыми, с понятным заголовком,
  продолжает выбранную в том же репозитории и удаляет ненужную.
- **traced from:** BR-001.
- **rationale:**
  - reason: окно закрыто - терминалы сессий потеряны, а разговор нужен;
  - assumptions: журналы Claude Code лежат в `~/.claude/projects` (D-02);
  - relationships: сценарий 8 раздела 17 BRD продукта; ADR-0012;
  - design constraints: сессия остаётся нативной: продолжение - обычный `claude --resume` (ADR-0012, п.5).
- **MOE:** прошлая сессия проекта продолжается из списка, и Claude Code видит прежний разговор (качественная).
