# decision-log фичи 08 - история сессий

Решения и допущения прогона по Issue #10 (2026-10-26). Исход «открыто» - допущение, принятое за постановщика без владельца
(рекомендации Issue #10, владелец поручил решать по качеству); подтверждает либо меняет владелец продукта.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | История и продолжение сессий - принятая возможность продукта: non-goal BRD «восстановление сессий» сужен до автоматического восстановления процессов и вкладок, «история сессий внутри Cyborg отсутствует» заменено описанием; требования - в отдельной фиче 08 | убрать возможность из кода (README и сайт её описывают); описать внутри фичи 05 (фича про платформы) | Issue #10, вопросы 1 и 4; прогон на настоящем Claude Code 26.10.2026 | открыто |
| D-02 | Источник истории - журналы Claude Code `~/.claude/projects/<имя>`; своего хранилища у Cyborg нет | своя копия истории: расхождения с CLI | ADR-0012, п.3; код `listHistory` | открыто |
| D-03 | В список входят только интерактивные сессии (`entrypoint: cli`) с заголовком; сессии SDK и `claude -p` и журналы без заголовка не показываются | показывать все файлы журналов: список засорили бы служебные сессии, их не продолжить в терминале | код `journalFacts`, тест | открыто |
| D-04 | Заголовок: последний `custom-title`, иначе последний `ai-title`, иначе первый набранный запрос (служебная разметка `<...>` не запрос), в одну строку до 120 символов | всегда первый запрос: не отличает сессии с общим началом | код `journalFacts`, тест | открыто |
| D-05 | Список - 50 свежих; файл читается по краям (по 64 КБ) | без предела и полное чтение: журналы сессий - мегабайты | числа выбраны кодом (в постановке нет) | открыто |
| D-06 | Удаление стирает журнал и каталог вывода сессии; перед ним - подтверждение с предупреждением, что продолжить станет нельзя | перенос в корзину: Cyborg не знает корзины ОС; удаление без вопроса: необратимо | код `deleteHistory`, `confirm` в интерфейсе | открыто |
