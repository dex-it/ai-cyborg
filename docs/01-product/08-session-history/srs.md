# SRS фичи 08 - прошлые сессии Claude Code проекта

## 1. SRS overview

Требования к вкладке «Сессии»: список, продолжение, удаление. Вход - BRD фичи (`brd-feat.md`, BR-8001), код `src/main/history.ts`,
`src/main/main.ts` (`history:*`, `session:resume`), `src/renderer/app.ts`. Основания решений - `decision-log.md`.

## 2. Purpose

Задать наблюдаемое поведение истории сессий так, чтобы правка проверялась по требованию, а не по коду.

## 3. Scope

Список прошлых сессий проекта, продолжение, удаление. Вне фичи: автоматическое восстановление, собственное хранилище, поиск
по содержимому (`brd-feat.md`, раздел 3).

## 4. Product perspective

Переключатель «Файлы»/«Сессии» в нижней полосе окна. Читает `~/.claude/projects` (ADR-0012, п.3), запуск продолжения - как у обычной
сессии (ADR-0003).

## 5. Product functions

Список; продолжение; удаление. Сессии, ушедшие в worktree, - FR-5008 (фича `05-macos-support`).

## 6. User characteristics

`inherited`: BRD продукта, раздел 5.

## 7. Limitations

Только чтение каталога журналов и удаление выбранной сессии. Новых зависимостей нет.

## 8. Assumptions and dependencies

Формат журнала Claude Code 2.1.310 (записи `entrypoint`, `custom-title`, `ai-title`, `user`) и имя каталога репозитория; смена
формата ломает список. Допущения D-01..D-06 открыты до подтверждения владельцем.

## 9. Apportioning of requirements

Главный процесс: FR-8001 (чтение), FR-8002 (запуск), FR-8003 (удаление). Интерфейс: вкладка, подтверждение удаления.

## 10. Specified requirements

Общие атрибуты, если у требования не сказано иное: `feature: 08-session-history`; приоритет - обязательно; основание -
несценарное требование (сценарий 8 BRD продукта); уровень верификации - модуль (`npm test`) для испытания и собранное приложение
для демонстрации.

## 11. External interfaces

`n/a`: внешних интерфейсов, кроме журналов Claude Code (ADR-0012), нет.

## 12. Functions

### FR-8001 Список прошлых сессий проекта

- **Требование:** вкладка «Сессии» показывает до 50 прошлых интерактивных сессий репозиториев проекта, свежие по времени последней
  записи журнала первыми; в строке - заголовок (последний `custom-title`, иначе последний `ai-title`, иначе первый набранный запрос,
  в одну строку до 120 символов), имя репозитория и давность. Сессии SDK и `claude -p` (запись `entrypoint` не `cli`), журналы без
  заголовка и пустые файлы не показываются; служебная разметка `<...>` запросом не считается. Нет проекта - «Нет проекта»,
  нет сессий - «Прошлых сессий нет», сбой чтения - его текст. Сессии worktree входят в список (FR-5008).
- **traced from:** BR-8001.
- **источник:** код `listHistory`, `journalFacts`; прогон на настоящем Claude Code 26.10.2026; D-02..D-05.
- **rationale:** reason - найти нужную сессию по смыслу, а не по идентификатору; assumptions - D-02, D-03; relationships - FR-5008;
  design constraints - ADR-0012, п.3, п.4.
- **verification:** испытание - `test/history.test.ts` («journalFacts: custom-title старше ai-title…», «сессия SDK не интерактивна»,
  «listHistory: только интерактивные с заголовком, свежие первыми; лимит; чужие файлы мимо», «ago»); демонстрация - вкладка на
  настоящем Claude Code.
- **класс:** Functions. **origin:** derived.

### FR-8002 Продолжение прошлой сессии

- **Требование:** клик по строке запускает `claude --resume <id>` в репозитории сессии как новую вкладку, остальные репозитории
  проекта - `--add-dir`; порядок аргументов - FR-9002. Канал `session:resume` принимает идентификатор только вида UUID и
  каталоги только из репозиториев проектов, и отказывает «Журнал сессии не найден», если журнала нет. Сессия worktree возобновляется из
  каталога репозитория: Claude Code возвращает её в worktree (FR-5008).
- **traced from:** BR-8001.
- **источник:** код `session:resume`, `claudeArgs`; прогон на настоящем Claude Code 26.10.2026 (продолжение вернуло сессию в worktree); D-02.
- **rationale:** reason - продолжить разговор там же; assumptions - Claude Code сам находит журнал (ADR-0012, п.5); relationships -
  FR-9002, FR-5008, FR-1017 (проверка аргументов); design constraints - ADR-0002, п.5.
- **verification:** испытание - `test/history.test.ts` («claudeArgs: --resume с id стоит до --add-dir», «сессии worktree»: существование
  журнала); демонстрация - продолжение на настоящем Claude Code. Проверки аргументов канала `session:resume` отдельным тестом не покрыты
  (обработчик в `main.ts`; общие проверки - `sessionDirsAllowed`, `isSessionId`).
- **класс:** Functions. **origin:** derived.

### FR-8003 Удаление прошлой сессии

- **Требование:** кнопка «×» в строке после подтверждения («Удалить сессию «<заголовок>»? Её журнал будет стёрт, продолжить её станет
  нельзя.») удаляет файл `<id>.jsonl` и одноимённый каталог (вывод инструментов, субагенты) из каталога журнала репозитория либо его
  worktree; других файлов не трогает; строка исчезает из списка. Канал `history:delete` принимает проект, репозиторий этого проекта и
  идентификатор вида UUID, иначе «Некорректное удаление сессии»; журнала нет - «Журнал сессии не найден».
- **traced from:** BR-8001.
- **источник:** код `deleteHistory`, `history:delete`; прогон на настоящем Claude Code 26.10.2026; D-06.
- **rationale:** reason - убрать ненужную сессию из списка; assumptions - D-06; relationships - FR-5008; design constraints - ADR-0012, п.5.
- **verification:** испытание - `test/history.test.ts` («сессии worktree: журнал … виден, возобновляется и удаляется»); демонстрация -
  удаление на настоящем Claude Code стёрло журнал в каталоге worktree.
- **класс:** Functions. **origin:** derived.
