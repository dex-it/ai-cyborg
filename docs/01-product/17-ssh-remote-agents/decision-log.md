# decision-log фичи 17 - удалённые сессии Claude Code по SSH

Решения по цели `ssh-remote-agents` (2026-11-09): «Cyborg запускает сессии Claude Code на серверах разработчика по SSH и ведёт их жизненный цикл - создание с заданием, живой терминал, явный итог агента, закрытие с уборкой места на хосте - для человека из интерфейса и для сессии-оркестратора через MCP-инструменты, и удалённая сессия переживает обрыв связи и выход Cyborg». Этап 2 (2026-11-11) - решения D-21..D-31 плана «продолжаемые сессии, сон, доступы и настройка агента на хосте», утверждённого оператором. Источник требований выше цели оператор не назвал; решения, названные в цели и в проектировании, - исход «принято проектировщиком», выведенные составителем из кода правки - «принято составителем», до подтверждения владельцем.

Экземпляр Cyborg назван идентификатором: сессию, которую держит другое окно, не подхватывают | подхват чужих сессий; бесконечный частый повтор | два окна не должны писать в один терминал | принято проектировщиком |
