# SRS фичи 06 - витрина продукта: README и сайт документации

## 1. SRS overview

Требования к README и сайту документации. Вход - BRD фичи (`brd-feat.md`, BR-6001). Основания решений -
`decision-log.md`.

## 2. Purpose

Задать наблюдаемое поведение сборки и публикации сайта и состав README так, чтобы они проверялись по требованию.

## 3. Scope

README; проект `site/`, страницы `docs/guide/`, workflow `docs-site.yml`, проверка `site/scripts/check-dist.mjs`.
Вне фичи: скриншоты, лицензия, английская версия.

## 4. Product perspective

Сайт не часть приложения: собирается отдельно, значок берёт из `assets/icon.svg`. Страницы лежат в `docs/guide/` рядом с
корпусом, проект Starlight - в `site/`.

## 5. Product functions

README со значком, навигацией и разделами; сайт на русском с поиском; публикация на Pages.

## 6-9

`inherited` либо не применимо: пользователи - BRD продукта, раздел 5; ограничение - без скриншотов (D-03).

## 10. Specified requirements

Общие атрибуты: `feature: 06-docs-site`; приоритет - обязательно; верификация - демонстрация (сборка и просмотр) и
испытание (`npm run verify`).

## 11. External interfaces

### FR-6003 Публикация на GitHub Pages

- **Требование:** на пуш в `master` и вручную workflow `docs-site.yml` собирает сайт, проверяет сборку и публикует его
  на https://dex-it.github.io/ai-cyborg/ через GitHub Pages (Actions); на PR, затрагивающий сайт, страницы или значок,
  собирает и проверяет, ничего не публикуя. Проверка не обязательна в защите ветки. Экшены закреплены по SHA коммита.
- **traced from:** BR-6001.
- **источник:** запрос оператора «задеплой по аналогии»; образец - workflow `Docs site` в `dex-it/ai-kit`; D-01.
- **rationale:** reason - публикация без ручных шагов; assumptions - в репозитории включены Pages со сборкой из Actions и
  окружение `github-pages` допускает `master`; relationships - `ci.yml` проверяет приложение, этот workflow - сайт.
- **verification:** демонстрация - прогон workflow на GitHub и открытый сайт.
- **класс:** External interfaces. **origin:** source.

## 12. Functions

### FR-6001 README

- **Требование:** README открывается значком приложения, названием, слоганом, бейджами (CI, платформы, Node.js, статус)
  и навигацией; далее разделы: о проекте, возможности, быстрый старт, клавиши, чего не делает, статус, устройство
  (диаграмма), документация, разработка. Каждая названная возможность подтверждена на приложении; условия возможностей
  названы (ревью MR требует плагина `dex-auto`).
- **traced from:** BR-6001.
- **источник:** запрос оператора; D-02.
- **rationale:** reason - вход в продукт; assumptions - диаграмма Mermaid рендерится GitHub; relationships - сайт повторяет
  и углубляет README; design constraints - без скриншотов и лицензии (D-03).
- **verification:** демонстрация - просмотр README на GitHub; прогон возможностей на приложении (дерево, сессии, задачи
  и MR на `cli/go-gh`, история, настоящий Claude Code).
- **класс:** Functions. **origin:** source.

### FR-6002 Сайт документации

- **Требование:** сайт на Astro и Starlight, русский, тёмная и светлая темы, поиск Pagefind; разделы «Начать»,
  «Возможности», «Как это устроено», «Справка», «Участие», «Вопросы». Страницы - `docs/guide/**`. Адрес и название - из
  `site/site.config.mjs`. Значок берётся из `assets/icon.svg` при сборке. Проверка сборки (`npm run verify`) без сети:
  внутренние ссылки и якоря ведут на существующие файлы под базовым путём, у страниц есть canonical, индекс поиска
  русский и покрывает все страницы, есть sitemap.
- **traced from:** BR-6001.
- **источник:** запрос оператора; образец - `dex-it/ai-kit`; D-01, D-04.
- **rationale:** reason - справка шире README; assumptions - версии Astro 7.3.8 и Starlight 0.42.6 как у ai-kit;
  relationships - FR-6003; design constraints - новых зависимостей приложения нет, зависимости сайта в `site/` с точными
  версиями.
- **verification:** испытание - `npm run build && npm run verify` в `site/` (22 страницы, 921 ссылка, ошибок нет),
  `npm run check`; демонстрация - просмотр собранных страниц.
- **класс:** Functions. **origin:** source.
