# BRD фичи 06 - витрина продукта: README и сайт документации

Источник: запрос оператора 2026-10-26 - значок и структурное описание в README «как у больших десктопных утилит»
(пример - Ghostty), «доки сразу сделай и задеплой по аналогии» с `dex-it/ai-kit` и https://dex-it.github.io/ai-kit.
Сообщение оператора про зачаточный вид продукта оборвано; из него принято одно: подача честно называет раннюю стадию.

## 1. BRS overview

У продукта был только текстовый README без значка и без сайта. Фича даёт новому человеку понятный вход: страницу
репозитория с логотипом, навигацией и разделами и сайт документации на GitHub Pages. Адресован владельцу продукта и
составителям SRS.

## 2. Business purpose

Сократить путь нового разработчика от ссылки на репозиторий до первой сессии и дать справку по возможностям и
устройству, не заставляя читать корпус требований.

## 3. Business scope

Внутри границы: README (значок, слоган, бейджи, навигация, разделы); сайт документации (Astro и Starlight, страницы в
`docs/guide/`); публикация на GitHub Pages workflow-ом; проверка сборки сайта.

`non-goals`:

- скриншоты и видео интерфейса: оператор отложил («скриншота пока не надо»);
- лицензия: в репозитории её нет, выбор за владельцем;
- английская версия сайта;
- упаковка и установщики.

## 7. Mission, goals and objectives

### BR-6001 Понятный вход в продукт

- **Требование:** по ссылке на репозиторий и на сайт новый разработчик понимает, что делает Cyborg, чего не делает, что
  нужно для запуска, и запускает его; описание не обещает того, чего продукт не умеет.
- **traced from:** BR-001, BR-002, BR-004, BR-5001.
- **rationale:**
  - reason: запрос оператора; у продукта нет другого входа, кроме README без значка;
  - assumptions: образец оформления - ai-kit (Astro, Starlight, Pages через Actions);
  - relationships: BRD продукта, разделы 1-3;
  - design constraints: каждое утверждение подачи проверено на приложении (D-02).
- **MOE:** страница репозитория и сайт открываются, ссылки целы, заявленные возможности подтверждены прогоном
  (качественная).
