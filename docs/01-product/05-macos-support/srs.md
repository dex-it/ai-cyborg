# SRS фичи 05 - работа Cyborg на macOS

## 1. SRS overview

Требования к запуску, клавишам команд, чтению журнала событий и платформенным умолчаниям, нужные для работы на
macOS наравне с Linux. Вход - BRD фичи (`brd-feat.md`, BR-5001) и Issue dex-it/ai-cyborg#2. Основания решений -
`decision-log.md` (D-NN).

## 2. Purpose

Задать наблюдаемое поведение на macOS так, чтобы правка проверялась по требованию, а не по коду.

## 3. Scope

Скрипт запуска, клавиши команд и подсказки интерфейса, чтение журнала событий сессии, шрифт терминала, каталог
данных замера, автоматическая проверка PR. Вне фичи: упаковка, запуск из Dock и Finder, Option как Meta, Windows (D-07).

## 4. Product perspective

Скрипт `cyborg` - в корне репозитория. Клавиши - интерфейс (`src/renderer/platform.ts`, `app.ts`), платформа
приходит из моста preload (D-03). Чтение журнала - `SessionManager` главного процесса.

## 5. Product functions

Запуск одной командой; команды приложения на клавише своей системы; надёжное чтение событий хуков; шрифты и
каталог данных по платформе.

## 6. User characteristics

`inherited`: BRD продукта, раздел 5.

## 7. Limitations

- Новых npm-зависимостей нет.
- Запуск из Dock и Finder не поддерживается (BRD фичи, раздел 12).

## 8. Assumptions and dependencies

- Electron 45: меню приложения по умолчанию содержит Edit > Copy и Paste с Cmd+C и Cmd+V (D-02).
- Допущения D-06, D-08 открыты до подтверждения владельцем.

## 9. Apportioning of requirements

Скрипт запуска: FR-5001. Интерфейс и preload: FR-5002, FR-5004. Главный процесс: FR-5003, FR-5006. Загрузка проекта: FR-5007. История сессий: FR-5008. Автоматическая проверка: FR-5005, FR-5009.

## 10. Specified requirements

Общие атрибуты, если у требования не сказано иное: `feature: 05-macos-support`; приоритет - обязательно;
основание - несценарное требование; уровень верификации - модуль (`npm test`) для испытания и собранное приложение
для демонстрации.

## 11. External interfaces

### FR-5001 Запуск одной командой

- **Требование:** `./cyborg` в корне репозитория на macOS и Linux проверяет наличие git, Node.js 24 и новее и npm
  (иначе завершается с сообщением и кодом 1), ставит зависимости, если нет `node_modules` или `package-lock.json`
  новее `node_modules/.package-lock.json`, собирает приложение и запускает Electron, передавая ему свои аргументы.
  Работает при вызове по символьной ссылке из любого каталога. На Linux без setuid `chrome-sandbox` и без
  user namespaces добавляет `--no-sandbox` и предупреждает в stderr (D-06).
- **traced from:** BR-5001.
- **источник:** Issue #2, критерий 2; README; D-06.
- **rationale:** reason - README ссылается на скрипт, которого нет; assumptions - `sh` и утилиты POSIX есть на
  обеих системах; relationships - ADR-0006 п.6; design constraints - без GNU-расширений.
- **verification:** испытание - `test/launcher.test.ts` (скрипт исполняемый и разбирается как POSIX sh; Node старше 24 - сообщение и код 1 до установки;
  Node 24 доходит до npm); демонстрация - чистый клон на macOS: установка, сборка, окно (`cyborg` открыл страницу
  `Cyborg`); без Node и со старым Node - сообщение и код 1; через символьную ссылку из другого каталога. Ветка
  Linux не прогонялась (D-06).
- **класс:** External interfaces. **origin:** source.

## 12. Functions

### FR-5002 Клавиши команд своей системы

- **Требование:** на macOS: Cmd+Shift+N - новая сессия, Cmd+0 - размер шрифта по умолчанию, Cmd+колесо - шаг размера
  шрифта; на остальных системах те же команды на Ctrl. Чужой модификатор команду не вызывает, в том числе Ctrl на
  macOS (D-01). Подсказка кнопки «Новая сессия» и текст пустого экрана называют сочетание своей системы. Копирование и
  вставка терминала на macOS - Cmd+C и Cmd+V через меню Electron; вне macOS - Ctrl+Shift+C и Ctrl+Shift+V (D-02).
- **traced from:** BR-5001.
- **источник:** Issue #2, критерии 3 и 4; D-01, D-02, D-03, D-08.
- **rationale:** reason - клавиши были только на Ctrl; assumptions - Cmd+Shift+N не занят меню Electron;
  relationships - FR-3002 фичи 03 (вставка); design constraints - платформа из моста preload без IPC (ADR-0002 п.3).
- **verification:** испытание - `test/platform.test.ts` (`hasCommandKey`, `shortcut`, `isClipboardKey`);
  демонстрация - в собранном приложении события CDP: Ctrl+Shift+N и Ctrl+колесо молчат, Cmd+Shift+N открывает
  сессию, Cmd+колесо x3 даёт размер 16, Cmd+0 - 13; `webContents.copy()` и `paste()` с выделением в терминале.
  Cmd+0 физической клавиатурой не проверено (D-08).
- **класс:** Functions. **origin:** source.

### FR-5003 Чтение журнала событий независимо от момента взвода наблюдателя

- **Требование:** события хуков, записанные в файл сессии между запуском процесса и взводом наблюдателя файла,
  читаются: после взвода журнал читается ещё раз. Смена рабочего каталога и активность сессии доходят до интерфейса
  на macOS так же, как на Linux (D-04).
- **traced from:** BR-5001.
- **источник:** Issue #2, критерий 5; D-04.
- **rationale:** reason - на macOS наблюдатель взводится на следующем витке цикла, ранняя запись теряется;
  assumptions - чтение идёт по смещению и повторное безопасно; relationships - ADR-0003 п.3, п.4; design constraints
  - без опроса таймером.
- **verification:** испытание - `src/main/sessions.test.ts` («читает события: смена cwd, активность, удаление файла
  на выходе»: запись сразу после `create()`); демонстрация - собранное приложение с подставным `claude`, шлющим
  события: `cd` в worktree переводит дерево на worktree.
- **класс:** Functions. **origin:** source.

### FR-5004 Платформенные умолчания

- **Требование:** шрифты терминала - `'JetBrains Mono', 'SF Mono', Menlo, 'DejaVu Sans Mono', 'Ubuntu Mono',
  monospace`. Каталог данных замера `scripts/measure.mjs` по умолчанию - каталог данных Electron:
  `~/Library/Application Support/cyborg` на macOS, `$XDG_CONFIG_HOME/cyborg` либо `~/.config/cyborg` на остальных;
  `CYBORG_USERDATA` главнее. На macOS значок в Dock - `assets/icon.png`: `icon` окна там не действует.
- **traced from:** BR-5001.
- **источник:** Issue #2, раздел «Что сделать» (шрифты, `scripts/measure.mjs`).
- **rationale:** reason - в списке не было шрифтов macOS, замер искал данные там, где их нет;
  assumptions - имя приложения `cyborg` (проверено `app.getName()`); relationships - нет; design constraints - нет.
- **verification:** демонстрация - `app.getName()` и `app.getPath('appData')` в собранном приложении; значок Dock - вызов `app.dock.setIcon` без ошибки, файл 512x512 загружается (сам значок в Dock не просматривался);
  `node scripts/measure.mjs` называет путь macOS.
- **класс:** Functions. **origin:** source.

### FR-5005 Автоматическая проверка PR

- **Требование:** для каждого PR и пуша в `master` GitHub Actions на macOS и Linux выполняет `npm ci`, сборку,
  проверку типов, `npm test` и дымовой тест `scripts/smoke.mjs`; падение любого шага делает проверку красной.
  Дымовой тест запускает собранное приложение с временным каталогом данных, подставным `claude` и репозиторием-
  пробой и проверяет: окно открыто; дерево показывает git-статус; подсказки называют сочетание своей системы;
  сочетание своей системы открывает сессию, чужое нет; вывод pty доходит до терминала; событие хука с новым
  рабочим каталогом переводит дерево на worktree; колесо и сброс клавишей своей системы меняют размер шрифта; пути вне репозиториев и каталогов сессий отклоняются
  (FR-1027); кнопка «Задачи» открывает и закрывает панель, у проекта без источников кнопок нет (FR-1001); бросок файла вне
  зон отменён (FR-3005); приложение с работающей сессией завершается по SIGTERM за 5 с.
  Версии экшенов закреплены по SHA коммита, их обновляет Dependabot; отдельная проверка `CI` сводит результат матрицы в
  одно имя для защиты ветки (D-09).
- **traced from:** BR-5001.
- **источник:** запрос оператора «тестировать автоматически при создании PR»; D-09.
- **rationale:** reason - у проекта не было CI, а регресс на macOS (красные тесты, клавиши) ловился только руками;
  assumptions - на macOS-раннере GitHub есть сессия WindowServer для окна Electron, на Linux хватает `xvfb`;
  relationships - FR-5001..5004; design constraints - без новых npm-зависимостей: DevTools Protocol поверх
  встроенных `fetch` и `WebSocket` Node 24.
- **verification:** испытание - `test/launcher.test.ts` (скрипт запуска: бит исполнения, `sh -n`, отказ при Node
  старше 24, переход к npm при Node 24); демонстрация - `node scripts/smoke.mjs` на macOS проходит за 6 с и падает
  кодом 1 при сломанной клавише и при возвращённом подтверждении на любом закрытии окна (подвешивало SIGTERM); запуск workflow в GitHub - не выполнялся, нет прав на репозиторий.
- **класс:** Functions. **origin:** source; закрепление по SHA и дымовой тест через CDP - derived.

### FR-5006 Меню приложения и закрытие окна

- **Требование:** меню приложения не содержит перезагрузки интерфейса (Reload, Force Reload) и масштаба страницы (Zoom In,
  Zoom Out, Actual Size); остаются правка, окно, выход (на macOS меню приложения) и инструменты разработчика. Закрытие
  окна и пункт меню «Quit» (Cmd/Ctrl+Q), пока работает хотя бы одна сессия, показывают подтверждение с числом сессий;
  отказ оставляет окно и сессии как были, согласие завершает сессии и приложение. Выход, уже начатый сигналом SIGINT или
  SIGTERM либо ОС, подтверждения не спрашивает и завершает приложение (D-10).
- **traced from:** BR-5001.
- **источник:** прогон на macOS: перезагрузка интерфейса оставила две сессии без вкладок; D-10.
- **rationale:** reason - Reload из меню Electron по умолчанию терял вкладки живых сессий, а масштаб страницы
  конфликтовал с масштабом шрифта (FR-5002); assumptions - перезагрузка интерфейса оператору не нужна; relationships -
  закрытие вкладки спрашивает так же (`app.ts`); design constraints - ADR-0003: сессии живут в главном процессе.
- **verification:** испытание - `test/menu.test.ts` (нет ролей reload и zoom на darwin, linux, win32),
  `src/main/sessions.test.ts` (`count`); демонстрация - собранное приложение: меню без Reload и масштаба, закрытие окна
  и пункт «Quit» с одной сессией спрашивают, отказ оставляет окно и приложение, согласие завершает приложение и pty;
  SIGTERM и SIGINT с сессией завершают приложение за секунду без вопроса. Нативный диалог физически не нажимался:
  ответ подставлен в главном процессе.
- **класс:** Functions. **origin:** derived.

### FR-5007 Пути репозиториев проекта - физические

- **Требование:** путь репозитория проекта при загрузке приводится к физическому (без символьных ссылок); ссылка и её цель
  в одном проекте сливаются в один репозиторий; несуществующий путь остаётся как задан. Сессия, запущенная в
  репозитории с путём через ссылку, показывается как сессия этого репозитория, а не как ушедшая в worktree; смена ветки
  и история сессий находят репозиторий (D-11).
- **traced from:** BR-5001.
- **источник:** прогон на macOS: репозиторий через ссылку показывался как `rA-link ⎇ rA`; D-11.
- **rationale:** reason - git и Claude Code называют репозиторий физическим путём (на macOS `/tmp` и `/var` сами ссылки);
  assumptions - физический путь однозначен; relationships - ADR-0004 (projects.json); design constraints - один источник
  истины на загрузке, без сравнения путей в местах использования.
- **verification:** испытание - `test/stores.test.ts` («пути репозиториев»: ссылка, слияние дублей, несуществующий путь);
  демонстрация - собранное приложение с проектом через ссылку: вкладка `CC1 · rA`, дерево `rA`, смена ветки работает.
- **класс:** Functions. **origin:** derived.

### FR-5008 История сессий видит сессии worktree

- **Требование:** вкладка «Сессии» показывает интерактивные сессии репозитория проекта и сессий, ушедших в его worktree
  (`<репозиторий>/.claude/worktrees/<имя>`), продолжает и удаляет их. Журнал worktree лежит в каталоге
  `~/.claude/projects/<репозиторий>--claude-worktrees-<имя>`; продолжение - `claude --resume <id>` из каталога
  репозитория (D-12).
- **traced from:** BR-5001, BR-001.
- **источник:** прогон на настоящем Claude Code 2.1.310: две параллельные сессии ушли в worktree, вкладка показывала
  «Прошлых сессий нет»; D-12.
- **rationale:** reason - Cyborg изолирует параллельные сессии worktree, и без этих каталогов история не видела бы
  именно их; assumptions - имя каталога журнала worktree - `projectDirName` пути worktree; relationships - ADR-0003;
  design constraints - только чтение каталога журналов Claude Code и удаление выбранной сессии, как прежде.
- **verification:** испытание - `test/history.test.ts` («сессии worktree»: список, существование, удаление; красный без
  правки); демонстрация - две настоящие сессии: обе в списке, продолжение вернуло Claude в worktree, удаление стёрло
  журнал в каталоге worktree.
- **класс:** Functions. **origin:** derived.

### FR-5009 Проверка согласованности корпуса в CI

- **Требование:** `npm run check:corpus` (`scripts/check-corpus.ts`, без зависимостей) проверяет корпус `docs/` и завершается кодом 1 при любой находке:
  у файлов корпуса есть front matter со `status` `review` либо `approved`, датой и `feature` по каталогу; ADR нумеруются подряд, id совпадает с именем
  файла, есть раздел «Расхождения с текущим кодом»; номер единицы уникален и лежит в диапазоне своей фичи; у каждого FR и NFR есть `verification` с
  существующими файлами тестов и `traced from` с заведённым BR, а у каждого BR фичи есть требование на него; ссылки `FR-`, `NFR-`, `BR-`, `ADR-`
  заведены, `D-NN` есть в decision-log своей фичи либо названной («фичи NN»); ссылки `файл:строка` указывают на существующий файл и строку в его
  пределах; счётчики `.req_counter` равны последним номерам корпуса; матрица `docs/04-verification/verification-matrix.md` (`npm run corpus:matrix`)
  совпадает с SRS. Отдельное задание `corpus` в `ci.yml` запускает проверку на каждый PR и пуш в `master`; результат входит в проверку `CI`.
- **traced from:** BR-5001.
- **источник:** Issue #10 (проверка согласованности корпуса в CI); D-13.
- **rationale:** reason - корпус и код расходились незаметно (ADR-0002, ADR-0004, BRD); assumptions - D-13; relationships - FR-5005; design
  constraints - без новых зависимостей: Node 24 запускает TypeScript напрямую.
- **verification:** испытание - `test/check-corpus.test.ts` (согласованный корпус проходит; на каждое нарушение - находка; временные корпуса, а не реальный);
  демонстрация - `npm run check:corpus` на реальном корпусе: ошибок нет, при испорченном счётчике код 1.
- **класс:** Functions. **origin:** derived.
