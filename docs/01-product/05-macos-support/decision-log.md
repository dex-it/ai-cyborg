# decision-log фичи 05 - работа Cyborg на macOS

Решения и допущения прогона по Issue dex-it/ai-cyborg#2 (2026-10-26). Исход «открыто» - допущение, принятое за
постановщика без оператора; подтверждает либо меняет владелец продукта.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Команды приложения (новая сессия, сброс и шаг размера шрифта) - Cmd на macOS, Ctrl на остальных; чужой модификатор команду не вызывает: Ctrl+C в терминале macOS - прерывание | оба модификатора на всех системах: Ctrl+Shift+N и Ctrl+колесо на macOS конфликтуют с терминальным вводом и привычками платформы | Issue #2, критерий 3 | принято |
| D-02 | Копирование и вставка терминала на macOS - пункты Edit меню Electron (Cmd+C, Cmd+V), своего перехвата нет; Ctrl+Shift+C/V остаются вне macOS. Проверено: выделение двойным кликом и `webContents.copy()` кладут слово в буфер, `webContents.paste()` вставляет текст ровно один раз | свой перехват Cmd+C/V с `clipboard`: пункт меню обрабатывает то же нажатие вторым, вставка рискует задвоиться | прогон, проверка на собранном приложении | принято |
| D-03 | Платформа - поле `platform` моста preload (`process.platform`), без канала главного процесса; ADR-0002 п.3 расширен | `navigator.platform` и разбор user agent в интерфейсе: устаревший и косвенный источник | прогон, дизайн; ADR-0002 п.3, D-10 фичи 03 | принято |
| D-04 | После взвода наблюдателя журнал событий читается ещё раз на следующем витке цикла (`setImmediate`): kqueue взводится после текущего витка, запись между запуском pty и взводом событие не даёт и иначе остаётся непрочитанной | опрос журнала таймером: нагрузка и задержка; правка только теста: зазор остался бы в приложении | прогон, замер: запись сразу после `fs.watch` - 0 событий, после `setImmediate` - 1 | принято |
| D-05 | Тест подмодуля с путём не в UTF-8 пропускается только когда файловая система отвергает такие имена (`EILSEQ`, APFS), причина в сообщении пропуска | удалить тест; пропускать по платформе: ФС на macOS бывают разные | прогон; запрет безосновательных пропусков | принято |
| D-06 | Скрипт запуска - `sh` без GNU-утилит, Node 24 и новее, зависимости при смене `package-lock.json`, `--no-sandbox` на Linux только без setuid `chrome-sandbox` и без user namespaces. Linux-ветка на этой машине не прогонялась | bash и `readlink -f`: на macOS нет в старых системах; всегда `--no-sandbox`: отключает песочницу без нужды | Issue #2, критерий 2; README | открыто: Linux-ветка не проверена |
| D-07 | Вне фичи: Option как Meta, запуск из Dock и Finder, упаковка, Windows, обновление зависимостей | Option как Meta: ломает ввод символов на нелатинских раскладках | Issue #2, раздел «Вне объёма» | принято |
| D-08 | Cmd+0 перехватывается интерфейсом (`preventDefault` в capture), как Ctrl+0 на Linux; на macOS у меню Electron есть пункт Actual Size с тем же сочетанием. Нажатие через меню не проверено: события CDP идут мимо меню, `osascript` без разрешения Accessibility | убрать пункты масштаба из меню: правка меню вне ТЗ | прогон | открыто: проверить Cmd+0 физической клавиатурой |
