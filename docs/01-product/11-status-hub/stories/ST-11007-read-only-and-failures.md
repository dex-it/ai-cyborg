# ST-11007 Только чтение, безопасность аргументов и отказы jira-cli

Как разработчик, я хочу, чтобы Jira читалась безопасно и без риска блокировки моей учётной записи.

## Acceptance Criteria

- **AC-1.** Дано: любые действия с Jira. Когда Cyborg вызывает `jira`. Тогда только `version`, `me`, `project list`, `issue list`, `issue view`, `open --no-browser`, аргументами массива, без записи в Jira, конфиг и токен `jira-cli` не читаются. [FR-11010]
- **AC-2.** Дано: ключ задачи или проекта не по форме либо не из последнего списка проекта. Когда он приходит от интерфейса. Тогда до `jira` он не доходит; адрес не `http`/`https` (`file:`, `javascript:`) отклонён. [FR-11010]
- **AC-3.** Дано: названия, описание, комментарии и ошибки с цветовыми и управляющими кодами. Когда они показываются. Тогда коды вычищены, текст рисуется через `textContent`; ответ ограничен 120 с и 64 МБ. [FR-11010]
- **AC-4.** Дано: нет бинаря, нет настройки, вход не принят, прочий отказ, таймаут, переполнение вывода, ответ не JSON. Когда карточка строится. Тогда у каждого своя причина одной строкой с командой исправления, интерфейс не падает. [FR-11011]
- **AC-5.** Дано: отказ входа. Когда проходит время и открывается карточка. Тогда `jira` не вызывается до «Обновить»; успешная проверка входа в диалоге проекта снимает остановку; отказ не по входу опрос не останавливает; «No result found» - не ошибка. [FR-11011]
- **AC-6.** Дано: выбрано несколько проектов Jira и неверный вход. Когда идёт серия запросов. Тогда сервер видит неверный вход один раз (первый список идёт один), а отказ входа по другому проекту после принятого первого - «нет прав на проект», назван под списком, опрос не останавливается. [FR-11011]
