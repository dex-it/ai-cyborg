# ST-11006 Сессия Claude Code по записи карточки

Как разработчик, я хочу одним действием запустить сессию по задаче Jira либо по MR, чтобы агент прочитал задачу, разобрал пайплайн, доработал замечания или провёл ревью.

## Acceptance Criteria

- **AC-1.** Дано: задача Jira с ключом `DEX-12`. Когда я нажимаю «Начать». Тогда открывается сессия, первое сообщение которой - «Задача Jira DEX-12: прочитай её (jira issue view DEX-12 --comments 5), разберись в постановке и предложи план работ. Код не правь, пока я не подтвержу план.»; название и описание задачи в сообщение не попадают. [FR-11008]
- **AC-2.** Дано: `session:create` с `{jira: {key}}`. Когда ключ не по форме `ABC-12` либо источников старта несколько. Тогда отказ. [FR-11008]
- **AC-3.** Дано: у задачи есть связанный MR, либо в проекте один репозиторий, либо несколько. Когда я нажимаю «Начать». Тогда сессия открывается в репозитории связанного MR, в единственном репозитории либо после меню выбора; у проекта без репозиториев кнопка недоступна, подсказка называет причину. [FR-11008]
- **AC-4.** Дано: сессия по задаче уже открыта. Когда я нажимаю «К сессии» либо дважды «Начать». Тогда возврат к открытой сессии, вторая не создаётся. [FR-11008]
- **AC-5.** Дано: свой MR с упавшим пайплайном. Когда я нажимаю «Разобрать пайплайн». Тогда сессия получает «Пайплайн MR <ссылка> упал: найди причину в логах упавших заданий, переключись на ветку MR и исправь её.». [FR-11009]
- **AC-6.** Дано: свой MR с замечаниями либо чужой MR. Когда я нажимаю «Доработать» либо «Ревью». Тогда сессия стартует с теми же сообщениями, что у вкладки «MR/PR». [FR-11009]
- **AC-7.** Дано: по MR открыта сессия. Когда карточка строится. Тогда вместо кнопок по причинам одна «К сессии»; без моего нажатия сессия не запускается. [FR-11009]
