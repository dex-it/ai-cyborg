# ST-11002 Индикатор и карточка статуса проекта

Как разработчик, я хочу одним взглядом на кнопку видеть худшее состояние проекта и по нажатию - карточку с тем, что требует внимания.

## Acceptance Criteria

- **AC-1.** Дано: у проекта включён хотя бы один источник (GitHub, GitLab либо Jira). Когда я смотрю на полосу сессий. Тогда есть кнопка «Статус» с цветной точкой и счётчиком; у проекта без источников кнопки нет, а открытая карточка при смене проекта закрывается. [FR-11002]
- **AC-2.** Дано: карточка закрыта. Когда я нажимаю кнопку. Тогда карточка открывается под ней и получает фокус; повторное нажатие, клик снаружи и Escape закрывают её; клик внутри, перерисовавший карточку, её не закрывает. [FR-11002]
- **AC-3.** Дано: у своего открытого MR пайплайн «упал». Когда данные получены. Тогда точка красная; замечания к своему MR либо чужой не-черновик на моём ревью - янтарная; пайплайн «идёт» или «ожидает» - синяя; ничего из перечисленного - зелёная; ни один источник кода не ответил - серая. [FR-11004]
- **AC-4.** Дано: у проекта есть красные, янтарные и ревью-записи. Когда считается счётчик. Тогда свой MR с упавшим пайплайном и замечаниями - одна запись, MR из обоих списков - один раз, от 100 - «99+»; закрытые, влитые и чужие черновики не считаются; задачи Jira уровень не поднимают. [FR-11004]
- **AC-5.** Дано: проект только с Jira. Когда список Jira получен. Тогда точка зелёная; список не получен - серая. [FR-11004]
- **AC-6.** Дано: проект выбран, карточка открыта. Когда проходит минута, нажимается «Обновить» либо проходит 5 минут при видимом окне. Тогда данные собираются заново (автор, затем рецензент, Jira параллельно); свёрнутое окно не опрашивается. [FR-11003]
- **AC-7.** Дано: один источник недоступен (нет входа, нет remote, нет ответа). Когда карточка строится. Тогда она называет причину, остальные источники показаны; данные прежнего проекта после смены проекта отбрасываются. [FR-11003]
