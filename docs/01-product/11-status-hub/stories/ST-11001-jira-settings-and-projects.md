# ST-11001 Jira в свойствах проекта и выбор проектов Jira

Как разработчик, я хочу включить Jira для проекта и выбрать нужные проекты Jira из списка, чтобы в карточке были задачи только оттуда, где я работаю.

## Acceptance Criteria

- **AC-1.** Дано: диалог свойств проекта, раздел «Источники задач». Когда я включаю галочку Jira. Тогда под ней виден итог проверки: «jira-cli не установлен», «не настроен», «не вошёл» либо «вход выполнен: <пользователь> (jira-cli <версия>)». [FR-11001]
- **AC-2.** Дано: Jira включена, вход принят. Когда я открываю блок «Проекты Jira». Тогда вижу выбранные ключи метками с «×» (нет выбора - «проект по умолчанию из jira init»), подсказки «В ветках репозиториев: KEY · N», поле поиска по ключу и названию и список проектов Jira с галочками. [FR-11012]
- **AC-3.** Дано: поле поиска. Когда я ввожу ключ по форме и нажимаю Enter. Тогда ключ добавляется, форма диалога не отправляется; при 10 выбранных введённое остаётся в поле и названа причина. [FR-11012]
- **AC-4.** Дано: ключ не по форме (с пробелом, начинается с цифры) либо больше 10 ключей. Когда сохраняется проект. Тогда сохранение отклоняется ошибкой, в файл ничего не пишется. [FR-11001]
- **AC-5.** Дано: файл без поля `jira`. Когда проект загружается. Тогда проект читается как «Jira выключена». [FR-11001]
- **AC-6.** Дано: выбраны два проекта Jira. Когда обновляется карточка. Тогда задачи запрашиваются отдельным вызовом на каждый проект, сливаются по давности без повторов (до 50, сверх - «+»); проект, по которому запрос не удался, назван под списком, по остальным задачи показаны. [FR-11012]
