# ST-11003 Мои задачи Jira и связанные с ними MR

Как разработчик, я хочу видеть назначенные на меня открытые задачи Jira рядом с их MR и пайплайнами.

## Acceptance Criteria

- **AC-1.** Дано: Jira включена, есть открытые задачи на мне. Когда открыта карточка. Тогда раздел «Jira · на мне: N» показывает их свежие первыми: ключ, название, статус, приоритет, давность и метки связанных MR с пайплайном (`#12 ✓`, `✕`, `…`). [FR-11005]
- **AC-2.** Дано: часть задач в категории «In Progress». Когда строится список. Тогда они в группе «В работе», остальные - в «Остальные открытые», пустая группа не показывается. [FR-11005]
- **AC-3.** Дано: ключ `DEX-1` и MR с `DEX-1` в названии либо ветке (регистр не важен), а также MR с `DEX-12` и `XDEX-1`. Когда задача связывается с MR. Тогда связан только первый: ключ ищется целым словом. [FR-11005]
- **AC-4.** Дано: задач нет либо источник ответил ошибкой. Когда карточка строится. Тогда «Открытых задач на вас нет.» либо причина ошибки. [FR-11005]
