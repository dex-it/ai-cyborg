# decision-log фичи 15 - MCP-сервер Cyborg и инструменты сессий

Решения по цели `mcp-session-tools` (2026-11-07): «Cyborg поднимает MCP-сервер, через который сессия Claude Code в вкладке Cyborg управляет другими вкладками своего проекта». Источник требований оператор не назвал; решения из описания сделанного в цели - исход «принято в цели», решения оператора - «принято оператором», выведенные из кода правки - «принято составителем» до подтверждения владельцем.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | MCP-сервер живёт в главном процессе Cyborg: Streamable HTTP на `127.0.0.1`, порт выдаёт ОС, `POST /mcp` с одним сообщением JSON-RPC (`initialize`, `ping`, `tools/list`, `tools/call`); поток SSE сервер не держит, `GET` получает 405 | поток SSE для запросов сервера к клиенту | сервер ничего не запрашивает у клиента; спецификация разрешает 405 на `GET` | принято в цели |
| D-02 | Каждая сессия получает свой Bearer-токен: конфиг `--mcp-config` лежит файлом 0600 рядом с файлом событий сессии, путь к нему - переменная `CYBORG_MCP`; при выходе сессии токен отзывается и файл удаляется, файлы убитого экземпляра убираются при старте, как файлы событий | токен в аргументе командной строки | командную строку процесса видят все пользователи машины, порт на `127.0.0.1` - тоже; вызывающую сессию называет только токен | принято в цели |
| D-03 | Запрос с заголовком `Origin` - 403, без токена либо с чужим и отозванным - 401 | проверка только токена | страница в браузере дотягивается до `127.0.0.1` и всегда шлёт `Origin`, клиент Claude Code его не шлёт | принято в цели |
| D-04 | `open_session` передаёт интерфейсу только одноразовый ключ, номер вызывающей сессии и каталог; промпт хранит главный процесс и отдаёт его `session:create` по ключу и совпавшему каталогу | промпт в событии интерфейсу и обратно в `session:create` | интерфейсу не доверяют (ADR-0002 п.5): текст модели дошёл бы до аргументов `claude` через недоверенный канал | принято составителем |
| D-05 | Новая вкладка открывается в фоне: активная вкладка остаётся активной; без активной вкладки новая становится активной | переключение на новую вкладку | вызывающая сессия и человек работают в своей вкладке, человек переключается сам | принято в цели |
| D-06 | Проект сессии для инструментов - набор её каталогов запуска: соседи - работающие сессии с тем же набором каталогов; `repo` у `open_session` - один из каталогов вызывающей сессии, перечень стоит в схеме инструмента | проект по данным интерфейса | главный процесс проектов сессий не знает; интерфейс при открытии вкладки сверяет каталог с проектом вызывающей вкладки | принято составителем |
| D-07 | `send_to_session` пишет только в сессию в состоянии `waiting`: вставкой (bracketed paste) и Enter отдельной записью через 150 мс; состояние перепроверяется перед вставкой и перед Enter, начавшийся ход отменяет Enter с ошибкой | запись в работающую сессию; текст и Enter одной записью | Enter в открытый запрос разрешения ответил бы на него «Да»; перевод строки в тексте без вставки TUI принял бы за Enter; пауза - как у кнопок команд (D-06 фичи 12) | принято в цели |
| D-08 | Работающей сессии сообщение ставится в очередь главного процесса и отдаётся по одному, когда сессия в `waiting` и 2 с нет её событий; сессии в `waiting`, у которой событие свежее 2 с либо очередь не пуста, сообщение тоже идёт в очередь | отказ работающей сессии; доставка сразу по `Stop` | чужой Stop-хук может продолжить ход; очередь не обгоняет саму себя | принято в цели |
| D-09 | `Stop` с `background_tasks` или `session_crons` оставляет сессию в `working` | `Stop` - всегда конец хода | сессия проснётся сама, ввод извне попал бы в её ход | принято в цели |
| D-10 | Отказы: `open_session` - пустой промпт, ведущие «-» и «!», больше 100 000 байт, каталог вне перечня; `send_to_session` - себе, сессии вне соседей, в `starting` и `asking`, ведущие «!», «/», «#», больше 100 000 байт; управляющие символы, кроме перевода строки и табуляции, вычищаются из сообщения. Промпт `open_session` может начинаться со слэш-команды | одни правила для обоих инструментов | «-» claude примет за ключ; «!» Claude Code выполнит как команду оболочки без запроса разрешения; «/» и «#» в чужой сессии правят её настройки и память в обход её разрешений; ESC закрыл бы вставку и пустил текст клавишами; предел - запас до 128 КиБ одного аргумента Linux (`MAX_ARG_STRLEN`); первое сообщение новой сессии - её собственное задание | принято в цели |
| D-11 | Подтверждения отправки `send_to_session` в интерфейсе Cyborg нет: человек подтверждает вызов инструмента запросом разрешения Claude Code в вызывающей сессии | окно подтверждения Cyborg перед отправкой | ответ оператора | принято оператором |
| D-12 | Остаточный риск принят: состояние сессии известно только по хукам, запрос разрешения может появиться раньше своего `Notification`; очередь живёт в памяти и пропадает с вкладкой и с выходом Cyborg | очередь на диске; распознавание запроса разрешения по выводу терминала | ответ оператора; разбор вывода отвергнут ADR-0003 | принято оператором |
| D-13 | `list_sessions` отдаёт хвост последнего ответа - 1500 последних знаков с «…» впереди, без комментария `cyborg-buttons` в конце | ответ целиком; начало ответа | итог работы обычно в конце ответа; комментарий кнопок служебный (фича 12) | принято в цели |
| D-14 | Интерфейс не открыл вкладку за 20 с либо окна нет - ошибка инструмента с причиной; отказ интерфейса (вкладки вызывающей сессии нет, каталог больше не в проекте, `session:create` отказал) возвращается модели текстом до 500 знаков | ожидание без предела | вызов инструмента не должен висеть, пока окно не отвечает | принято в цели (20 с), причины отказа - принято составителем |
| D-15 | Сервер не поднялся (порт не дан) - сессии работают без MCP Cyborg и без `--mcp-config`; сессии, запущенные до того, как сервер слушает, остаются без него | отказ запуска сессий | сессии создаёт окно, а оно грузится дольше, чем поднимается сервер; инструменты - добавка, без них сессия остаётся прежней | принято составителем |
| D-16 | Правки корпуса вне фичи, род - расширение области: BRD продукта (BR-009, разделы 3, 5, 9, 11, 17, заметка в шапке), ADR-0002 п.3 и п.5 (каналы `session:handoff`, `session:handoffFailed`, старт `{handoff}`), ADR-0003 п.7 и п.9 (`--mcp-config`, удаление конфига), FR-1015 (пишущие файлы) и FR-1017 (формы старта `session:create`) фичи 01; зависимые единицы найдены поиском по номерам и формам старта | новые единицы рядом с задетыми | один предмет - одна единица (unit-identity) | принято составителем |
