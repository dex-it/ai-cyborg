# SRS фичи 07 - смена ветки репозитория из дерева

## 1. SRS overview

Требования к меню веток и смене ветки. Вход - BRD фичи (`brd-feat.md`, BR-7001) и код `src/main/git.ts`,
`src/main/main.ts` (`git:switch`), `src/renderer/app.ts` (`showBranchMenu`). Основания решений - `decision-log.md` (D-NN).

## 2. Purpose

Задать наблюдаемое поведение меню веток и смены ветки так, чтобы правка проверялась по требованию, а не по коду.

## 3. Scope

Меню веток репозитория в дереве, канал `git:branches`, канал `git:switch`, функции `gitBranches`, `gitSwitch`.
Вне фичи: создание и удаление веток, коммиты, слияние (`brd-feat.md`, раздел 3).

## 4. Product perspective

Часть дерева сессии (фича `04-session-tree`): клик по метке ветки в строке корня открывает меню. Изменяет репозиторий единственной
командой (ADR-0011).

## 5. Product functions

Список веток; смена ветки; отказ при работающей сессии; отказ при конфиге, исполняющем команды.

## 6. User characteristics

`inherited`: BRD продукта, раздел 5.

## 7. Limitations

- Репозиторий меняется только командой `git switch` (ADR-0011, п.1).
- Новых зависимостей нет.

## 8. Assumptions and dependencies

- Нужен установленный `git`; допущения D-01..D-05 открыты до подтверждения владельцем.

## 9. Apportioning of requirements

Главный процесс: FR-7001 (список), FR-7002, FR-7003, FR-7004 (смена и отказы). Интерфейс: меню, поиск, показ отказа.

## 10. Specified requirements

## 12. Functions

### FR-7001 Список веток репозитория

- **Требование:** клик по метке ветки в строке корня дерева открывает меню: локальные ветки и ветки remote без локальной копии
  (с пометкой «только на сервере»): сначала локальные, затем только на сервере, внутри каждой группы свежие по дате коммита
  первыми; текущая отмечена «✓». Поле «Найти ветку» отбирает по подстроке
  имени без учёта регистра; показываются первые 200 совпавших; при отсутствии совпадений - «Нет веток». Каталог не репозиторий
  либо ошибка git - списки пусты. Канал `git:branches` принимает только репозиторий проекта.
- **traced from:** BR-7001.
- **источник:** код `gitBranches`, `showBranchMenu`; прогон на стенде 26.10.2026; D-01, D-05.
- **rationale:** reason - выбрать ветку, не помня её имени; assumptions - D-05; relationships - FR-7002; design constraints -
  ADR-0011, п.2.
- **verification:** испытание - `test/git-branch.test.ts` («локальные и только удалённые ветки»); осмотр - `--sort=-committerdate` в `gitBranches`, предел 200 в `showBranchMenu`;
  демонстрация - меню на стенде.
- **класс:** Functions. **origin:** derived.

### FR-7002 Смена ветки `git switch` по имени из списка

- **Требование:** выбор ветки (клик либо Enter на первой найденной) выполняет `git -c submodule.recurse=false switch <ветка>` в
  репозитории. Имя принимается, только если оно есть в списке веток и не начинается с `-`: иначе ошибка «Ветки <имя> нет», команда
  не запускается. Ветка remote заводит локальную с отслеживанием. Незакоммиченные правки переносит или отклоняет сам git: причина
  (первая строка после команды без префикса `error:`/`fatal:`) показывается в меню «Ветка не сменилась: …», ветка не меняется.
  Успех закрывает меню и перерисовывает дерево. Выбор текущей ветки ничего не делает.
- **traced from:** BR-7001.
- **источник:** код `gitSwitch`, `git:switch`; прогон на стенде (смена, отказ); D-02, D-06.
- **rationale:** reason - сменить ветку одним действием; assumptions - D-02; relationships - FR-7003, FR-7004; design constraints -
  ADR-0011, п.1-3, п.6.
- **verification:** испытание - `test/git-branch.test.ts` (смена, в том числе на ветку remote; `--orphan=x` - «Ветки … нет»; конфликт
  с правкой - отказ без префикса «Command failed»); осмотр - `submodule.recurse=false` в `src/main/git.ts`; демонстрация - смена на стенде.
- **класс:** Functions. **origin:** derived.

### FR-7003 Отказ при работающей сессии

- **Требование:** если репозиторий - рабочий либо дополнительный каталог работающей сессии Claude Code, `git:switch` отвечает
  `{error: 'в репозитории работает сессия Claude: веткой управляет она'}`, ветка не меняется. Сессия, ушедшая из каталога командой
  `cd`, репозиторий запуска не освобождает. Завершённая сессия репозиторий не держит.
- **traced from:** BR-7001.
- **источник:** код `SessionManager.uses`; прогон на стенде; D-03.
- **rationale:** reason - ветку под работающей сессией сессия узнаёт только после следующего хука; assumptions - D-03; relationships -
  ADR-0003 (хуки), FR-7002; design constraints - ADR-0011, п.5.
- **verification:** испытание - `src/main/sessions.test.ts` («каталоги работающих сессий…»: `uses` для рабочего и дополнительного
  каталога, после выхода - нет); демонстрация - отказ на стенде при работающей сессии. Ответ канала `git:switch` отдельным тестом
  не покрыт (обработчик в `main.ts`).
- **класс:** Functions. **origin:** derived.

### FR-7004 Отказ в репозитории с конфигом, исполняющим команды

- **Требование:** если в конфиге репозитория (области `local`, `worktree`) есть ключ `filter.*`, `extensions.partialclone` либо
  `remote.*.promisor`, смена отказывает ошибкой «в конфиге репозитория задан <ключ>: при смене ветки git запустил бы команду из него,
  переключите ветку в терминале»; `git switch` не запускается, команда из фильтра не выполняется. Ключи из пользовательского и
  системного конфига не считаются.
- **traced from:** BR-7001.
- **источник:** код `repoSwitchRisk`; ADR-0005, п.4 (тот же класс угроз для статуса); D-04.
- **rationale:** reason - чужой репозиторий задаёт драйвер фильтра, а выписывание файлов его запускает; assumptions - D-04;
  relationships - ADR-0005; design constraints - ADR-0011, п.4.
- **verification:** испытание - `test/git-branch.test.ts` (`filter.evil.smudge`: отказ с ключом, файл `pwned` не создан, ветка прежняя;
  `remote.origin.promisor` и `extensions.partialclone` - отказ с ключом).
- **класс:** Security. **origin:** derived.

### FR-7005 Меню выбора репозитория и ветки управляется с клавиатуры

- **Требование:** меню «Где запустить Claude Code» (и подобные «Где начать задачу», «Где открыть MR») и меню смены ветки объявлены `menu` с подписью, пункты - `menuitem` (ветки - `menuitemradio` с `aria-checked`).
  - Меню репозиториев при открытии переводит фокус на первый пункт, меню веток оставляет фокус в поле поиска; из поля `ArrowDown` уходит на первый пункт, `Enter` в поле по-прежнему выбирает первую найденную ветку (D-05).
  - Стрелки вверх и вниз (по кругу), `Home` и `End` переводят фокус по пунктам, `Enter` и пробел выбирают пункт. В порядке табуляции из меню один пункт. Сочетания с `Ctrl`, `Alt`, `Cmd` не перехватываются.
  - `Escape` закрывает меню и возвращает фокус на кнопку, открывшую его (если она ещё в окне); выбор пункта делает то же. Клик мимо закрывает меню без возврата фокуса.
- **traced from:** BR-7001.
- **источник:** осмотр интерфейса 2026-10-28: пункты меню были `div` с обработчиком клика, без фокуса и клавиш; D-07.
- **rationale:** reason - сессию в нужном репозитории и ветку нельзя было выбрать без мыши; assumptions - D-07; relationships - FR-7001, FR-7002, FR-1011, FR-2011; design constraints - нет.
- **verification:** испытание - `test/list-keys.test.ts` (`listTarget`, `rove`, `asMenuItem`, `bindList`); демонстрация - стрелки, `Escape` и возврат фокуса в меню репозиториев и меню веток в собранном приложении.
- **класс:** Functions. **origin:** source.
