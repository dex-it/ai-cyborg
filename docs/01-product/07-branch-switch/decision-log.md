# decision-log фичи 07 - смена ветки

Решения и допущения прогона по Issue #10 (2026-10-26). Исход «открыто» - допущение, принятое за постановщика без владельца
(рекомендации Issue #10, владелец поручил решать по качеству); подтверждает либо меняет владелец продукта.

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Смена ветки - принятая возможность продукта: non-goal BRD «переключение ветки» снят, граница - единственная команда `git switch` (ADR-0011); требования - в отдельной фиче 07 | убрать возможность из кода (README и сайт её описывают); описать её внутри фичи 01 (фича про задачи) | Issue #10, вопросы 1 и 4; прогон на стенде 26.10.2026 | открыто |
| D-02 | Меняется только на существующую ветку из списка, без создания, удаления и `--force`; ветка remote без локальной копии заводит локальную с отслеживанием | создание веток из меню: необратимые операции вне запроса; имя из поля ввода: имя в `git switch` без списка | код `gitSwitch`, тест смены ветки | открыто |
| D-03 | В репозитории, который является рабочим либо дополнительным каталогом работающей сессии, смена отказывает: веткой управляет сессия | менять ветку под сессией: сессия узнаёт о смене из своих хуков только после следующего действия | BRD продукта, раздел 3 («ветку MR переключает агент сессии»); прогон: отказ показан | открыто |
| D-04 | Репозиторий с `filter.*`, `extensions.partialclone`, `remote.*.promisor` не переключается, причина называет ключ и советует терминал | перекрывать ключи окружением, как для статуса (ADR-0005): для `switch` не проверено; переключать и доверять конфигу: исполнение команд из чужого конфига | ADR-0011, п.4; тест (`filter.evil.smudge`: файл не создан) | открыто |
| D-05 | Меню показывает первые 200 совпавших веток; Enter выбирает первую найденную | без предела: меню с тысячами строк | число выбрано прогоном (в постановке нет); код `showBranchMenu` | открыто |
| D-06 | Отказ смены - ответ `{error}` канала `git:switch`, а не исключение; текст виден в меню («Ветка не сменилась: …») | исключение: интерфейсу пришлось бы разбирать текст ошибки IPC | образец - `mrs:open` | принято |
| D-07 | Меню выбора репозитория и ветки - `menu` с пунктами `menuitem`, управление стрелками, `Enter`, `Escape` с возвратом фокуса на открывшую кнопку; фокус при открытии меню репозиториев - на первом пункте, меню веток - в поле поиска (D-05) | фокус на первом пункте и в меню веток: поиск по набору текста пропал бы; закрывать меню по `Tab` с фокусом наружу: решение зависит от выбора владельца, пока `Tab` проходит один пункт и выходит | осмотр интерфейса 2026-10-28; FR-7005 | открыто |
