# BRD фичи 18 - запуск файла из просмотра в системном терминале с предупреждением и одобрением

Источник: формулировка оператора (2026-11-15): «при клике на файл который можно запустить в терминале - предлагать запуск в терминале, предупредить об опасности запуска, если пользователь одобрит - сохранить одобрение и хэш файла, дальше додумай»; цель `run-file-in-terminal` с ответами оператора о месте кнопки, признаках запускаемости и виде терминала (D-01, D-02, D-04) и его команда о логин-оболочке (D-15). Допущения цели приняты оператором («по всем допущениям - ок»); решения составителя, выведенные из кода правки, - `decision-log.md`, исход «принято составителем» до подтверждения владельцем.

## 1. BRS overview

Разработчик видит в дереве сессии скрипт или собранную программу и, чтобы запустить её, уходит в свой терминал, находит каталог и набирает команду. Фича даёт в шапке просмотра файла кнопку «▶ Запустить в терминале»: файл запускается в окне системного терминала ОС, а первый запуск каждого содержимого проходит через предупреждение об опасности и сохраняемое одобрение. Адресована владельцу продукта и составителям SRS.

## 2. Business purpose

Разработчик запускает файл репозитория с того места, где его читает, и не запускает незаметно для себя содержимое, которого не одобрял: файлы репозитория меняют сессии Claude Code и чужие коммиты.

## 3. Business scope

Внутри границы: признак запускаемости файла (бит исполнения, shebang, расширение из таблицы) и кнопка в шапке просмотра - во вкладке локальной сессии и в просмотре без сессии, в том числе у файла, который просмотр не показывает; предупреждение с путём, командой и риском; одобрение по содержимому и команде, сохраняемое между запусками Cyborg; запуск в окне системного терминала на Linux и macOS в каталоге файла; отказы с названной причиной.

`non-goals`:

- вопрос о запуске на клик по строке дерева: клик открывает просмотр, как раньше (D-01);
- свой терминал внутри окна Cyborg; терминал, транскрипт и pty сессии Claude Code не меняются (D-04);
- удалённые сессии: кнопки и запуска нет, как у «Открыть в системе» (D-19);
- запуск по ссылке-пути из вывода сессии (D-19);
- аргументы и переменные окружения запуска, выбор интерпретатора человеком, настройка эмулятора в интерфейсе, список одобрений с отзывом в интерфейсе (D-19);
- Windows (D-19; BRD продукта, раздел 3: macOS и Linux);
- запуск при логин-оболочке не семейства sh: Cyborg отказывает и называет оболочку (D-15).

## 7. Mission, goals and objectives

### BR-18001 Файл из просмотра запускается в системном терминале, а неодобренное содержимое - только после предупреждения

- **Требование:** разработчик открывает из дерева файл, который можно запустить, и кнопкой в шапке просмотра запускает его в окне системного терминала в каталоге файла; перед первым запуском и после каждого изменения содержимого либо команды запуска Cyborg показывает путь, точную команду и предупреждение об опасности и запускает только по согласию; согласие запоминается для этого содержимого и этой команды. Если запуск невозможен, Cyborg называет причину, а не молчит.
- **traced from:** BR-011.
- **rationale:**
  - reason: запуск скрипта репозитория - частое действие рядом с чтением файла, а исполнение файла, изменённого сессией или чужим коммитом, без взгляда человека опасно;
  - assumptions: у разработчика есть эмулятор терминала из перечня либо заданный `$TERMINAL` на Linux, Terminal.app на macOS и логин-оболочка семейства sh (D-10, D-11, D-15);
  - relationships: BR-011 и сценарий 18 раздела 17 BRD продукта; BR-003 (просмотр файла); ADR-0021; ADR-0002;
  - design constraints: интерфейс показывает недоверенные данные и не решает, что и как запускать: путь, команду, хэш и одобрение ведёт главный процесс (ADR-0002, ADR-0021); терминал сессии не затрагивается (D-04).
- **MOE:** запускаемый файл стартует из просмотра в окне терминала без набора команды руками; файл, изменённый после одобрения, без нового согласия разработчика не исполняется; отказ запуска назван окном с причиной (качественная).

### Открытые вопросы
