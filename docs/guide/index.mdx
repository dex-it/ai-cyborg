## Что это

Когда параллельно идут три-четыре сессии `claude`, они расползаются по терминалам, а что каждая из них меняет в репозитории, приходится выяснять отдельно. Cyborg собирает их в одно окно: у каждой сессии рядом с терминалом видно её дерево файлов, ветку и git-изменения, файл открывается тут же. Задачи и MR из GitHub и GitLab лежат на соседней панели, и сессию можно начать прямо с них.

Claude Code при этом остаётся настоящим: Cyborg запускает обычный CLI `claude` в терминале и ничего в нём не подменяет. История сессий та же, что при запуске из консоли, и любую из них можно продолжить в любом месте.

:::note[Статус]
Ранняя версия. Приложение запускается из исходников, установщиков и подписанных сборок нет. Работает на macOS и Linux, проверяется в CI на обеих системах.
:::

## Быстрый старт

<Steps>

1. Установите Node.js 24, git и [Claude Code](https://docs.claude.com/en/docs/claude-code), войдите в `claude`.

2. Склонируйте репозиторий и запустите приложение:

   ```bash
   git clone https://github.com/dex-it/ai-cyborg.git
   cd ai-cyborg
   ./cyborg
   ```

3. Создайте проект: ⚙ → «Новый проект», добавьте репозитории, сохраните. Нажмите `+ CC`: сессия стартует.

</Steps>
