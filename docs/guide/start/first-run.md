## Проект

Проект - это набор локальных репозиториев под одним именем.

1. Нажмите ⋯ рядом с выбором проекта и выберите «Новый проект».
2. Задайте название, при желании описание.
3. «Добавить репозиторий…» - выберите каталог git-репозитория. Каталог не из git тоже можно добавить, но изменений в дереве не будет видно.
4. В разделе «Источники задач» включите GitHub и/или GitLab, если нужны задачи и MR. Рядом показано, выполнен ли вход в `gh` и `glab`.
5. «Сохранить».

Проекты хранятся в файле `projects.json` в каталоге данных приложения ([где он лежит](/concepts/data/)).

## Сессия

Нажмите «Новая сессия» (или `Ctrl+Shift+N`, на macOS `Cmd+Shift+N`). Если в проекте несколько репозиториев, Cyborg спросит, где запустить Claude Code: сессия стартует в выбранном, остальные подключаются к ней как дополнительные каталоги (`--add-dir`).

В первый раз в новом каталоге Claude Code спросит, доверяете ли вы папке. Это его собственный вопрос, ответьте в терминале сессии.

Слева у сессии своё дерево файлов: ветка, число изменений и git-статус файлов. Подробнее - в разделе [Возможности](/features/).

## Сессия по задаче

Если включён источник задач, наверху появится кнопка «Задачи». Откройте её, найдите задачу и нажмите «Начать»: Cyborg запустит сессию в репозитории, remote которого совпадает с задачей, и первым сообщением передаст ей ссылку на задачу. Заголовок сессии покажет номер, название и статус задачи.

См. [Задачи и MR](/features/tasks-mrs/).
