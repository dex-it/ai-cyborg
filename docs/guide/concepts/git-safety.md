---
title: "git только на чтение"
description: "Как защищены вызовы git над чужими репозиториями."
---

Cyborg читает состояние git вызовом установленного `git` без оболочки и меняет репозиторий единственным способом - `git switch` по вашей команде в дереве. Статус берётся в машиночитаемом формате, включая неотслеживаемые файлы, и совпадает с тем, что видит сама сессия в терминале.

## Конфиг репозитория не доверенный

Репозиторий проекта может быть чужим, а его `.git/config` способен запускать команды. Поэтому каждый вызов `git` идёт с отключёнными хуками и fsmonitor:

```text
git -c core.fsmonitor=false -c core.hooksPath=/dev/null -C <репозиторий> ...
```

`git status` запускает clean-фильтры файлов, а драйвер фильтра задаётся ключами конфига `filter.*`. Одним ключом фильтры не отключить, поэтому Cyborg собирает ключи фильтров репозитория и вложенных заполненных подмодулей и перекрывает их через окружение (`GIT_CONFIG_COUNT`). Фильтры из пользовательского и системного конфига доверенные и остаются.

Если ключи собрать нельзя - имя ключа или путь вложенного репозитория не в UTF-8, вложенность глубже восьми уровней, ошибка git, - статус не показывается вовсе. Неполный набор без перекрытия Cyborg не использует.

## Смена ветки

`git switch` по имени ветки из списка (имя не уходит в `git` опцией). Cyborg откажется переключать ветку, если при этом git мог бы выполнить команду из конфига репозитория: фильтры `filter.*` (выписывание файлов запускает smudge-фильтры) или partial clone (докачка объектов идёт транспортом из конфига). Подмодули `switch` не затрагивает.

Незакоммиченные правки git переносит сам либо отказывает; текст отказа показывается в меню ветки.
