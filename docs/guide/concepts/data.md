## Каталог данных приложения

| Платформа | Путь |
|---|---|
| macOS | `~/Library/Application Support/cyborg` |
| Linux | `~/.config/cyborg` |

| Файл | Что внутри |
|---|---|
| `projects.json` | Проекты: название, описание, репозитории, включённые источники задач, последний выбранный проект. Запись атомарна (временный файл и переименование). |
| `trackers.json` | Прежние общие настройки источников. Читается один раз для проектов без своего поля. |
| `claude-hooks.json` | Хуки сессий ([хуки](/concepts/hooks/)). Пишется при каждом запуске. |
| `sessions/` | Файлы событий работающих сессий. Каталог `0700`, файлы `0600`, удаляются с сессией. |

Пути репозиториев при загрузке проекта приводятся к физическим (без символьных ссылок): так их называют git и Claude Code.

Настройки интерфейса (размер шрифта, фильтры и сортировка панелей) хранятся в самом окне и переживают перезапуск.

## Чего Cyborg не хранит

- **Токены.** `gh` и `glab` работают под своим входом, Cyborg их не читает и не передаёт.
- **Содержимое сессий.** Журналы пишет Claude Code в `~/.claude/projects`; Cyborg их читает для списка истории и удаляет только ту сессию, которую вы выбрали.
- **Свой клиент модели.** Работает только локальный `claude`.

## Сеть

Единственные сетевые обращения Cyborg - запросы к трекерам через `gh` и `glab`, под вашим входом. Остальное (git, терминал, файлы) локально.
