## Тесты

`npm test` запускает два набора на встроенном `node:test`, без тестового фреймворка:

- модульные тесты рядом с кодом главного процесса (`src/main/*.test.ts`);
- тесты из `test/`: каждый файл собирается esbuild во временный каталог и запускается в Node. Electron и нативный модуль терминала в них подменяются, поэтому тесты идут без окна.

Покрыты хранилища, история и журнал сессий, фильтры git и смена ветки, трекеры и MR, панели в интерфейсе, платформенные сочетания клавиш, меню приложения, скрипт запуска.

На файловых системах, не допускающих имена не в UTF-8 (APFS), один тест пропускается с объяснением.

## Дымовой тест

`npm run smoke` запускает собранное приложение с временным каталогом данных, подставным `claude` и репозиторием-пробой и по DevTools Protocol проверяет:

- окно открывается, дерево показывает git-статус;
- подсказки называют сочетание своей системы;
- сочетание своей системы открывает сессию, чужое - нет;
- вывод pty доходит до терминала;
- событие хука с новым рабочим каталогом переводит дерево на worktree;
- колесо и сброс клавишей меняют размер шрифта;
- приложение с работающей сессией завершается по `SIGTERM`.

Нужен дисплей: на Linux запускайте под `xvfb-run`, `--no-sandbox` передаётся аргументом (`node scripts/smoke.mjs --no-sandbox`). Новых зависимостей тест не требует.

## CI

GitHub Actions (`.github/workflows/ci.yml`) на каждый PR и каждый пуш в `master`, на `macos-latest` и `ubuntu-latest`:

1. `npm ci` - та же установка, что делает `./cyborg`;
2. `npm run build`;
3. `npm run typecheck`;
4. `npm test`;
5. дымовой тест окна.

Отдельная проверка `CI` сводит результат матрицы в одно имя: его можно сделать обязательным в защите ветки. Экшены закреплены по SHA коммита, обновления присылает Dependabot.
