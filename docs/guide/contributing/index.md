## Окружение

Нужны Node.js 24, npm и git. Остальное ставит `npm install` (он же пересобирает нативный модуль терминала под Electron).

```bash
git clone https://github.com/dex-it/ai-cyborg.git
cd ai-cyborg
npm install
npm run build         # сборка в dist/
npm run typecheck     # проверка типов
npm test              # тесты (node --test)
npm run check:corpus  # согласованность корпуса docs/
npm run smoke         # дымовой тест окна (нужен дисплей)
npm start             # сборка и запуск
```

## Где что лежит

| Путь | Что |
|---|---|
| `src/main/` | Главный процесс: сессии, git и поиск, проекты и воркспейсы, трекеры, кнопки-команды, окно «Расширения»; точки входа `main.ts` и `preload.ts`. |
| `src/renderer/` | Интерфейс: проекты, полоса сессий, xterm, дерево, Monaco, панели, окна поиска и «Расширения»; точка входа `app.ts`. |
| `src/shared/` | Код, общий для главного процесса и интерфейса (запрос поиска, окно «Расширения»). |
| `test/`, `src/**/*.test.ts` | Тесты на встроенном `node:test`. |
| `scripts/` | Сборка (`build.mjs`), запуск тестов, дымовой тест, замер панели, проверка корпуса и матрица верификации (`check-corpus.ts`). |
| `site/`, `docs/guide/` | Этот сайт: проект Astro и его страницы. |
| `docs/` | Корпус: BRD продукта, требования по фичам, ADR. |

## Как вносить изменения

Работа идёт циклом «требования → разработка → фиксация истины»: изменение поведения сопровождается правкой корпуса в `docs/` (требование, решение, при необходимости ADR). Правила описаны в `CLAUDE.md` репозитория.

1. Создайте ветку от `master`.
2. Внесите изменение вместе с тестом: сборка, типы, `npm test` и `npm run check:corpus` должны проходить. Тест не отключается, ассерт не ослабляется.
3. Если меняется поведение, обновите корпус: `docs/01-product/<фича>/` и номера в `docs/.req_counter/`; после правки SRS пересоберите матрицу командой `npm run corpus:matrix`.
4. Откройте PR. CI проверит его на macOS и Linux ([тесты и CI](/contributing/tests-ci/)).

Новых npm-зависимостей по возможности не добавляйте: у проекта их мало, а тесты идут без тестового фреймворка.
