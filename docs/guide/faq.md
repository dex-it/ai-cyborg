## Не запускается или не находит инструменты

**`./cyborg`: нужен Node.js 24 или новее.** Скрипт проверяет версию до установки. Поставьте Node 24 (например, через `fnm` или `nvm`) и запустите снова.

**В сессии `claude: command not found`.** Cyborg запускает `$SHELL -lc 'exec claude ...'`, то есть в логин-шелле. Убедитесь, что `claude` лежит в `PATH` логин-шелла. На macOS zsh в логин-режиме читает `.zprofile`, но не `.zshrc`: если путь добавлен только в `.zshrc`, запускайте Cyborg из терминала, где он уже есть в `PATH`.

**На Linux окно не открывается, ошибка песочницы.** `./cyborg` добавит `--no-sandbox` сам, если нет ни setuid `chrome-sandbox`, ни user namespaces. Чтобы песочница работала, см. [Установка и запуск](/start/install/).

## Задачи и MR

**Кнопок «Задачи» и «MR/PR» нет.** Включите источник в свойствах проекта (⚙ → «Свойства проекта» → «Источники задач»).

**Написано «gh не установлен» или «gh не залогинен».** Установите [`gh`](https://cli.github.com/) и выполните `gh auth login`; то же для `glab`. Если запускали Cyborg не из терминала, `gh` может не быть в `PATH` процесса.

**Список задач пуст, хотя они есть.** По умолчанию включён фильтр «Назначено мне»: снимите его. Задачи берутся по remote репозиториев проекта, у репозитория без подходящего remote источника нет.

**У «Ревью» ничего не происходит в сессии.** Нужен плагин `dex-auto` в Claude Code ([требования](/start/requirements/)): без него команду `/dex-auto:auto` Claude не узнаёт.

## Дерево, ветки, история

**Дерево не обновляется.** Пока окно закрыто другими окнами, опрос git приостанавливается и возобновляется, как только окно снова видно. Пока работает сессия, дерево также обновляется по её событиям.

**Не получается сменить ветку.** Либо в репозитории работает сессия (веткой управляет она), либо конфиг репозитория мог бы запустить команду при смене (`filter.*`, partial clone), и Cyborg отказывается. Причина показана в меню ветки, ветку в этом случае переключите в терминале.

**На вкладке «Сессии» пусто.** Показываются только интерактивные сессии с заголовком в репозиториях проекта; фоновые запуски (`claude -p`, SDK) нет. Сессии, ушедшие в worktree, показываются тоже.

**Файл не открывается.** Просмотр читает только текстовые файлы до 5 МБ; двоичные и большие файлы Cyborg не показывает и пишет причину.
