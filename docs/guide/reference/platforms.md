| Проверено | Apple Silicon, Node 24, Electron 45 | CI на `ubuntu-latest` (под `xvfb`) |
| Запуск | `./cyborg` | `./cyborg` |

| Клавиши | `Cmd` | `Ctrl` |
| Песочница Chromium | не требует настройки | setuid `chrome-sandbox` или user namespaces, иначе `--no-sandbox` |
| Значок | значок приложения в Dock | значок окна |

## Что различается

| | macOS | Linux |
|---|---|---|
| Запуск файла из просмотра | Terminal.app через `osascript`; Cyborg ждёт `osascript` до 120 с и показывает его ошибку | Первый найденный эмулятор: `$TERMINAL`, `x-terminal-emulator`, `gnome-terminal`, `konsole`, `xfce4-terminal`, `kitty`, `alacritty`, `wezterm`, `foot`, `xterm`; ни одного - отказ с подсказкой про `TERMINAL` |
| Путь с обратной косой чертой при запуске файла | Не запускается | Запускается |
| Скрипт запуска исполняет | `/bin/sh` в окне Terminal.app | `$SHELL -lc`, без `SHELL` - `/bin/bash` |
| Копировать и вставить в терминале | `Cmd+C`, `Cmd+V` (пункты меню «Правка») | `Ctrl+Shift+C`, `Ctrl+Shift+V`; `Ctrl+C` - прерывание |
| Новая сессия, размер шрифта | `Cmd+Shift+N`, `Cmd+0`, `Cmd+колесо` | `Ctrl+Shift+N`, `Ctrl+0`, `Ctrl+колесо` |
| Найти файл | `Cmd+P` | `Ctrl+Shift+P`: `Ctrl+P` в терминале - клавиша оболочки |
| Меню приложения | Первым идёт «Cyborg»: «О программе», «Службы», «Скрыть», «Завершить Cyborg» | Нет меню «Cyborg»: «Выход» последним пунктом «Воркспейс», «О программе Cyborg» в «Справке» |
| Меню «Окно» | Ещё «Изменить масштаб окна» и «Все окна - на передний план» | «Свернуть» и «Закрыть окно» |
| Токен Claude для хостов на диске | Шифруется средствами системы, если шифрование доступно | Только при настоящей связке ключей; без неё токен живёт до выхода из Cyborg |
| Управляемые настройки Claude Code, которые читает окно «Расширения» | `/Library/Application Support/ClaudeCode` | `/etc/claude-code` |

Остальное поведение обеих платформ одинаково. Различия клавиш подробно - в [списке клавиш](/reference/hotkeys/), запуск файла - в разделе [Запуск файла из просмотра](/features/run-file/).

## macOS

- Запускайте `./cyborg` из терминала: так приложение наследует `PATH` с `gh`, `glab` и `claude`. При запуске не из терминала `PATH` скуден.
- Сессия стартует как `$SHELL -lc 'exec claude ...'`. Логин-шелл zsh читает `.zprofile`, но не `.zshrc`: если `claude` добавлен в `PATH` только в `.zshrc`, приложению, запущенному не из терминала, он не виден.
- Пути вроде `/tmp` и `/var` на macOS - символьные ссылки; Cyborg приводит пути репозиториев к физическим.
- Запуск файла открывает Terminal.app командой `osascript`: если система не разрешила Cyborg управлять Terminal, окно «Файл не запущен» покажет ответ `osascript`. Автотесты проверяют только состав аргументов `osascript`, настоящий Terminal.app они не запускают.
- Уведомления о ждущих сессиях показывает система; если разрешение на них снято, их не будет.
- Файловая система APFS не допускает имена файлов не в UTF-8; на проверки Cyborg это не влияет.

## Linux

См. [Установка и запуск](/start/install/): песочница Chromium и флаг `--no-sandbox`.

- Для запуска файла нужен эмулятор терминала. `PATH` и `TERMINAL` читаются из окружения самого Cyborg, а не из логин-оболочки: переменная, заданная только в файле настроек оболочки, Cyborg, запущенный из меню приложений, не видна. Запускайте `./cyborg` из терминала либо задайте `TERMINAL` там, откуда он стартует.
- Уведомлениям о ждущих сессиях нужен демон уведомлений: без него показа не будет.
- Токен Claude для хостов шифруется, только если у системы есть связка ключей. Без неё Cyborg держит токен до выхода и пишет об этом; на диск он не попадает.

## Windows

Не поддерживается и не проверялась.
