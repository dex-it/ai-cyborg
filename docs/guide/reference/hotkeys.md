| Действие | Linux | macOS |
|---|---|---|
| Новая сессия | `Ctrl+Shift+N` | `Cmd+Shift+N` |
| Размер шрифта терминала и файлов | `Ctrl+колесо` | `Cmd+колесо` |
| Размер шрифта по умолчанию (13) | `Ctrl+0` | `Cmd+0` |
| Копировать выделение в терминале | `Ctrl+Shift+C` | `Cmd+C` |
| Вставить в терминал | `Ctrl+Shift+V` | `Cmd+V` |
| Выйти | `Ctrl+Q` | `Cmd+Q` |
| Найти файл (меню «Поиск») | `Ctrl+Shift+P` | `Cmd+P` |
| Найти в файлах | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Найти в изменениях | `Ctrl+Shift+D` | `Cmd+Shift+D` |
| Расширения: магазины (меню «Расширения») | `Ctrl+Shift+X` | `Cmd+Shift+X` |
| Окружение: переменные для всех запускаемых процессов (меню «Воркспейс») | `Ctrl+Shift+E` | `Cmd+Shift+E` |
| Новая строка в промпте | `Shift+Enter` | `Shift+Enter` |
| Кнопки-команды: сочетания `F1`-`F12` задаёте вы в окне «Кнопок» | `F1`-`F12` | `F1`-`F12` (с `Fn`, если F-клавиши управляют яркостью и звуком) |
| Сохранить правку Markdown | `Ctrl+S` | `Cmd+S` |
| Закрыть диалог, окно поиска или «Расширения», карточку «Статус», меню | `Esc` | `Esc` |

Подсказка у кнопки «Новая сессия» и текст пустого экрана называют сочетание вашей системы. Свои сочетания кнопок-команд задаются в [редакторе кнопок](/features/commands/#сочетания-клавиш); `Esc` в редакторе кнопок и промптов при несохранённой правке спрашивает подтверждение.

Сочетание кнопки-команды (свои) срабатывает на видимой сессии, в том числе когда фокус в терминале, и не срабатывает, пока открыто окно (поиск, «Расширения», редактор) или фокус в поле ввода вне терминала. Для своих кнопок допустимы `Alt` или `Cmd` с буквой либо цифрой, `Ctrl+Shift` с буквой и F-клавиши `F1`-`F12`: `Ctrl` с одной буквой занят терминалом. Заняты приложением и не принимаются: на macOS `Cmd+Q`, `C`, `V`, `X`, `A`, `Z`, `W`, `M`, `H`, `0`, `Shift+Cmd+N`, `Shift+Cmd+Z`; на Linux `Ctrl+Shift+N`, `Ctrl+Shift+C`, `Ctrl+Shift+V`, `F11`.

## Вкладки с клавиатуры

Вкладки сессий, вкладки внутри сессии (Claude и файлы), «Файлы»/«Сессии» боковой панели, а также виды окна поиска и разделы окна «Расширения» работают без мыши. `Tab` входит в список вкладок на выбранной вкладке и выходит из списка; стрелки, `Home` и `End` переводят фокус на соседнюю вкладку, `Enter` или пробел выбирают её. Фокус сам вкладку не выбирает, поэтому перебор не переключает терминал на ходу.

## Меню и список сессий с клавиатуры

В меню выбора репозитория и ветки: стрелки вверх и вниз, `Home`, `End` переводят фокус по пунктам, `Enter` или пробел выбирают, `Escape` закрывает меню и возвращает фокус на кнопку, открывшую его. В меню веток фокус стоит в поле поиска: `Enter` выбирает первую найденную ветку, стрелка вниз переходит к списку. Во вкладке «Сессии» боковой панели те же стрелки идут по записям, `Enter` продолжает сессию, `Delete` удаляет её (или все выделенные) после подтверждения, `Escape` снимает выделение. Мышью записи выделяются щелчком с `Cmd` (macOS) или `Ctrl` (Linux), диапазон - щелчком с `Shift`; пока что-то выделено, обычный щелчок тоже выделяет, а не продолжает сессию.

## Дерево файлов с клавиатуры

Фокус в дерево ставит `Tab`: он попадает на выбранный файл, а если выбранного нет - на первую строку; следующий `Tab` выводит из дерева.

| Клавиша | Действие |
|---|---|
| `↓` / `↑` | Следующая / предыдущая видимая строка (по кругу не ходит) |
| `Home` / `End` | Первая / последняя строка |
| `→` | Свёрнутый каталог или репозиторий раскрыть; на раскрытом - перейти к первой вложенной строке |
| `←` | Раскрытый каталог или репозиторий свернуть; на свёрнутом каталоге и на файле - перейти к строке выше уровнем |
| `Enter` / пробел | То же, что клик: каталог раскрыть или свернуть, файл открыть |

Те же клавиши работают в списке окна «Расширения». Сочетания с `Ctrl`, `Alt` и `Cmd` дерево не перехватывает. Кнопка ветки в строке репозитория - обычная кнопка: до неё доходит `Tab` со строки репозитория, `Enter` на ней открывает список веток. Дерево перерисовывается при каждом раскрытии и смене git-статуса; фокус остаётся на строке с тем же путём, а если строка пропала, переходит к её родителю.

## Окно запуска файла

[Запуск файла из просмотра](/features/run-file/) открывает отдельное окно системного терминала. В нём действуют клавиши этого терминала, а не Cyborg:

| Клавиши | Действие |
|---|---|
| `Ctrl+C` | Прерывает файл, но не окно: видны код выхода (130) и приглашение. На macOS это тоже `Ctrl`, не `Cmd` |
| `Enter` | После завершения файла закрывает окно |

## Подробности

- Размер шрифта общий для терминала, просмотра файла и дерева, лежит в пределах 8-32 и запоминается между запусками.
- Один шаг размера - каждые 100 пикселей прокрутки: деление колеса мыши даёт ровно один шаг, а жест на тачпаде накапливается, поэтому размер растёт плавно, а не прыгает до предела.
- На macOS чужой модификатор не срабатывает: `Ctrl+Shift+N` там ничего не делает, а `Ctrl+C` в терминале остаётся прерыванием, как в любом терминале. На Linux, наоборот, `Cmd` (Meta) не используется.
- Копирование и вставка на macOS выполняют пункты меню «Правка», так что `Cmd+C` и `Cmd+V` работают, как в других приложениях. На Linux `Ctrl+C` остаётся прерыванием, а копирование и вставка - `Ctrl+Shift+C` и `Ctrl+Shift+V`. В вкладке [удалённой сессии](/features/remote/#буфер-обмена-и-вставка) правый клик вставляет из буфера окна, когда Claude включил режим мыши.
- `Shift+Enter` отправляет в Claude Code перевод строки (ESC+CR), а не отправку промпта.
- Выход при работающих сессиях спрашивает подтверждение ([сессии](/features/sessions/)).
- Голосовой ввод удалённой сессии (`/voice` Claude Code): запись микрофона Cyborg начинается только по пробелу, который вы нажали в терминале активной вкладки этой сессии (не раньше чем за 2 секунды до запроса), при окне в фокусе. Одна запись длится не дольше 180 секунд; потеря фокуса окном её завершает ([удалённые сессии](/features/remote/)).

## Меню приложения

В меню нет перезагрузки интерфейса и масштаба страницы: перезагрузка оставила бы работающие сессии без вкладок, а масштаб страницы конфликтует с размером шрифта. Разделы идут в порядке, привычном для системы; «Воркспейс» стоит на месте меню «Файл», отдельного «Файла» нет.

| | «Свойства проекта…» | | выбран проект |
| | «Кнопки…» | | всегда |
| | «Окружение…» | `Ctrl+Shift+E` | всегда |
| | «Хосты…» | | всегда |
| | «Выход» (только Linux, последним пунктом) | `Ctrl+Q` | |
