Кнопки «Задачи» и «MR/PR» на полосе сессий появляются, когда у проекта включён источник (GitHub и/или GitLab). Репозитории берутся по remote репозиториев проекта. Cyborg вызывает `gh` и `glab` под вашим входом и только читает: запросы на запись он не выполняет.

Обе вкладки показывают последний полученный список и обновляют его в фоне раз в 5 минут, пока окно Cyborg на виду. Повторное открытие вкладки список не перезагружает, если ему меньше 5 минут. **Обновить** запрашивает список сразу и заново проверяет вход в `gh` и `glab`; прежний список остаётся на экране, пока не придёт новый. Время списка - в подсказке у кнопки. Если фоновое обновление не удалось целиком (например, пропала сеть и ни один источник не ответил), прежний список остаётся на месте, а следующая попытка будет не раньше чем через 5 минут; если ответил хотя бы один источник, список обновляется, а ошибка другого видна в нём. При открытии вкладки и по «Обновить» ошибка показывается всегда. Если фоновое обновление не принесло пайплайн или апрувы MR, остаются прежние значения. Список, который не изменился, не перерисовывается, поэтому раскрытое описание и выделенный в нём текст остаются на месте.

## Возвращение к строке

«Начать», «К сессии», «Ревью» и «Доработать» помечают строку: она подсвечена слева полоской, пока вы не нажмёте действие в другой строке или не смените проект. Положение списка Cyborg запоминает для каждой вкладки отдельно: закрыли панель, посмотрели сессию, открыли снова, и список на том же месте.

У сессии, начатой по задаче или MR, в шапке дерева слева есть кнопка «К #12 в списке» («К !12» у MR GitLab). Она открывает панель на нужной вкладке, подсвечивает строку и прокручивает список к ней. Если строки нет в показанном списке (другой фильтр), подсветится, когда она появится. Список заново кнопка не загружает.

## Задачи

Список открытых задач проекта: номер, название, источник и репозиторий, состояние и дата обновления.

- **Назначено мне** - фильтр по исполнителю (по умолчанию включён).
- **Сортировка** - по обновлению, созданию или номеру.
- **Метки** - полоса с цветными метками репозитория; выбор метки оставляет только задачи с ней.
- Клик по строке раскрывает детали: автор, исполнители, даты, описание.
- Клик по номеру открывает задачу в браузере.
- **Начать** запускает сессию в репозитории, remote которого совпадает с задачей. Сессия получает ссылку на задачу первым сообщением и просьбу сменить статус задачи в трекере, когда агент приступит к работе. Заголовок сессии показывает номер, название и статус. Панель остаётся открытой: сессия появляется в полосе сессий, а у задачи кнопка меняется на «К сессии», так что можно начать несколько задач подряд. «К сессии» переключает на сессию.

## MR и PR

Вкладка «MR/PR» показывает открытые PR GitHub и MR GitLab тех же репозиториев.

- **Показать**: все, «Author: я», «Assignee: я», «Reviewer: я».
- В строке: номер, название, автор, ветки, пайплайн (успешен, нет пайплайна и т. д.) и число апрувов. Пайплайн и апрувы подгружаются по очереди: пока загрузка идёт, строка показывает «…», а если получить их не удалось - «—».
- **Ревью** - у чужого MR. Сессия получает `/dex-auto:auto review <ссылка>`; для этого нужен плагин `dex-auto` в Claude Code ([требования](/start/requirements/)).
- **Доработать** - у вашего MR. Сессия получает просьбу разобрать замечания к MR, переключиться на его ветку и доработать её.
- Сессия по MR открывается, не закрывая панель; если по MR уже идёт сессия, кнопка называется «К сессии» и переключает на неё.

:::note
Cyborg ничего не пишет в трекер: ни комментариев, ни статусов. Это делает агент внутри сессии.
:::
