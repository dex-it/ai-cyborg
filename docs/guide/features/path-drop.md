---
title: "Путь в промпт"
description: "Перетаскивание файла из дерева или файлового менеджера на терминал сессии."
---

Чтобы сослаться на файл в промпте, не нужно набирать путь: перетащите строку дерева или файл из файлового менеджера ОС на терминал сессии или на её вкладку «Claude». В промпт вставится абсолютный путь, как при вставке из буфера.

## Правила вставки

- Путь из букв, цифр и символов `_@%+=:,./-` вставляется как есть.
- Остальные (с пробелом, кириллицей, спецсимволами) - в одинарных кавычках, кавычка внутри записывается `'\''`. Например, `'/home/me/Мой файл.md'`.
- Несколько файлов склеиваются через пробел, после последнего пробел.
- Пути с управляющими символами не вставляются: в процесс сессии они отправили бы ввод.

## Границы

- Вставляется только текст пути; в сессию больше ничего не уходит.
- Бросок на завершённую сессию, мимо терминала или на другие части окна ничего не делает, окно остаётся на месте.
- Файл без пути на диске (например, перетащенный из браузера) пропускается.
- Строку дерева можно бросить только на терминал: собственный тип перетаскивания не даёт вставить путь в текстовые поля.
