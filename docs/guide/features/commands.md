Под терминалом каждой сессии есть полоса кнопок. Нажатие кнопки отправляет её текст в ту сессию, которая видна (Enter уходит отдельно, сразу за текстом); кнопка с пунктирной рамкой только вставляет текст, а Enter вы нажимаете сами. Cyborg сам ничего не отправляет: без вашего нажатия текст в сессию не уходит.

Встроенные кнопки:

| Кнопка | Что отправляет | Клавиша |
|---|---|---|
| Сливай | `сливай` и Enter | F1 |
| Сделай PR | `сделай PR` и Enter | F2 |
| Мердж | `смерджи PR <ссылка PR>` без Enter | F3 |
| Приберись | `приберись` и Enter | F4 |

У каждой кнопки есть описание: оно показывается в подсказке при наведении (в подсказке: сочетание клавиш, описание, текст кнопки).

Кнопки не блокируются, пока Claude работает: Claude Code сам ставит ввод в очередь. Cyborg не проверяет, пусто ли поле ввода: если там что-то набрано, текст кнопки допишется к нему. У завершившейся сессии кнопки недоступны.

## Свои кнопки

Меню **Воркспейс → Кнопки команд…** открывает в редакторе Monaco действующий набор: встроенные кнопки с описаниями и ваши. Это поле `commands` файла воркспейса; что записано в редакторе, то и сохранится в файле. Чтобы поменять текст встроенной кнопки, правьте её запись (`label` оставьте прежним); чтобы убрать кнопку, поставьте ей `"disabled": true`.

```json
[
  { "label": "Сливай", "text": "сливай", "submit": true, "hotkey": "Alt+S" },
  { "label": "Приберись", "text": "/cleanup-merged-branches", "description": "Убрать слитые ветки", "submit": true },
  { "label": "Мердж", "text": "смерджи PR {pr}", "submit": false },
  { "label": "Сделай PR", "text": "сделай PR", "disabled": true }
]
```

| Поле | Значение |
|---|---|
| `label` | Подпись кнопки, до 40 знаков. Кнопка с тем же `label` (регистр не важен) заменяет встроенную на её месте. |
| `text` | Фраза или слеш-команда скилла, одна строка до 2000 знаков. |
| `submit` | `true` - текст и Enter; `false` (по умолчанию) - только вставка. Для опасных действий оставьте `false`. |
| `hotkey` | Необязательное сочетание: `Alt+S`, `Ctrl+Shift+K`, `CmdOrCtrl+Shift+M`. |
| `description` | Необязательное описание, до 200 знаков в одну строку: что кнопка делает и когда нужна. Показывается в подсказке. |
| `disabled` | `true` - кнопка скрыта (так отключается и встроенная); её сочетание освобождается. |

«Сохранить» (или `Cmd/Ctrl+S`) проверяет текст: если в нём ошибка, диалог называет кнопку и поле, а файл не меняется. После записи полоса обновляется сама; правка файла в другом редакторе подхватывается, когда окно снова получает фокус. Кнопок может быть не больше 30. Запись кнопок не трогает проекты и остальные поля файла воркспейса.

Негодная кнопка в файле, правленном вручную, пропускается, а у полосы появляется «Кнопки: замечаний N»; список причин - в подсказке и в диалоге правки.

Файл воркспейса общий для команды, и версии Cyborg у людей могут отличаться. Старая версия называет `description` и `disabled` неизвестными полями кнопки, не скрывает отключённую встроенную кнопку и стирает поле `prompts`, когда сохраняет проекты. Если файл общий, обновите Cyborg у всех.

## Кнопки, которые предлагает модель

Часть действий ситуативна, и заранее кнопку под них не напишешь. Поэтому Cyborg добавляет к каждой сессии короткую инструкцию (к системному промту, рядом с инструкцией об изоляции): если после ответа понятны следующие шаги, Claude в самом конце ответа пишет комментарий вида

```text
<!-- cyborg-buttons: [{"label": "Написать тест", "text": "напиши тест на пустой массив для sum"}] -->
```

Когда шаги неочевидны, комментарий не пишется. Cyborg читает его из последнего сообщения хода (событие `Stop`) и показывает кнопки на полосе после заданных. Комментарий остаётся и в терминале: Cyborg вывод сессии не меняет, поэтому под ответом видны одна-три строки.

- **Чем отличаются.** Заданные вами кнопки нейтральные, предложенные моделью - голубоватые, со значком ✦ перед подписью; в подсказке написано «Предложено моделью» и показан текст. Рамка, как у остальных кнопок: пунктирная у той, что только вставляет текст, сплошная у той, что отправит его.
- **Enter - только если модель попросила и вы нажали.** По умолчанию предложенная кнопка вставляет текст в поле ввода: вы читаете его и нажимаете Enter сами. Если модель добавила `"submit": true` (реплику можно отправить без правки), кнопка отправит текст сразу; у такой кнопки сплошная рамка, а подсказка говорит «нажатие отправит текст с Enter». Ответ модели не считается доверенным: она могла прочитать файл с чужими указаниями, поэтому прочитайте подпись и текст в подсказке, прежде чем нажимать. Кнопка нажимается только вами.
- **Чего нет никогда.** Реплика, начинающаяся с «!», отбрасывается: Claude Code выполняет такой ввод как команду оболочки без запроса разрешения. Реплика с «/» (команда Claude Code) вставляется без Enter, даже если модель попросила `submit`. Символы направления текста и управляющие символы в подписи и тексте отвергают кнопку.
- **Что принимается.** Не больше двух кнопок, `label` до 40 знаков, `text` до 2000 знаков в одну строку, необязательные `submit` и `description`; сочетания клавиш и `disabled` из предложения не действуют. В `text` работают подстановки.
- **Сколько живут.** До вашего следующего запроса, до нового предложения или пока модель сама не продолжит работу либо не остановится на вопросе или запросе разрешения; между запусками они не сохраняются. Понравившуюся кнопку добавьте в набор сами (меню «Кнопки команд…»).

## Промпты кнопок запуска сессий

Кнопки «Ревью», «Доработать» и «CI» у MR (список MR и карточка «Статус»), «Взять в работу» у задачи GitHub и GitLab и запуск сессии по задаче Jira начинают сессию с первого сообщения. Его текст тоже настраивается: меню **Воркспейс → Промпты кнопок…** открывает в Monaco действующие тексты всех пяти промптов с описаниями. Это поле `prompts` файла воркспейса; что записано в редакторе, то и сохранится.

```json
{
  "mr.review": { "text": "/dex-auto:auto review {mr_url}", "description": "Кнопка «Ревью» у MR" },
  "jira.start": { "text": "Задача Jira {jira_key}: прочитай её и предложи план. Код не правь, пока я не подтвержу план." }
}
```

| Промпт | Кнопка | Подстановки |
|---|---|---|
| `mr.review` | «Ревью» | `{mr_url}` - ссылка на MR |
| `mr.rework` | «Доработать» | `{mr_url}` |
| `mr.ci` | «CI» | `{mr_url}` |
| `task.start` | «Взять в работу» у задачи GitHub и GitLab | `{task_url}` - ссылка на задачу, `{status_command}` - `gh issue edit` либо `glab issue update` |
| `jira.start` | сессия по задаче Jira | `{jira_key}` - ключ задачи |

Без записи в файле отправляется прежний встроенный текст. Подставляются только ссылка или ключ: название задачи или MR, ветки и автор - чужой текст, в промпт они не попадают, и подстановками стать не могут. Текст - одна строка до 2000 знаков и не начинается с «-» (первое сообщение передаётся программе аргументом, и дефис она приняла бы за параметр). Неизвестный промпт или подстановка (например, опечатка `{jira_kye}`) называются, и редактор не даст такое сохранить.

Если файл правили руками и запись негодна, сессия по этой кнопке не запустится: окно сообщения назовёт промпт и причину. Cyborg не подставит вместо вашего текста встроенный молча. Остальные кнопки это не затрагивает.

## Подстановки

В `text` работают три подстановки:

| Подстановка | Что подставляется |
|---|---|
| `{branch}` | Ветка git сессии в момент нажатия. |
| `{pr}` | Ссылка на PR/MR, с которого начата сессия; иначе ссылка на открытый PR/MR с этой веткой в репозиториях проекта. Ваш PR приоритетнее чужого; если подходящих несколько, Cyborg откажет и назовёт номера; PR из форка с той же веткой назначения (например, `main`) за PR ветки сессии не принимается. |
| `{task}` | Ключ задачи Jira либо ссылка на задачу трекера, из которых начата сессия. |

Нет значения (у ветки нет PR или их несколько, сессия начата не из задачи, в проекте не включены GitHub и GitLab) - текст не уходит, а у полосы на несколько секунд называется подстановка и причина. Ветка должна состоять из букв, цифр и знаков `. _ / -`: иначе Cyborg откажется подставлять её в запрос к модели.

## Сочетания клавиш

Сочетание кнопки видно в подсказке при наведении на неё. Сочетание нажимает кнопку видимой сессии. Нужен Alt (Option) либо Cmd, либо Ctrl вместе с Shift, либо F-клавиша, с модификаторами или без: чистый Ctrl с буквой - управляющие символы терминала (`Ctrl+C` и другие). На macOS F-клавиши по умолчанию управляют яркостью и звуком: для кнопок их нажимают с Fn либо включают «Использовать F1, F2 и т. д. как стандартные функциональные клавиши» в настройках клавиатуры. Сочетания, занятые приложением (`Cmd+Q`, `Cmd+C`, `Cmd+V`, `Cmd+Shift+N`, на Linux `Ctrl+Shift+N`, `Ctrl+Shift+C`, `Ctrl+Shift+V`, `F11`), и повтор сочетания у второй кнопки отвергаются: кнопка остаётся без сочетания. Файл воркспейса переносят между macOS и Linux, поэтому редактор не даст сохранить сочетание, которое не годится на другой системе (например, `CmdOrCtrl+K`: на Linux нужен Shift). Сочетание не срабатывает при вводе в поле, при открытом диалоге и под открытой панелью задач.

:::note
Редактор кнопок - единственное место, где Cyborg записывает файл: он меняет только поле `commands` файла воркспейса. Файлы репозиториев Cyborg по-прежнему не правит.
:::
