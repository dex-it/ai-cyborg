Под терминалом каждой сессии есть полоса кнопок. Нажатие кнопки отправляет её текст в ту сессию, которая видна (Enter уходит отдельно, сразу за текстом); кнопка с пунктирной рамкой только вставляет текст, а Enter вы нажимаете сами. Cyborg сам ничего не отправляет: без вашего нажатия текст в сессию не уходит.

Встроенные кнопки:

| Кнопка | Что отправляет |
|---|---|
| Сливай | `сливай` и Enter |
| Сделай PR | `сделай PR` и Enter |
| Мердж | `смерджи PR <ссылка PR>` без Enter |
| Приберись | `приберись` и Enter |

Кнопки не блокируются, пока Claude работает: Claude Code сам ставит ввод в очередь. Cyborg не проверяет, пусто ли поле ввода: если там что-то набрано, текст кнопки допишется к нему. У завершившейся сессии кнопки недоступны.

## Свои кнопки

Меню **Воркспейс → Кнопки команд…** открывает JSON в редакторе Monaco. Это поле `commands` файла воркспейса: массив кнопок, которые добавляются к встроенным.

```json
[
  { "label": "Сливай", "text": "сливай", "submit": true, "hotkey": "Alt+S" },
  { "label": "Приберись", "text": "/cleanup-merged-branches", "submit": true },
  { "label": "Мердж", "text": "смерджи PR {pr}", "submit": false }
]
```

| Поле | Значение |
|---|---|
| `label` | Подпись кнопки, до 40 знаков. Кнопка с тем же `label` (регистр не важен) заменяет встроенную на её месте. |
| `text` | Фраза или слеш-команда скилла, одна строка до 2000 знаков. |
| `submit` | `true` - текст и Enter; `false` (по умолчанию) - только вставка. Для опасных действий оставьте `false`. |
| `hotkey` | Необязательное сочетание: `Alt+S`, `Ctrl+Shift+K`, `CmdOrCtrl+Shift+M`. |

«Сохранить» (или `Cmd/Ctrl+S`) проверяет текст: если в нём ошибка, диалог называет кнопку и поле, а файл не меняется. После записи полоса обновляется сама; правка файла в другом редакторе подхватывается, когда окно снова получает фокус. Кнопок может быть не больше 30. Запись кнопок не трогает проекты и остальные поля файла воркспейса.

Негодная кнопка в файле, правленном вручную, пропускается, а у полосы появляется «Кнопки: замечаний N»; список причин - в подсказке и в диалоге правки.

## Подстановки

В `text` работают три подстановки:

| Подстановка | Что подставляется |
|---|---|
| `{branch}` | Ветка git сессии в момент нажатия. |
| `{pr}` | Ссылка на PR/MR, с которого начата сессия; иначе ссылка на открытый PR/MR с этой веткой в репозиториях проекта. Ваш PR приоритетнее чужого; если подходящих несколько, Cyborg откажет и назовёт номера; PR из форка с той же веткой назначения (например, `main`) за PR ветки сессии не принимается. |
| `{task}` | Ключ задачи Jira либо ссылка на задачу трекера, из которых начата сессия. |

Нет значения (у ветки нет PR или их несколько, сессия начата не из задачи, в проекте не включены GitHub и GitLab) - текст не уходит, а у полосы на несколько секунд называется подстановка и причина. Ветка должна состоять из букв, цифр и знаков `. _ / -`: иначе Cyborg откажется подставлять её в запрос к модели.

## Сочетания клавиш

Сочетание нажимает кнопку видимой сессии. Нужен Alt (Option) либо Cmd, либо Ctrl вместе с Shift: чистый Ctrl с буквой - управляющие символы терминала (`Ctrl+C` и другие). Сочетания, занятые приложением (`Cmd+Q`, `Cmd+C`, `Cmd+V`, `Cmd+Shift+N`, на Linux `Ctrl+Shift+N`, `Ctrl+Shift+C`, `Ctrl+Shift+V`), и повтор сочетания у второй кнопки отвергаются: кнопка остаётся без сочетания. Файл воркспейса переносят между macOS и Linux, поэтому редактор не даст сохранить сочетание, которое не годится на другой системе (например, `CmdOrCtrl+K`: на Linux нужен Shift). Сочетание не срабатывает при вводе в поле, при открытом диалоге и под открытой панелью задач.

:::note
Редактор кнопок - единственное место, где Cyborg записывает файл: он меняет только поле `commands` файла воркспейса. Файлы репозиториев Cyborg по-прежнему не правит.
:::
