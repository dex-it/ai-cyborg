Окно «Расширения» показывает то, что Claude Code берёт для ваших сессий: магазины плагинов и их содержимое, установленные плагины, скиллы, команды и агентов, серверы MCP. Оно открывается из меню «Расширения» (пункты доступны, когда выбран проект) и закрывается `Esc`, кнопкой «Закрыть» или кликом по затемнению вокруг окна. Если открыта форма действия (установка, подключение), `Esc` сначала закрывает её. Выбранные вкладка, область и переключатели фильтра запоминаются между запусками.

| Пункт меню | Что открывает | macOS | Linux |
|---|---|---|---|
| «Магазины…» | вкладка «Магазины» | `Cmd+Shift+X` | `Ctrl+Shift+X` |
| «Установленные плагины и скиллы…» | вкладка «Установленные» | | |
| «Серверы MCP…» | вкладка «MCP» | | |
| «Хабы магазинов…» | вкладка «Хабы» | | |

## Область

Над списком переключатель области (на вкладке «Хабы» его нет: хабы не зависят от области). У каждой записи метка, откуда она.

| Область | Что показывает |
|---|---|
| «Сессия» | общее для вас, репозиторий активной сессии (и её рабочий каталог, если она в worktree), затем скиллы, команды, агенты и плагины репозиториев, которые подключены сессии через `--add-dir` (серверы MCP оттуда Claude Code не берёт). Появляется, пока есть сессия, и тогда выбрана сама. |
| «Проект» | общее для вас один раз и каждый репозиторий проекта своей группой. Без сессии выбрана сама. |
| «Везде» | только то, что действует во всех проектах и воркспейсах: настройки пользователя, организации и claude.ai. Другой воркспейс покажет то же самое. |

Метки: «везде» (для вас во всех проектах), «проект» (в `.claude/settings.json` или `.mcp.json` репозитория, это попадает в коммит), «локально» (только для вас в этом репозитории), «организация», «claude.ai», «плагин», «на сессию» (действует только на время сессии).

## Магазины

Подключённые магазины с источником и датой обновления; в магазине плагины, в плагине скиллы, команды и агенты (`/плагин:скилл`). У плагинов, чьи исходники лежат не в клоне магазина (у большинства плагинов официального магазина), состав виден только после установки; показаны имя и описание. Магазин, который назвал в настройках репозиторий, но вы ещё не подключили, показан с пометкой и кнопкой «Подключить».

**Установить…** у плагина: окно спрашивает область и репозиторий. «Везде» - для вас во всех проектах; «Локально» - только для вас в этом репозитории, репозиторий не меняется (предлагается по умолчанию в проекте и сессии); «Проект» - запись в `.claude/settings.json` репозитория, она попадёт в коммит. Плагин запускает программы с вашими правами, ставьте те, которым доверяете. Запущенные сессии подхватят плагин после `/reload-plugins`, новые - сразу. Магазин, который требует выполнить свою команду установки, откажет: подтвердите такую установку в терминале.

**Отключить…** у магазина убирает его и все установленные из него плагины; форма называет их.

**Подключить магазин…** принимает `владелец/репозиторий` GitHub, https-адрес, `git@хост:путь` или абсолютный путь и область, как у установки.

**GitHub ↗** или **Открыть ↗** открывает страницу источника в браузере. Кнопка есть у магазина, у установленного плагина (ведёт на источник его магазина) и у записи хаба. Подпись «GitHub» у адресов `github.com`, `raw.githubusercontent.com`, `git@github.com:владелец/репо`, `ssh://git@github.com/владелец/репо` и `владелец/репо`: все они приводятся к `https://github.com/владелец/репо`. Другой https-адрес открывается как есть, подпись «Открыть». Источник - путь на диске или ssh-адрес не на GitHub - кнопки не получает: страницу по такому адресу не угадать. В браузер уходят только адреса `http` и `https`.

## Установленные

Плагины и отдельные скиллы, команды и агенты, сгруппированные по месту записи, с версией, областью и состоянием («выключен», «выключен в …», «ошибка»). **Удалить…** убирает плагин из той области, где он установлен. Плагины организации в окне не удаляются.

У плагина, скилла, команды и агента справа видно, сколько раз их вызывали ([статистика вызовов](#статистика-вызовов)).

## MCP

Серверы пользователя, репозитория (личные и из `.mcp.json` с состоянием «одобрен», «ждёт одобрения», «отключён»), организации и плагинов. Строка: имя, транспорт и программа либо адрес без пути. Ключи, заголовки и аргументы запуска в окне не показываются и не читаются.

**Проверить связь** запускает `claude mcp list` в каталоге области: программы серверов запускаются и ходят по сети, поэтому кнопка нажимается вами, а не при открытии окна. После проверки у серверов «подключён», «нужна авторизация» или «не подключился» с причиной, и появляются коннекторы claude.ai.

## Хабы

Хаб - список магазинов, в котором ищут магазин и откуда его подключают. Это понятие Cyborg, не Claude Code. Встроенные хабы включены, их можно отключить:

| Хаб | Что в нём |
|---|---|
| «Anthropic» | `claude-plugins-official` (его Claude Code добавляет сам), `claude-community` (сторонние плагины, присланные в Anthropic), `anthropic-agent-skills` и `knowledge-work-plugins`. |
| «DEX» | магазин команды DEX: `dex-it/ai-kit`. |
| «GitHub» | пример из восьми самых звёздных магазинов GitHub, в которых несколько плагинов (`wshobson/agents`, `ruvnet/ruflo`, `thedotmack/claude-mem`, `phuryn/pm-skills`, `microsoft/power-platform-skills` и другие). Список готовый, без сети; звёзды и число плагинов записаны на 2026-10-30. |
| «GitHub: поиск по теме» | репозитории с темой `claude-code-marketplace` (от 20 звёзд, без форков и архивных, по убыванию звёзд, первые 30). Каждый проверяется: берётся только тот, у кого есть `.claude-plugin/marketplace.json`, а имя и число плагинов читаются оттуда. Строка показывает звёзды. Список читается с GitHub без входа и держится 5 минут, «Обновить» читает заново; если GitHub ограничил запросы, окно скажет подождать. |

Магазины хаба GitHub не проверяет Anthropic: тема - слова автора репозитория. Читайте описание и состав, прежде чем ставить оттуда плагины (подключение магазина ничего не запускает, установка плагина запускает).

**Добавить хаб…** принимает название и https-адрес JSON-файла со списком магазинов, например для магазинов вашей команды:

```json
{
  "name": "Магазины команды",
  "marketplaces": [
    { "name": "team-plugins", "description": "Плагины команды", "source": { "source": "github", "repo": "acme/claude-plugins" } },
    { "name": "tools", "source": { "source": "git", "url": "https://git.example.com/tools/plugins.git" } }
  ]
}
```

Допустимы источники `github`, `git` и `url`; остальные записи отбрасываются, их число называется. Файл только читается (не больше 1 МиБ и 500 записей). У записи кнопка «Подключить…» открывает форму подключения с готовым адресом; подключённые магазины помечены. Свои хабы можно отключать, включать и удалять; своих хабов не больше 20, название до 60 знаков. Хабы общие для всех воркспейсов и хранятся в `hubs.json` ([данные](/concepts/data/)).

Веб-каталоги магазинов (claudemarketplaces.com, claudemarket.ai) в хабы не входят: списка магазинов для программ они не отдают, их можно открыть в браузере.

## Статистика вызовов

У плагина, его скилла, команды и агента, у отдельных скиллов, команд и агентов и у сервера MCP справа стоит «вызовов N · давность» (например, «вызовов 12 · 3 ч») либо «не вызывался»; подсказка называет число и время последнего вызова. На вкладке «Установленные» у плагина число суммарное по его составу и серверам MCP. На вкладке «Магазины» счёт есть у состава установленных плагинов; у плагинов, которые не установлены, его нет.

Считается по журналам сессий Claude Code `*.jsonl` в `~/.claude/projects` (или `CLAUDE_CONFIG_DIR/projects`), в том числе журналам субагентов. Журналы читаются все, а не только открытых проектов и воркспейса, поэтому счёт охватывает всё, что делалось на этом компьютере. В счёт идут:

- вызовы инструмента `Skill`: скиллы и команды;
- вызовы `Agent` (`Task`) с типом субагента: агенты;
- вызовы инструментов серверов MCP (`mcp__сервер__…`);
- слеш-команды, набранные вами в сессии.

Первый подсчёт идёт по всем журналам и на гигабайтах журналов занимает от нескольких секунд до десятков секунд; список при этом уже показан, а в строке состояния написано «Считаю вызовы по журналам сессий…». Результат хранится в кэше `extensions-usage.json` в [каталоге данных](/concepts/data/): по каждому журналу его размер, время изменения и счётчики, поэтому следующие подсчёты дочитывают только дописанное. Журналы только читаются.

Ограничения: повторы истории в возобновлённых и ответвлённых сессиях считаются дважды (порядка 2%), а журнал, который удалили, из счёта выпадает, и числа уменьшаются. Формат журналов Claude Code не гарантирует, поэтому при его смене счёт может перестать находить вызовы.

## Размер окна

В правом нижнем углу окна есть ручка. Потяните её мышью, и окно растёт или уменьшается. Окно стоит по центру, поэтому оно растёт в обе стороны сразу: правый край идёт за указателем, левый зеркально. Минимальный размер 520 на 320 пикселей, максимальный ограничен окном приложения. Размер запоминается в настройках воркспейса и при открытии подгоняется под окно приложения. Щелчок по ручке без сдвига размер не закрепляет: окно по-прежнему подстраивается под содержимое.

С клавиатуры: `Tab` до ручки, затем стрелки. Шаг 16 пикселей по каждому краю (`Shift` - 64), поэтому ширина меняется на 32 пикселя за нажатие (`Shift` - 128), а высота на 16 (`Shift` - 64). `Home` на ручке и двойной щелчок по ней возвращают размер по умолчанию и забывают запомненный.

## Фильтр

Поле над списком оставляет записи, у которых в имени или описании есть набранное, и раскрывает нужные ветки. «Aa» - учитывать регистр, «.*» - регулярное выражение.

## Что нужно

Claude Code в `PATH` вашего шелла (так же, как для сессий). Без него магазины и плагины не видны, скиллы и серверы из файлов остаются. Как окно обращается с настройками Claude Code - [«Расширения» в безопасности](/concepts/git-safety/#расширения).
