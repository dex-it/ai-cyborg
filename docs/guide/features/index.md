Cyborg ничего не заменяет в Claude Code: он запускает обычный `claude` в терминале и добавляет вокруг него то, чего в одной вкладке терминала не видно.

| | |
|---|---|
| [Сессии](/features/sessions/) | Сколько угодно сессий во вкладках, уведомление, когда сессия ждёт, история, продолжение и удаление. |
| [Делегирование](/features/delegation/) | Сессия поручает работу дочерним сессиям и получает их итог: инструменты MCP, метка родителя и цвет «семьи» на вкладках, плагин со скиллом `parallel-sessions`. |
| [Удалённые сессии по SSH](/features/remote/) | `claude` работает на хосте по SSH, окно остаётся здесь: сон и пробуждение, буфер обмена, голосовой ввод `/voice`, клоны на хосте. |
| [Дерево и просмотр файлов](/features/tree/) | Ветка, число изменений и git-статус у каждой сессии, просмотр файла и сравнение с HEAD, Markdown документом с правкой по кнопке, смена ветки. |
| [Запуск файла](/features/run-file/) | Скрипт из просмотра запускается в системном терминале после предупреждения; одобрение действует, пока не изменилось содержимое файла. |
| [Расширения](/features/extensions/) | Окно из меню «Расширения»: магазины плагинов и их плагины, установленные плагины и скиллы, серверы MCP по областям «Сессия», «Проект», «Везде»; установка и удаление плагинов, подключение магазинов, хабы магазинов, статистика вызовов, размер окна. |
| [Поиск](/features/search/) | Окно поиска из меню: файл по имени, строка по содержимому и по изменениям (добавленные и удалённые строки), подстрока, слово или регулярное выражение, переход к строке. |
| [Задачи и MR](/features/tasks-mrs/) | Задачи и MR из GitHub и GitLab, старт сессии по задаче, ревью и доработка MR. |
| [Статус проекта](/features/status/) | Кнопка со сводкой: упавшие пайплайны, замечания, ревью, задачи Jira с деталями и запуск сессии одним действием. |
| [Кнопки-команды](/features/commands/) | Полоса под терминалом: типовые фразы в сессию одним нажатием или сочетанием клавиш, подстановки ветки, PR и задачи, свой набор в файле воркспейса. |
| [Путь в промпт](/features/path-drop/) | Перетаскивание файла из дерева или файлового менеджера на терминал. |
| [Изоляция сессий](/features/isolation/) | Параллельные сессии в одних репозиториях работают каждая в своём worktree. |

## Чего Cyborg не делает

- Не редактирует файлы репозиториев: правит сессия или ваш редактор. Свои записи Cyborg ограничены: проекты и кнопки-команды в файле воркспейса, общие кнопки, промпты и хабы в каталоге данных ([что и куда пишется](/concepts/data/#что-cyborg-пишет)). В настройки Claude Code он пишет вызовом `claude plugin` из окна «Расширения» по вашему подтверждению (в области «Проект» это `.claude/settings.json` репозитория) и глобальный `CLAUDE.md`, когда вы сохраняете его из [редактора](/features/sessions/#инструкции-для-всех-сессий).
- Не коммитит и не пушит, в трекер, MR и Jira не пишет. Это делает агент сессии.
- Не запускает сессии сам: по пайплайну, задаче или MR сессию открывает только ваше нажатие. Дочерние сессии открывает другая сессия своим инструментом ([делегирование](/features/delegation/)), удалённые - вы сами из меню «▾» ([удалённые сессии](/features/remote/)).
- Не имеет своего клиента модели: работает обычный `claude` на этой машине либо, в [удалённой сессии](/features/remote/), на хосте SSH. Репозитории берёт локальные; на хост их `origin` клонирует сам хост.
