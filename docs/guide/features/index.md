Cyborg ничего не заменяет в Claude Code: он запускает обычный `claude` в терминале и добавляет вокруг него то, чего в одной вкладке терминала не видно.

## Чего Cyborg не делает

- Не редактирует файлы репозиториев: правит сессия или ваш редактор. Единственная запись - поле кнопок-команд в файле воркспейса из меню «Кнопки команд…».
- Не коммитит и не пушит, в трекер, MR и Jira не пишет. Это делает агент сессии.
- Не запускает сессии сам: по пайплайну, задаче или MR сессию открывает только ваше нажатие.
- Работает только с локальными репозиториями и локальным `claude`, без своего клиента модели.
