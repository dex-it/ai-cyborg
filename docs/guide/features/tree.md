## Дерево

У каждой сессии своё дерево. Корень показывает репозиторий, ветку и число изменений (`⎇ main ±3`). У файлов справа буква статуса: например `M` - изменён, `U` - новый, не отслеживаемый git. У каталога с изменениями внутри - точка.

- Статусы обновляются сами, пока сессия работает: по событиям Claude Code (каждый вызов инструмента) и по опросу `git status` раз в три секунды, пока окно видно. Правки вне сессии (из редактора, другим процессом) подхватываются тем же опросом.
- Каталог раскрывается кликом по нему; раскрытие у каждой сессии своё.
- Дерево управляется и с клавиатуры: `Tab` ставит фокус на выбранный файл (если выбранного нет - на первую строку), стрелки ходят по строкам, `Enter` раскрывает каталог или открывает файл. Все клавиши - в [списке клавиш](/reference/hotkeys/#дерево-файлов-с-клавиатуры). Фокус остаётся на своей строке, когда дерево обновляется.
- Поле «Найти файл» над деревом оставляет только файлы, в имени которых есть набранное, без учёта регистра. Ищется во всех репозиториях сессии, в том числе в свёрнутых и нераскрытых каталогах; файлы из `.gitignore` не входят. Найденное показано деревом: каталоги раскрыты, совпавшая часть имени подсвечена. Показываются первые 500 совпадений, ниже - сколько ещё; `Esc` очищает поле. Фильтр у каждой сессии свой.
- Если в проекте несколько репозиториев, остальные идут ниже и сворачиваются.
- Если сессия ушла в отдельный worktree, дерево переходит за ней, а подпись корня показывает `repo ⎇ имя-worktree`.

## Просмотр файла

Клик по файлу открывает его в Monaco рядом с терминалом, в той же вкладке сессии. Подсветка синтаксиса по расширению, только чтение: редактор ввода не принимает.

Если файл изменён относительно HEAD, открывается сравнение: слева версия из HEAD, справа рабочая. Двоичные файлы и файлы больше 5 МБ не открываются, сказано почему.

Размер шрифта терминала и просмотра общий: `Ctrl+колесо` и `Ctrl+0` (на macOS `Cmd`), диапазон 8-32, значение запоминается.

## Смена ветки

Клик по ветке в корне дерева открывает список веток с поиском: локальные первыми, ветки только на сервере с пометкой. Выбор выполняет `git switch`.

- Пока в репозитории работает сессия Claude, кнопки нет: веткой управляет сессия.
- Cyborg не переключит ветку, если конфиг репозитория мог бы запустить при этом команду (фильтры `filter.*`, докачка в partial clone). Причина показывается в меню, ветку в таком случае переключите в терминале.
