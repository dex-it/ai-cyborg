## Дерево

У каждой сессии своё дерево. Корень показывает репозиторий, ветку и число изменений (`⎇ main ±3`). У файлов справа буква статуса: `M` - изменён, `A` - добавлен в индекс, `D` - удалён (файл остаётся в дереве зачёркнутым), `R` - переименован, `U` - новый, не отслеживаемый git, `!` - конфликт слияния. У каталога с изменениями внутри - точка.

- Статусы обновляются сами, пока сессия работает: по событиям Claude Code (каждый вызов инструмента) и по опросу `git status` раз в три секунды, пока окно видно. Правки вне сессии (из редактора, другим процессом) подхватываются тем же опросом.
- Каталог раскрывается кликом по нему; раскрытие у каждой сессии своё.
- Дерево управляется и с клавиатуры: `Tab` ставит фокус на выбранный файл (если выбранного нет - на первую строку), стрелки ходят по строкам, `Enter` раскрывает каталог или открывает файл. Все клавиши - в [списке клавиш](/reference/hotkeys/#дерево-файлов-с-клавиатуры). Фокус остаётся на своей строке, когда дерево обновляется.
- Найти файл по имени, строку по содержимому или среди изменений можно окном поиска: меню «Поиск» (`Cmd+P` на macOS, `Ctrl+Shift+P` на Linux), подробности - в разделе [Поиск](/features/search/).
- Если в проекте несколько репозиториев, остальные идут ниже и сворачиваются.
- Без активной сессии (сессий ещё нет или все закрыты) в области дерева стоят репозитории проекта, а в шапке написано «нет активной сессии». Клик по файлу открывает просмотр на месте терминала, закрывается он крестиком. Ветку здесь сменить можно, пока в репозитории не работает сессия.
- Если сессия ушла в отдельный worktree, дерево переходит за ней, а подпись корня показывает `repo ⎇ имя-worktree`.

## Просмотр файла

Клик по файлу открывает его в Monaco рядом с терминалом, в той же вкладке сессии. Подсветка синтаксиса по расширению, только чтение: редактор ввода не принимает. Исключение - Markdown, о нём ниже.

Если файл изменён относительно HEAD, открывается сравнение в одной колонке: строки версии из HEAD и рабочей идут вперемешку, удалённые и добавленные помечены. Двоичные файлы и файлы больше 5 МБ не открываются, сказано почему.

### Markdown

Файл `.md` или `.markdown` открывается отрендеренным документом: заголовки, таблицы, списки задач, код, картинки из репозитория. Ссылка на сайт открывается в браузере системы, ссылка на файл репозитория - во вкладке рядом (`/docs/x.md` считается от корня дерева, `#L12` открывает исходник на строке), ссылка на заголовок прокручивает документ. Документ из репозитория недоверенный: скрипты, стили и формы из него вырезаются, а картинки из сети не загружаются, на их месте рамка с подписью.

Если документ изменён относительно HEAD, в шапке есть кнопка «Сравнение»: она показывает то же сравнение в одной колонке, что у прочих файлов, а кнопка «Документ» возвращает рендер. Выбранный вид держится, пока вкладка открыта.

Кнопка «Править» в шапке открывает исходник в редакторе. `Ctrl+S` (на macOS `Cmd+S`) или кнопка «Сохранить» записывает файл, «Готово» возвращает к документу или к сравнению, откуда начата правка. Пока правка не сохранена, в шапке написано «не сохранено», а у вкладки стоит точка.

- Если файл за время правки изменился на диске (его переписала сессия), сохранение спрашивает, перезаписать ли его. Отказ спрашивает, перечитать ли файл с диска; правка остаётся в редакторе, пока вы не согласитесь её потерять.
- Закрытие вкладки, сессии или просмотра с несохранённой правкой предлагает её сохранить. Закрытие окна, выход и смена воркспейса спрашивают, терять ли правку, и их можно отменить.
- Переход к строке из поиска открывает исходник в редакторе.
- Записать можно только существующий файл Markdown внутри репозиториев проекта и каталогов сессий: ни новый файл, ни ссылку на файл вне репозитория, ни файл в `.git` Cyborg не перепишет.

Размер шрифта терминала и просмотра общий: `Ctrl+колесо` и `Ctrl+0` (на macOS `Cmd`), диапазон 8-32, значение запоминается.

## Смена ветки

Клик по ветке в корне дерева открывает список веток с поиском: локальные первыми, ветки только на сервере с пометкой. Выбор выполняет `git switch`.

- В дереве сессии кнопки нет: веткой управляет сессия. В дереве без сессии кнопка есть, но смена ветки в репозитории, где работает сессия, откажет.
- Cyborg не переключит ветку, если конфиг репозитория мог бы запустить при этом команду (фильтры `filter.*`, докачка в partial clone). Причина показывается в меню, ветку в таком случае переключите в терминале.
