## Вкладки

Каждая сессия - вкладка вида `CC1 · repo`: номер, репозиторий, а когда сессия ушла в worktree, и его имя (`CC1 · repo ⎇ create-a-txt`). Цвет вкладки отличает сессии друг от друга. Новая сессия - кнопка `+ CC` или `Ctrl+Shift+N` (на macOS `Cmd+Shift+N`).

Внутри вкладки - терминал сессии (вкладка «Claude») и открытые файлы. Терминал - обычный xterm.js с настоящим процессом `claude` внутри.

## Завершение

- Закрытие вкладки работающей сессии спрашивает подтверждение: «Сессия Claude Code ещё работает. Завершить её?».
- Закрытие окна или выход (`Cmd+Q` / `Ctrl+Q`), пока идут сессии, тоже спрашивает, сколько сессий будет завершено. Выход по сигналу (`Ctrl+C` в терминале, где запущен `./cyborg`, `kill`) вопроса не задаёт.
- Если процесс `claude` завершился сам, терминал остаётся на месте с пометкой `[сессия завершена, код N]`.

## История

Вкладка «Сессии» внизу слева показывает прошлые сессии проекта: заголовок, репозиторий и сколько времени прошло. В список попадают интерактивные сессии, запущенные человеком (Cyborg или обычная консоль), у которых есть заголовок. Фоновые запуски `claude -p` и SDK не показываются.

- Клик по записи продолжает сессию: `claude --resume <id>` в репозитории сессии.
- Крестик удаляет журнал сессии вместе с каталогом её вывода инструментов. После этого продолжить её нельзя, Cyborg переспрашивает.

Cyborg только читает журналы Claude Code из `~/.claude/projects` и удаляет ту сессию, которую вы выбрали. История та же, что у `claude` в консоли, поэтому сессию можно продолжить и там, и там.

Сессии, ушедшие в worktree ([изоляция](/features/isolation/)), хранятся Claude Code в отдельных каталогах, и Cyborg показывает и их.
