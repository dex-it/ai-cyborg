# ADR-CH-0002 Манифест плагина в package.json, строгая схема, два диапазона совместимости, префикс experimental_

> Решение составителя по запросу владельца (2026-11-02), не согласовано; ждёт приёмки. Основано на [ресёрче](../../research/README.md): [bb](../../research/bb.md), [DeepSeek Harness](../../research/deepseek-harness.md), [сравнение](../../research/comparison.md). Устройство целиком - [SAD](../design/sad.md).

> Уточнён по [SAD2, 3.3-3.4](../design/sad2.md#33-версии-и-миграции), [ADR-CH-0010](ADR-CH-0010-contracts-instead-of-services.md) и [ADR-CH-0014](ADR-CH-0014-secrets-config-state.md). Решение «манифест известен ядру до запуска кода, строгая схема» в силе. Манифест получает поля `engines`, `provides` / `requires` / `optional` / `consumes`, `permissions` (вместо `capabilities`), `ui`, `config` и `state` (схема и версия), `lock`. Целое число `engines.api` заменено семантической версией API плагинов в `engines.cyborg` (`^1`) и семантическими версиями контрактов (две мажорные одновременно, `@deprecated` с журналом); версии данных - `migrate` до активации вместо «миграции рядом». Судьба префикса `experimental_` в SAD2 не описана и остаётся открытой до P1.

## Decision Drivers

- Ядро должно знать о плагине **до** запуска его кода: что он вносит, чего требует, какие права просит.
- Нужна предсказуемая совместимость: приложение меняется быстрее, чем стабилизируется API.
- Статическая проверка вклада (команды, сочетания) убирает класс ошибок D-27 фичи 12.

## Context

bb: блок `bb` в `package.json`, строгая схема (`plugin-manifest.ts`), `engines.bb` и `engines.bbPluginSdk`, префикс `experimental_` на каждом публичном члене и реестр `api_to_audit.md`. dsh: блок `dsh`, `engines.dsh`, исключения `acceptRisk`, `upgrade-guide` на каждое внешнее ломание, форматы данных версионируются отдельно ([bb 5.1](../../research/bb.md), [dsh 5](../../research/deepseek-harness.md)).

## Decision

1. Манифест - блок `cyborg` в `package.json` плагина (и встроенных, и сторонних). Схема **строгая**: лишние поля отклоняются. Поля: `id`, `title`, `engines.cyborg` (диапазон версий приложения), `engines.api` (целая версия API), `main`, `renderer`, `activation` (`startup` или `lazy`), `requires`, `provides`, `capabilities`, `contributes` (команды, меню, настройки), `storage.legacy`.
2. **Проверка до импорта кода**: схема, `engines`, наличие требуемых сервисов; сбой даёт статус `Invalid` с причиной, плагин не загружается.
3. **Версия API - целое число**, сверяется на старте интерфейсом и главным процессом; несовпадение - явная ошибка. Мажорное изменение API - новое число.
4. **Префикс `experimental_`** у каждого нового публичного члена API и запись в реестре аудита (`plugin-api/AUDIT.md`): пока член не стабилизирован, ломать его можно; убрать префикс - решение P5.
5. **Журнал ломающих изменений**: каждое внешне видимое ломание публичного API записывается в тот же день как `Change` и `Migration` (до 500 слов), не при выпуске.
6. **Данные версионируются отдельно** от приложения: версия формата в файле плагина; миграция «рядом» (новый файл, прежний не трогается); будущая версия открывается явной ошибкой, не повреждением.
7. **Декларативный `contributes`** читается ядром без запуска плагина.

## Consequences

- Positive: ядро строит меню, настройки, таблицу сочетаний и граф зависимостей до активации; конфликты сочетаний находятся при загрузке; несовместимый плагин не запускается.
- Negative: манифест - ещё одно, что нужно поддерживать; для встроенных плагинов формально избыточен.
- Risks: схема манифеста быстро разрастётся - держим её короткой и расширяем только через `experimental_`.

## Alternatives Considered

- **Отдельный `cyborg-plugin.json`.** Pros: не смешивается с npm. Cons: не совместим с будущим распространением через npm. Why rejected: блок в `package.json` не мешает и готов к P5.
- **Манифест как код (экспорт из `main`).** Cons: ядру нужно выполнить код, чтобы узнать вклад. Why rejected: ломает ленивую активацию и статические проверки.
- **Только semver на приложение без числа API.** Cons: мелкие правки приложения делали бы несовместимыми все плагины. Why rejected: целое число API проще и честнее.

## Расхождения с текущим кодом

Решение целевое: код приложения пока устроен иначе ([Cyborg сегодня](../../research/cyborg-today.md)). Расхождение снимается фазами [дорожной карты](../../05-plans/roadmap.md).
