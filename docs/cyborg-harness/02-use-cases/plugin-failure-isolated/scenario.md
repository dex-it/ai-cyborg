# Плагин зависает, приложение продолжает работать

- **Актор:** пользователь; мейнтейнер.
- **Цель:** зависание или падение одного плагина не мешает остальным; причина видна.
- **Предусловия:** в `config` заданы группы хостов: `builtin` (встроенные плагины) и `trackers` (`trackers`, `search`); открыта сессия с запущенным агентом.
- **Требования:** BR-CH-006; FR-CH-1005, FR-CH-1009, FR-CH-1010, FR-CH-1016, FR-CH-1017, FR-CH-1018, FR-CH-2005, NFR-CH-1002.

## Основной ход

1. Плагин `trackers` входит в бесконечный цикл при вызове; хост `trackers` перестаёт отвечать на проверки.
2. Сторож не получает ответа 15 секунд и перезапускает хост `trackers`; плагины хоста (`trackers`, `search`) активируются заново, запись о перезапуске идёт в журнал плагинов.
3. Пока хост перезапускается, хост `builtin`, окно, терминал и процессы агентов работают; панель задач и поиск показывают состояние «плагин недоступен» (сосед по хосту `search` страдает вместе с `trackers`: так устроена группировка, пользователь может развести их по разным хостам).
4. Плагины из других хостов, потребляющие контракт `trackers` (например, `projects` через `cyborg.project-settings`), узнают о пропаже и возврате поставщика через `ctx.contracts.onChange`.
5. Пользователь открывает «Плагины Cyborg»: у плагина запись о зависании и перезапуске, причина, группа хоста.
6. Если зависание повторяется 3 раза подряд, сторож выключает плагин с записью в журнале; в «Плагины Cyborg» состояние «выключен сторожем», пользователь может включить его вручную или вынести в отдельную группу `plugins.hosts`.

## Альтернативы

- **А1. Исключение при активации или в вызове.** Хост ловит его: отказывает только этот плагин, с записью в журнале; соседи по хосту, другие хосты и окно работают (FR-CH-1005). Кнопка плагина не появляется или показывает заглушку.
- **А2. Исключение при монтировании вида.** Вид скрыт, показана заглушка, соседние виды работают, сбой в журнале (FR-CH-2005).
- **А3. Не более 3 перезапусков хоста за 5 минут.** Что делает сторож за этим пределом, SAD2 не уточняет (предложение: хост не перезапускается, плагины хоста выключаются, запись в журнале; фиксируется в P1). Стартовые значения порогов подтверждаются тестом: прецедента перезапуска зависшего локального хоста нет (FR-CH-1018).
- **А4. Безопасный режим.** Флаг запуска выключает **все** плагины, окно открывается с управлением плагинами (FR-CH-1009).
- **А5. Падает pty-хост ядра.** Процессы pty теряются, плагины получают это как завершение; сторож перезапускает pty-хост; окно не замирает (FR-CH-1018).

## Постусловия

Приложение не завершилось, процессы агентов живы (кроме А5), состояние и причина доступны для диагностики в журнале плагинов.
