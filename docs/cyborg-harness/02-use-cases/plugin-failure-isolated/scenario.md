# Плагин падает, приложение продолжает работать

- **Актор:** пользователь; мейнтейнер.
- **Цель:** сбой одного плагина не мешает остальным; причина видна.
- **Требования:** BR-CH-006; FR-CH-1004, FR-CH-1005, FR-CH-1009, FR-CH-1010, FR-CH-2005, NFR-CH-1002.

## Основной ход

1. При запуске плагин `tasks` бросает исключение при активации.
2. Ядро переводит его в `Failed` с причиной, пишет в журнал `logs/plugins/tasks.log`, остальные плагины активируются.
3. Кнопка «Задачи» в полосе сессий не появляется или показывает заглушку «плагин не работает»; терминал, дерево, поиск работают.
4. Пользователь открывает «Плагины Cyborg»: у `tasks` состояние «ошибка», причина, кнопка «Перезапустить».
5. Плагины, которым нужен сервис `tasks`, показывают «ждёт сервис tasks».
6. Пользователь перезапускает плагин; при успехе зависимые плагины активируются автоматически (FR-CH-1007).

## Альтернативы

- **А1. Падение при монтировании слота.** Слот скрыт, показана заглушка, соседние слоты работают (FR-CH-2005).
- **А2. Повторяющийся сбой.** Повтор с задержкой до 60 с; безопасный режим (флаг запуска) отключает всё, кроме встроенных плагинов (FR-CH-1009).

## Постусловия

Приложение не завершилось; состояние и причина доступны для диагностики.
