# Установка стороннего плагина с проверкой прав (этап 2)

- **Актор:** пользователь.
- **Цель:** установить чужой плагин и понимать, что он сможет.
- **Предусловия:** включён второй этап изоляции доступа (повод: плагин от автора вне команды или каталог плагинов); на первом этапе установки нет, загружаются только плагины из поставки. Безопасный режим выключен. Источник плагина, подпись и хеш - открытый вопрос 8 SAD2.
- **Требования:** BR-CH-004, BR-CH-005; FR-CH-1002, FR-CH-1023, FR-CH-1024, FR-CH-1025, FR-CH-2012, FR-CH-2013, FR-CH-2022, FR-CH-2035.

## Основной ход

1. Пользователь выбирает плагин в «Плагины Cyborg» -> «Установить» (форма источника - по решению вопроса 8).
2. Ядро читает манифест, проверяет схему, `engines.cyborg` и граф контрактов до выполнения кода.
3. Окно согласия показывает название, версию, источник и права теми же строками, что «Плагины Cyborg»: например, «ходит на хост из настройки baseUrl: jira.company.com», «читает секреты `vault://kv/data/jira*`», у `process` и `pty` - «полный доступ через программу», у `ui.lock` - «может закрыть окно Cyborg».
4. Пользователь подтверждает (`allowed-once`); при отказе, отмене или отсутствии ответа установка не происходит.
5. Главная часть плагина запускается в своём процессе (Electron как Node, `--permission`); UI - в `<iframe>` с собственным origin `cyborg-plugin://<id>/` и CSP по умолчанию; каждый вызов `ctx.os` идёт через шлюз и проверяется по правам; сеть и окружение закрывает шлюз, а не флаг процесса.
6. Попытка выйти за права (запуск необъявленной программы, чтение вне области, запрос на другой хост) отклоняется `PermissionDenied` и записывается в журнал плагина; прямое чтение файла вне разрешённого каталога в процессе плагина даёт `ERR_ACCESS_DENIED`.

## Альтернативы

- **А1. Безопасный режим.** Плагин не загружается: безопасный режим выключает все плагины (FR-CH-1009).
- **А2. Права слишком широкие.** Пользователь отказывается; данные не затронуты.
- **А3. Новая версия расширяет права.** Требуется повторное согласие; конкретный механизм - открытый вопрос 8 SAD2 (в Chrome MV3 расширение выключается до согласия).
- **А4. Пользователь меняет в `config` хост из `config:baseUrl`.** Смена на новый хост требует подтверждения (FR-CH-2013).
- **А5. Широкий класс.** Плагин с `process` или `pty` честно показан как «полный доступ через программу»: окно согласия не обещает защиты от самой программы (FR-CH-2012).

## Постусловия

Права плагина зафиксированы; их можно отозвать, выключив плагин (его секреты стираются при удалении).
