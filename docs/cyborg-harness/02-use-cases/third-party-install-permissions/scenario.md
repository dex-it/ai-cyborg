# Установка стороннего плагина с проверкой прав

- **Актор:** пользователь.
- **Цель:** установить чужой плагин и понимать, что он сможет.
- **Предусловия:** сторонние плагины включены (после P4); безопасный режим выключен.
- **Требования:** BR-CH-004, BR-CH-005; FR-CH-1002, FR-CH-2012, FR-CH-2013.

## Основной ход

1. Пользователь выбирает папку плагина в «Плагины Cyborg» -> «Установить из папки».
2. Ядро читает манифест, проверяет схему и совместимость до выполнения кода.
3. Окно подтверждения показывает название, версию, источник и список прав (`process.run:gh`, `net:api.example.com`, `fs.read:project`...).
4. Пользователь подтверждает (`allowed-once` для установки); при отказе или отсутствии ответа установка не происходит.
5. Плагин запускается в отдельном процессе; каждый его вызов к ОС идёт через шлюз и проверяется по правам.
6. Попытка выйти за права (запуск необъявленной программы, чтение вне проекта) отклоняется и фиксируется в журнале плагина.

## Альтернативы

- **А1. Безопасный режим.** Плагин не загружается, статус «отключён безопасным режимом».
- **А2. Права слишком широкие.** Пользователь отказывается; данные не затронуты.

## Постусловия

Права плагина зафиксированы; их можно отозвать, отключив плагин.
