# Пользователь после обновления: всё работает как раньше

- **Актор:** разработчик, ведущий несколько сессий Claude Code.
- **Цель:** обновить Cyborg и продолжить работу, ничего не потеряв.
- **Предусловия:** есть воркспейс в старом формате `{projects, lastProjectId, commands}`, `commands.json`, `prompts.json`, `hubs.json`, `trackers.json`, прежние настройки окна (`localStorage`, ключи `cyborg.*`), есть история сессий Claude Code.
- **Требования:** BR-CH-002; FR-CH-1014, FR-CH-3001, FR-CH-3003, FR-CH-3006, FR-CH-3011, FR-CH-3012, FR-CH-2008.

## Основной ход

1. Пользователь запускает новую версию `./cyborg`; открывается последний воркспейс (воркспейс выбирается до загрузки любого плагина).
2. Ядро один раз переводит старый формат в `config` и `state`: проекты и репозитории - в раздел `projects`, настройки трекеров - в раздел `trackers`, кнопки-команды - в раздел `command-buttons`, `lastProjectId` - в `state`; файлы пользователя и ключи `localStorage` переезжают туда же. Ручных действий нет.
3. Те же проекты, кнопки, наборы, хабы и фильтры панелей; меню строятся из вкладов плагинов, пункты и сочетания те же; `Cmd/Ctrl+Shift+X` открывает окно «Расширения Claude Code» (единственное видимое изменение названия).
4. Новая сессия запускается плагином `agent-claude-code` тем же `claude` с теми же хуками; дерево, поиск, задачи, MR, статус, кнопки-команды работают как раньше.
5. Старые сессии видны в «Сессиях» (история) и продолжаются через `resume`.
6. В разделе «Плагины Cyborg» все встроенные плагины в состоянии «активен», в группе хоста `builtin`.

## Альтернативы

- **А1. Плагин не активировался.** Функция плагина недоступна, остальные работают, в разделе «Плагины Cyborg» причина; окно не падает (FR-CH-1005, FR-CH-1017).
- **А2. Раздел `config` или `state` новее плагина или не проходит схему.** Версия раздела выше версии плагина (плагин откатили) - плагин не активируется, раздел не трогается; ошибка схемы после ручной правки - отказ только этому плагину; в обоих случаях причина в журнале, остальные плагины работают (FR-CH-2008).
- **А3. Воркспейс уже открыт.** Второй запуск на тот же воркспейс отказывает сообщением «Воркспейс уже открыт» (FR-CH-1014).
- **А4. Откат на прежнюю версию.** Пока работает прежний код, он сохраняет неизвестные поля файла, поэтому новые поля не стираются (FR-CH-3010, NFR-CH-3001).
- **А5. Открытые вкладки сессий после перезапуска приложения.** Поднимаются только если владелец отменил non-goal основного корпуса (FR-CH-3014, режим `lazy` по умолчанию); иначе как сегодня - история и `resume` вручную.

## Постусловия

Данные пользователя перенесены без потерь; прежние каналы работают через прокладку до закрытия фазы (FR-CH-3003).
