# Пользователь после обновления: всё работает как раньше

- **Актор:** разработчик, ведущий несколько сессий Claude Code.
- **Цель:** обновить Cyborg и продолжить работу, ничего не заметив.
- **Предусловия:** открыт воркспейс, есть `commands.json`, `prompts.json`, `hubs.json`, прежние настройки окна, есть история сессий Claude Code.
- **Требования:** BR-CH-002; FR-CH-3001, FR-CH-3003, FR-CH-3006.

## Основной ход

1. Пользователь запускает новую версию `./cyborg`.
2. Открывается последний воркспейс; те же проекты, кнопки, наборы, хабы и фильтры панелей.
3. Те же меню и сочетания; в окне `Cmd/Ctrl+Shift+X` открывается окно «Расширения Claude Code» (единственное видимое изменение названия).
4. Новая сессия запускается тем же `claude` с теми же хуками; дерево, поиск, задачи, MR, статус, кнопки-команды работают как раньше.
5. Старые сессии видны в «Сессиях» и продолжаются.
6. В разделе «Плагины Cyborg» все встроенные плагины в состоянии «активен».

## Альтернативы

- **А1. Плагин не активировался.** Функция плагина недоступна, остальные работают, в разделе «Плагины Cyborg» причина; приложение не падает (FR-CH-1005).
- **А2. Файл будущей версии.** Явная ошибка с названием файла, данные не повреждаются (FR-CH-2008).

## Постусловия

Данные пользователя не изменены; прежние каналы работают (прокладка до закрытия фазы).
