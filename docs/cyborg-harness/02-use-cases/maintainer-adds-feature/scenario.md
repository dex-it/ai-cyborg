# Мейнтейнер добавляет функцию как плагин

- **Актор:** разработчик Cyborg.
- **Цель:** добавить новую возможность, не трогая общие файлы.
- **Требования:** BR-CH-001; FR-CH-1013, FR-CH-3002, FR-CH-3005.

## Основной ход

1. Мейнтейнер создаёт папку `src/plugins/<id>` с манифестом, `main/`, `renderer/`.
2. Описывает в манифесте команды, настройки, права и слоты; пишет код только против `plugin-api`.
3. Добавляет тесты через тестовый хост и строку матрицы паритета, если функция заменяет существующую.
4. CI проверяет храповик границ: нет импортов ядра из плагина и чужих внутренностей, число прямых обращений к `electron` и `fs` не выросло.
5. Правки `main.ts`, `preload.ts`, `app.ts`, `index.html`, `styles.css` не требуются (MOE BR-CH-001).
6. PR проходит тесты, дымовой тест и `check:corpus`; в корпусе заводятся требование и решение.

## Альтернативы

- **А1. Нужной точки расширения нет.** Решение записывается в ADR; восьмая точка вводится только так (NFR-CH-1003).
- **А2. Функция требует правки ядра.** Допустимо, если запись в ADR объясняет, почему это не плагин.

## Постусловия

Функция отключается без поломки остального приложения.
