# Подключение второго агента

- **Актор:** автор плагина агента; пользователь.
- **Цель:** запускать в Cyborg другой CLI-агент рядом с Claude Code.
- **Предусловия:** у агента есть CLI; есть хуки или файловые следы для событий; контракт `cyborg.agent` версионируется семантически, до его стабилизации второй поставщик обязателен (P3). Автор из команды: плагин попадает в поставку сборкой.
- **Требования:** BR-CH-003; FR-CH-2009, FR-CH-2003, FR-CH-1021, FR-CH-2024, FR-CH-2012.

## Основной ход

1. Автор создаёт обычный плагин-поставщик `cyborg.agent` (ядро о нём не знает): запуск CLI, адаптер событий из следов агента, продолжение сессии (`resume`), при желании история.
2. В манифесте объявляет `provides: cyborg.agent` и право `pty` на нужную программу (агент стартует через оболочку пользователя, поэтому она в списке).
3. Запускает процесс сам: `ctx.os.pty.spawn({ program, args, cwd, env, persist: true })`; процесс держит pty-хост ядра. Общий набор тестов контракта проходит с подставной программой.
4. Плагин `sessions` потребляет `cyborg.agent` (`many`): пользователь выбирает агента при создании сессии («Новая сессия»); `sessions` получает билет `pty.share()`, и вывод идёт в терминал напрямую.
5. События (смена каталога, активность, ожидание) приходят через `sessions.onChange`; дерево, уведомления и кнопки работают так же, как у Claude Code, если агент их излучает.

## Альтернативы

- **А1. У агента нет хуков.** Работают запуск, вывод и ввод; события, которых нет, не излучаются; уведомления «сессия ждёт» не показываются.
- **А2. CLI не найден.** Поставщик сообщает причину, пользователь её видит, сессия не создаётся.
- **А3. Два агента одновременно.** `sessions` потребляет `cyborg.agent` с кратностью `many`: оба поставщика доступны, отказа при загрузке нет, агента выбирает пользователь при создании сессии (FR-CH-1004).
- **А4. Агент от стороннего автора.** Это этап 2: плагин в отдельном процессе с `--permission`, право `pty` показано как «полный доступ через программу» ([сценарий установки](../third-party-install-permissions/scenario.md)).

## Постусловия

Ядро не менялось; Claude Code продолжает работать; процессы обоих агентов переживают перезапуск хоста ([сценарий](../terminal-survives-host-restart/scenario.md)).
