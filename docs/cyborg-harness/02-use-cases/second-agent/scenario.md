# Подключение второго агента

- **Актор:** автор провайдера агента; пользователь.
- **Цель:** запускать в Cyborg другой CLI-агент рядом с Claude Code.
- **Предусловия:** у агента есть CLI; есть хуки или файловые следы для событий; контракт провайдера стабилен как `experimental_`.
- **Требования:** BR-CH-003; FR-CH-2009, FR-CH-2003.

## Основной ход

1. Автор создаёт плагин-провайдер: `handshake` (найден ли CLI, версия), `launch` (программа, аргументы, окружение), `attach` (события из следов агента).
2. Объявляет `capabilities` провайдера: умеет ли продолжать сессию, историю, дополнительные каталоги, хуки.
3. Общий набор тестов провайдера проходит с подставной программой.
4. Пользователь выбирает провайдера при создании сессии («Новая сессия»); ядро запускает pty по `LaunchSpec`.
5. События `session.cwd`, `session.activity`, `session.waiting` приходят от адаптера; дерево, уведомления и кнопки работают так же, как у Claude Code, если провайдер их излучает.

## Альтернативы

- **А1. У агента нет хуков.** Работают запуск, вывод и ввод; события, которых нет, помечены как недоступные; уведомления «сессия ждёт» не показываются.
- **А2. CLI не найден.** `handshake` сообщает факт, пользователь видит причину, сессия не создаётся.

## Постусловия

Ядро не менялось; Claude Code продолжает работать.
