# BRD фичи 02 - точки расширения и провайдеры

Источник: запрос владельца (2026-11-02), [ресёрч](../../research/comparison.md). Родитель - [BRD продукта](../brd.md): BR-CH-001, BR-CH-003, BR-CH-004, BR-CH-005.

## 1. BRS overview

Плагин полезен ровно настолько, насколько ему есть куда подключиться. Образцы показали две крайности: у bb контракты интерфейса на 6000 строк и сотни `experimental_`-членов, у dsh 108 классифицированных сервисов. Нам нужен узкий набор точек, который закрывает все нынешние функции и два заменяемых вида возможностей (агент, трекер), и при этом выдерживает недоверенный код.

## 2. Business purpose

Дать семь точек расширения с понятными контрактами, режимами событий и проверками, чтобы функции Cyborg и чужие плагины подключались одинаково, а другие агенты - без правок ядра.

## 3. Business scope

Внутри: реестр сервисов; события (observe, waterfall, guard); команды, сочетания, меню; слоты и сервис диалогов; шлюз IPC с пространствами имён, проверкой и прокладкой совместимости; настройки и хранилище; провайдер агента (pty-агент); провайдер трекера; уровни доверия, возможности, закрытые исходы подтверждений; изоляция L2.

`non-goals`:

- структурные провайдеры агента (SDK, ACP): отдельный вид контракта позже;
- хуки «ядро спрашивает плагин» с глобальным локом;
- общий глобальный React для плагинов;
- кроссплагинный доступ к внутренностям (только через сервисы).

## 4. Стороны и сценарии

Мейнтейнер, автор плагина, автор провайдера агента, пользователь. Сценарии: [второй агент](../../02-use-cases/second-agent/scenario.md), [установка стороннего плагина](../../02-use-cases/third-party-install-permissions/scenario.md), [мейнтейнер добавляет функцию](../../02-use-cases/maintainer-adds-feature/scenario.md).

## 5. Меры эффективности

| MOE | Значение |
|---|---|
| Все нынешние функции раскладываются на семь точек без обходов | 100% строк классификации SAD |
| Второй провайдер агента написан без правок ядра | 0 правок ядра |
| Каждая проверка прав L2 проходит через шлюз | 0 обходов в тестах отказов |
| Конфликт сочетаний находится при загрузке | 100% конфликтов (включая акселераторы меню) |
