# BRD фичи 01 - ядро и загрузчик плагинов

Источник: запрос владельца (2026-11-02) и [ресёрч](../../research/README.md). Родитель - [BRD продукта](../brd.md): BR-CH-001, BR-CH-005, BR-CH-006, BR-CH-007.

## 1. BRS overview

Чтобы функции могли жить плагинами, нужно ядро, которое находит плагин, проверяет его манифест и совместимость, разрешает зависимости, безопасно запускает и выгружает, показывает состояние и переживает его сбой. Образцы решили это по-разному: dsh - вендорным Cordis с процессом, где даже ядро - плагин; bb - SDK и серверной активацией с откатом и безопасным режимом. Мы делаем собственное минимальное ядро ([ADR-CH-0001](../../03-architecture/adr/ADR-CH-0001-core-and-plugins.md)).

## 2. Business purpose

Дать устойчивое основание для плагинов: предсказуемый жизненный цикл, видимый статус, безопасное поведение при сбое и понятный набор для автора.

## 3. Business scope

Внутри: манифест и его схема, проверка совместимости и API-версии, обнаружение, разрешение зависимостей (`requires`/`provides`), активация (в том числе ленивая) с тайм-боксом, откат регистраций при выгрузке, каскад зависимых, атомарная перезагрузка, безопасный режим, раздел «Плагины Cyborg», журнал плагина, флаг `--dump-plugins`, набор автора (шаблон, тестовый хост, проверка «только публичный API»).

`non-goals`:

- загрузка сторонних плагинов из сети и каталог (P5);
- изоляция процессом для L2 (фича 02, P4);
- перенос функций в плагины (фича 03).

## 4. Стороны и сценарии

Мейнтейнер, автор плагина, пользователь. Сценарии: [сбой плагина](../../02-use-cases/plugin-failure-isolated/scenario.md), [автор плагина](../../02-use-cases/author-writes-plugin/scenario.md), [мейнтейнер добавляет функцию](../../02-use-cases/maintainer-adds-feature/scenario.md).

## 5. Меры эффективности

| MOE | Значение |
|---|---|
| Сбой активации плагина не роняет приложение | 100% в тестах отказов |
| Состояние «ждёт сервис X» или «ошибка: причина» видно в интерфейсе и журнале | 100% плагинов |
| Выгрузка плагина оставляет 0 регистраций (HMR-safety тест реестра) | 100% реестров |
| Размер публичного API ядра | 7 точек, без роста без ADR |
| Добавление нового плагина-пилота (`path-drop`) не правит общих файлов | 0 общих файлов |
