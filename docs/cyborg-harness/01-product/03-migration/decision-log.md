# decision-log фичи 03 - миграция и паритет

Решения составителя по запросу владельца. Исход «открыто» - допущение, принятое за владельца. Записи D-09 и далее фиксируют решения [SAD2](../../03-architecture/design/sad2.md) и [ресёрча-2](../../research/sad2-validation.md); заменённые записи не удалены, а помечены в колонке «Исход».

| ID | Решение | Отвергнуто | Основание | Исход |
|---|---|---|---|---|
| D-01 | Миграция «душителем»: каркас в работающем коде, перенос по одной функции | «Большой взрыв»; параллельный новый продукт | ADR-CH-0006 | открыто |
| D-02 | Порядок: `path-drop`, `session-notifications`, `search`, `command-buttons`, `claude-extensions`, трекеры, `files`, `agent-claude-code`, оболочка | Начать с провайдера агента | Растущий риск; оболочка (`app.ts`) последней | **изменено: D-11** (принцип «по возрастанию риска» сохранён; пилот - `session-notifications`, `path-drop` отдельным плагином не будет; конкретный порядок - в дорожной карте) |
| D-03 | Старые каналы IPC живут через прокладку до конца фазы | Переименовать сразу | Условие «ничего не потерять» | открыто |
| D-04 | Паритет по записанным сессиям и подставным CLI с allowlist расхождений | Только существующие тесты | bb 5.6; тестов недостаточно для UI-уровня | открыто |
| D-05 | Допустимое изменение поведения - только переименование «Расширения Claude Code» (ADR-CH-0008) | Любые улучшения по ходу | Улучшения после паритета | открыто |
| D-06 | Бюджет: не хуже +10% | Без бюджета | Опыт образцов; NFR-CH-1001; база старта и памяти **не измерена** ([ресёрч-2, 5.1](../../research/sad2-validation.md#51-что-в-sad2-и-parity-plan-неверно-или-неточно)) | открыто |
| D-07 | Оболочка и терминал остаются в ядре | Вынести сайдбар и композер (как bb) | bb 10: высокий риск потери функций | **снято: заменено [D-11 фичи 01](../01-plugin-host/decision-log.md)** (ядро не знает сессий; терминал - документ плагина `sessions` в `<iframe>`; в ядре остаётся каркас по манифестам) |
| D-08 | Неисправленный дефект D-27 фичи 12 (сочетания и меню) закрывается единым реестром (FR-CH-2004, FR-CH-2029), не отдельным патчем | Отдельное исправление сейчас | Класс ошибок закрывается архитектурой; допустимо исправить раньше, если владелец решит | открыто |
| D-09 | Шаг 0 на текущем коде: `ProjectStore` сохраняет неизвестные поля, id сессии устойчивый | Параллельная работа старого и нового кода на одном файле без доработки; новый формат в другом файле | SAD2, 3.10, 6.1; [ресёрч-2, 5.1](../../research/sad2-validation.md#51-что-в-sad2-и-parity-plan-неверно-или-неточно): `OWN_FIELDS` стирает поля, `nextId++` обнуляется | принято в SAD2 |
| D-10 | Формат `{projects, lastProjectId, commands}`, файлы пользователя и `localStorage` переносятся одной миграцией в `config` и `state` плагинов; код миграции удаляется через пару версий | Вечная поддержка старого формата; миграция по каждому файлу отдельно | [ADR-CH-0014](../../03-architecture/adr/ADR-CH-0014-secrets-config-state.md); SAD2, 3.10; ресёрч-2, 5.1, 5.4 | принято в SAD2 |
| D-11 | Пилот - `session-notifications`, не `path-drop` (он часть `sessions`: приём MIME, не проверяет ни контракт, ни права) | `path-drop`; `search`; `command-buttons` | SAD2, 6.1 (шаг 4) | принято в SAD2 |
| D-12 | pty-хост с `persist` и `attach` делается первым на текущем коде, до каркаса | Откладывать pty-хост до каркаса | [ADR-CH-0012](../../03-architecture/adr/ADR-CH-0012-hosts-watchdog-pty-host.md); SAD2, 6.1 (шаг 1): виден пользователю сразу; в коде нет буфера вывода ([ресёрч-2, 5.2](../../research/sad2-validation.md#52-допущения-sad2-которые-код-нарушает)) | принято в SAD2 |
| D-13 | Восстановление сессий после перезапуска приложения (`lazy` по умолчанию, `eager`, `off`) через `resume` агента | Оставить non-goal основного корпуса | SAD2, 5.3, вопрос 15; ресёрч-2, 5.5: противоречит non-goal корпуса, FR-1015, FR-2014 | **открыто, нужен ответ владельца** (до P1) |
| D-14 | Пробелы паритета закрываются плагинами `git` (`cyborg.git`), `command-buttons`, `claude-extensions`, `search`, `session-notifications` и требованиями к ядру (меню, сочетания с условиями, отмена, промпт, заголовок, буфер, каталог) | Оставить функции без владельца; держать git в ядре | SAD2, 5.5, вопрос 16; [ресёрч-2, 5.3](../../research/sad2-validation.md#53-каналы-ipc-и-владелец-в-модели-sad2): `git:*`, `commands:*`, `extensions:*`, `project:selected` не имеют владельца | принято в SAD2; плагин `git` - вопрос 16 |
| D-15 | `smoke.mjs` и `static-guards.test.ts` переписываются вместе с переносом, утверждения сохраняются | Ослабить утверждения; оставить DOM-проверки без изменений | SAD2, 5.5; ресёрч-2, 5.2 п. 6; parity-plan, правило 1 | принято в SAD2 |
