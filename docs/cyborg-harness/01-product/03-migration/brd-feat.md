# BRD фичи 03 - миграция и паритет

Источник: условие владельца (2026-11-02): «то, что уже сейчас есть, было сохранено»; [SAD2](../../03-architecture/design/sad2.md) и [ресёрч-2](../../research/sad2-validation.md). Родитель - [BRD продукта](../brd.md): BR-CH-002, BR-CH-001, BR-CH-007.

## 1. BRS overview

Cyborg - живое приложение: 14 фич, 153 требования, 925 тестов, дымовой тест, пользователи с данными. Перестройка в ядро и плагины не должна стоить ни одной функции. Образцы дают приёмы: паритет по записанным сессиям с allowlist допустимых расхождений (bb), снапшоты записанных сессий и тесты через настоящий загрузчик (dsh), храповики границ (bb). Нужно превратить их в процесс переноса. Сверка SAD2 с кодом ([ресёрч-2, раздел 5](../../research/sad2-validation.md#5-сверка-с-кодом)) нашла, что часть переноса - не перенос, а новое поведение (буфер вывода pty, устойчивый id сессии, миграция формата воркспейса), и ряд функций без владельца в модели (git, кнопки-команды, окно «Расширения», вклады в меню); они вошли в миграцию отдельными требованиями.

## 2. Business purpose

Перенести все нынешние функции и данные пользователя во встроенные плагины так, чтобы пользователь ничего не потерял, а потерю нельзя было пропустить.

## 3. Business scope

Внутри: матрица паритета; порядок первого этапа (шаг 0 на текущем коде, pty-хост, спайки, каркас, пилот `session-notifications`, перенос по одной функции); перенос формата воркспейса, файлов пользователя и ключей `localStorage`; прокладка совместимости каналов (58: 51 `handle` и 7 `on`); записанные сессии и подставные программы; храповики границ; бюджеты; плагины для пробелов паритета; переписывание `smoke.mjs` и `static-guards.test.ts` с сохранением утверждений; переименование окна «Расширения»; удаление прокладки после закрытия фазы; фазы и условия выхода ([дорожная карта](../../05-plans/roadmap.md)). Восстановление сессий входит условно, до решения владельца.

`non-goals`:

- изменение поведения функций в ходе переноса (улучшения - отдельными PR после паритета; исключение - переименование «Расширения Claude Code»);
- передача фокуса окну-владельцу воркспейса (улучшение после паритета);
- переход трекеров с CLI на HTTP API (новое требование, не перенос);
- второй этап изоляции доступа (установка, процесс на плагин) - по поводу, вне миграции.

|---|---|

| Строк матрицы паритета без плагина и проверки | 0 |
