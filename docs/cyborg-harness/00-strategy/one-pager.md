# Cyborg Harness: идея на одной странице

## Идея

Сделать Cyborg **ядром с плагинами**: небольшое ядро (окно, сессии, воркспейс, загрузчик плагинов, шлюз IPC) и все функции - как встроенные плагины на публичном API; затем открыть этот API сторонним плагинам и другим агентам. Всё, что работает сегодня, сохраняется.

## Проблема

- Каждая возможность правит три общих файла (`main.ts`, `preload.ts`, `app.ts`) и копится в одном целом: 14 тыс. строк, 58 каналов IPC, 65 методов моста, шесть диалогов в одном `index.html`.
- Claude Code зашит в ядро: другой агент невозможен без форка.
- Расширить приложение снаружи нельзя.
- Побочный дефект связности: список занятых сочетаний ведётся вручную и не знает акселераторов меню (D-27 фичи 12).

## Решение

Минимальное собственное ядро в духе [DeepSeek Harness](../research/deepseek-harness.md) (сервисы, `inject`, откат регистраций, режимы событий) плюс манифест, совместимость и паритетная дисциплина в духе [bb](../research/bb.md); контракт провайдера агента проектируем сами (никто из образцов не встраивает интерактивный CLI в pty); доверие трёхуровневое. Перенос «душителем» с паритетными проверками. Подробно - [OVERVIEW](../OVERVIEW.md).

## Почему сейчас

- Корпус и тесты уже зрелые (153 требования, 893 теста, дымовой тест): есть на что опереться при паритете.
- Приложение ещё небольшое (14 тыс. строк): перестройка дешевле, чем будет после следующих десяти функций.
- Два сильных образца появились и открыты: можно проверить идеи на своём коде.

## Кому и что даёт

| Кто | Что получает |
|---|---|
| Пользователь | То же приложение; позже - выбор и контроль плагинов |
| Мейнтейнер | Новая функция без правки трёх общих файлов |
| Автор плагина | Понятный API, тестовый хост, безопасные права |
| Владелец продукта | Предсказуемая стоимость развития, возможность подключать новые агенты |

## Меры успеха

| Мера | Цель |
|---|---|
| Общих файлов, которые надо править при добавлении функции | с 3-5 до 0 |
| Требований корпуса подтверждено на каждом шаге миграции | 153 из 153 |
| Тесты и дымовой тест на каждом шаге | зелёные |
| Второй агент подключён без правок ядра | да (P3) |
| Время запуска | не хуже базового более чем на 10% |
| Сбой плагина роняет приложение | никогда |

## Риски

Разрез оболочки (`app.ts`, 1360 строк); потеря функции при переносе; сторонний код рядом с сессиями агента; раздувание API и ритуалов; контракт, выточенный под один агент. Меры - в [OVERVIEW, раздел 8](../OVERVIEW.md#8-риски).
