# Глоссарий

| Термин | Значение |
|---|---|
| **Ядро** | Минимум приложения: загрузчик плагинов, реестр сервисов, шина событий, шлюз IPC, границы путей и процессов, рантайм сессий, воркспейс, оболочка окна, реестр команд, настройки и хранилище, уведомления ОС ([SAD, раздел 5](03-architecture/design/sad.md#5-состав-ядра)) |
| **Плагин Cyborg** | Модуль приложения с манифестом (`cyborg` в `package.json`), подключаемый через публичный API. Не путать с плагином Claude Code |
| **Плагин Claude Code** | То, что устанавливают командой `claude plugin`; его показывает и ставит плагин `claude-extensions` ([ADR-CH-0008](03-architecture/adr/ADR-CH-0008-terminology.md)) |
| **Встроенный плагин (L1)** | Поставляется с приложением, работает в главном процессе, пользуется только публичным API |
| **Сторонний плагин (L2)** | Установлен пользователем, работает в отдельном процессе, права из манифеста |
| **Манифест** | Блок `cyborg` в `package.json`: `id`, `engines`, `requires`, `capabilities`, `contributes` и др. |
| **Точка расширения** | Место, куда плагин подключается: services, commands, slots, ipc, events, settings и storage, providers |
| **Сервис** | Объект, который плагин предоставляет по ключу (`provide`) и другие получают (`get`/`requires`) |
| **Definition, Provider, Consumer** | Три роли заменяемой возможности: определение (ядро), реализация (плагин-провайдер), потребитель |
| **Провайдер агента** | Плагин, подключающий CLI-агента: `handshake`, `launch`, `attach`, `history`, `recover` |
| **Провайдер трекера** | Плагин для GitHub, GitLab или Jira: `detect`, `auth`, `tasks`, `changeRequests` |
| **Слот** | Место в интерфейсе, куда плагин монтирует вклад: `strip.action`, `sidebar.tab`, `session.view`, `panel`, `terminal.footer` |
| **Режимы событий** | observe (наблюдать), waterfall (перехватывать), guard (только запрещать) |
| **Возможность (capability)** | Право, названное в манифесте: `fs.read:project`, `process.git`, `net:<хост>` и др. |
| **Безопасный режим** | Запуск, при котором работают только ядро и встроенные плагины |
| **Прокладка совместимости** | Слой, который обслуживает прежние каналы IPC поверх нового шлюза до конца миграции |
| **Паритет** | Свойство «ничего не потеряно»: требования, тесты, записанные сессии, данные, бюджеты ([план паритета](04-verification/parity-plan.md)) |
| **Храповик** | Проверка в CI, показатель которой может только улучшаться (число нарушений границ, прямых обращений к `electron` и `fs`) |
| **Записанная сессия** | Набор событий хуков, вывода и ответов подставных программ с эталоном, на которых проверяется паритет |
| **Душитель (strangler)** | Приём миграции: новое вырастает вокруг старого, функции переезжают по одной, старое исчезает последним |
| **`experimental_`** | Префикс публичного члена API, который ещё может измениться |
| **P0-P5** | Фазы [дорожной карты](05-plans/roadmap.md) |
