# Глоссарий

Термины приведены к [SAD2](03-architecture/design/sad2.md). Устаревшие термины оставлены с пометкой, куда смотреть.

| Термин | Значение |
|---|---|
| **Ядро** | Хост плагинов без предметной области: воркспейс, загрузка, версии, связь через контракты, изоляция сбоев и рендера, pty, права, клавиши и события, `config` и `state`. В ядре нет агента, сессий, файлов, проектов, трекеров и общей шины. Попадает в ядро только то, что нужно всем плагинам или окну без плагинов, и плагин не решит сам, не нарушив гарантию остальным ([SAD2, 2](03-architecture/design/sad2.md#2-что-есть-ядро); [ADR-CH-0009](03-architecture/adr/ADR-CH-0009-core-boundary-and-compactness.md)) |
| **Плагин Cyborg** | Равный другим модуль приложения с манифестом; центральных плагинов нет. Не путать с плагином Claude Code. Агент, сессии, файлы, проекты - плагины |
| **Плагин Claude Code** | То, что устанавливают командой `claude plugin`; его показывает и ставит плагин `claude-extensions` ([ADR-CH-0008](03-architecture/adr/ADR-CH-0008-terminology.md)) |
| **Встроенный плагин** | Поставляется с приложением; по умолчанию в хосте `builtin`, делит origin `cyborg-plugin://builtin/` |
| **Сторонний плагин** | Установлен пользователем; по умолчанию в своём хосте, со своим origin `cyborg-plugin://<id>/`; изоляция доступа - второй этап |
| **Манифест** | Описание плагина, которое ядро читает до запуска кода: `id`, `version`, `engines`, `provides` / `requires` / `optional` / `consumes`, `permissions`, `ui`, `config`, `state`, `lock`, `keybindings` ([SAD2, 3.3](03-architecture/design/sad2.md#33-версии-и-миграции)) |
| **Контракт** | Имя, версия и типы, через которые плагины знают друг друга; типы лежат в пакете `@cyborg/contracts` без логики. События - часть контракта владельца. Две другие связи без зависимости: команда по имени и MIME при перетаскивании ([ADR-CH-0010](03-architecture/adr/ADR-CH-0010-contracts-instead-of-services.md)) |
| **Поставщик, потребитель** | Плагин, который даёт контракт (`provides`), и плагин, который его берёт (`requires`, `optional`, `consumes`). Агент - поставщик `cyborg.agent` |
| **Кратность** | `one` или `many`; объявляет потребитель. При `one` два поставщика - отказ при загрузке, при `many` все собираются списком |
| **`ctx`** | Единственное, что видит плагин: контракты, команды, клавиши, `config`, `state`, `ctx.os`. В UI-части - урезанный `UiContext` |
| **`ctx.os`** | Доступ главной части плагина к ОС (`fs`, `process`, `pty`, `net`, `shell`, `clipboard`, `env`, `secrets` и др.); нет права в манифесте - нет объекта. У UI-части его нет |
| **Хост плагинов** | `utilityProcess`, в котором работают главные части плагинов группы; группы задаёт `plugins.hosts` ([ADR-CH-0012](03-architecture/adr/ADR-CH-0012-hosts-watchdog-pty-host.md)) |
| **Сторож** | Проверка ядра, отвечает ли хост; зависший хост перезапускается, плагин-виновник выключается после серии зависаний. Пороги - стартовые, проверяются тестом |
| **pty-хост** | Отдельный `utilityProcess` ядра, который держит процессы pty и кольцевые буферы вывода; плагины не исполняет |
| **Шлюз** | Шлюз безопасности ядра: проверяет права при каждом обращении к `ctx.os`, определяет вызывающего по каналу, пишет отказы в журнал |
| **Воркспейс** | Главная сессия приложения: файл `config`, его `state` и одно окно; процесс на воркспейс ([SAD2, 3.1](03-architecture/design/sad2.md#31-воркспейс-как-главная-сессия)) |
| **`config`** | Намеренные настройки: файл воркспейса и файл пользователя; раздел на плагин со схемой и версией |
| **`state`** | Память машины (активный проект, ширины, расстановка): каталог приложения, ключ по воркспейсу; раздел на плагин |
| **Билет `pty.share()`** | Одноразовый билет, которым главная часть плагина даёт своему UI просмотр своего pty; вывод идёт из pty-хоста в `<iframe>` по `MessagePort` мимо хоста плагина |
| **Origin плагина** | `cyborg-plugin://builtin/` у встроенных, `cyborg-plugin://<id>/` у сторонних; свой origin - отдельный процесс рендера ([ADR-CH-0013](03-architecture/adr/ADR-CH-0013-plugin-ui-iframe-bridge.md)) |
| **Оболочка (shell page)** | Страница каркаса окна от ядра; раздаёт порты `<iframe>` плагинов и рисует каркас до кода плагинов |
| **Права** | Разрешения `permissions` манифеста: `fs`, `process`, `pty`, `net`, `ui.lock` и др. С первого этапа видны (прозрачность), гарантию даёт второй этап |
| **Честная граница** | `process` и `pty` дают программе все права пользователя ОС; ограничения аргументов - смягчение, не защита |
| **Этап 1, этап 2** | Этап 1: все цели ядра, без изоляции доступа. Этап 2: процесс на плагин с `--permission`, `Compartment` вторым слоем, окна согласия, установка; по поводу ([ADR-CH-0011](03-architecture/adr/ADR-CH-0011-isolation-stages.md)) |
| **Дисциплина** | Правила этапа 1, проверяемые тестами: асинхронные члены контрактов, данные переживают `structuredClone`, импорт только `@cyborg/contracts` и своих модулей, доступ к ОС только через `ctx.os` |
| **Источник секретов** | Плагин, поставщик `cyborg.secret-source` (Vault и др.); в `config` лежит только ссылка `{ "$secret": "..." }`, хранилище ядра остаётся корнем доверия ([ADR-CH-0014](03-architecture/adr/ADR-CH-0014-secrets-config-state.md)) |
| **Безопасный режим** | Запуск, при котором выключены все плагины без исключений |
| **Прокладка совместимости** | Слой, который обслуживает прежние каналы IPC до конца миграции |
| **Паритет** | Свойство «ничего не потеряно»: требования, тесты, записанные сессии, данные, бюджеты ([план паритета](04-verification/parity-plan.md)) |
| **Храповик** | Проверка в CI, показатель которой может только улучшаться |
| **Записанная сессия** | Набор событий хуков, вывода и ответов подставных программ с эталоном, на которых проверяется паритет |
| **Душитель (strangler)** | Приём миграции: новое вырастает вокруг старого, функции переезжают по одной, старое исчезает последним ([ADR-CH-0006](03-architecture/adr/ADR-CH-0006-strangler-migration-and-parity.md)) |
| **P0-P5** | Фазы [дорожной карты](05-plans/roadmap.md) |
| **Точка расширения** | Устарело: общей единицы подключения нет, плагины связаны контрактами, см. [ADR-CH-0010](03-architecture/adr/ADR-CH-0010-contracts-instead-of-services.md) |
| **Сервис, `inject`** | Устарело: реестра сервисов по ключам нет, см. «Контракт» |
| **Definition, Provider, Consumer** | Устарело: роли заменены поставщиком и потребителем контракта |
| **Провайдер агента, провайдер трекера** | Устарело как вид точки расширения; агент - плагин, поставщик `cyborg.agent` ([ADR-CH-0004](03-architecture/adr/ADR-CH-0004-agent-provider-contract.md)) |
| **Слот** | Устарело: заменён родами областей и `<iframe>` на плагин, см. [ADR-CH-0013](03-architecture/adr/ADR-CH-0013-plugin-ui-iframe-bridge.md) |
| **Режимы событий (observe, waterfall, guard)** | Устарело: общей шины нет, события входят в контракт владельца, см. [ADR-CH-0010](03-architecture/adr/ADR-CH-0010-contracts-instead-of-services.md) |
| **Уровни доверия L0-L2** | Устарело: заменены изоляцией трёх видов (сбоев, рендера, доступа), см. [ADR-CH-0011](03-architecture/adr/ADR-CH-0011-isolation-stages.md) |
| **Возможность (capability)** | Устарело: теперь «права» (`permissions`) |
| **`experimental_`** | Префикс члена API, который ещё может измениться; в SAD2 не описан, судьба открыта до P1 ([ADR-CH-0002](03-architecture/adr/ADR-CH-0002-manifest-and-compatibility.md)) |
