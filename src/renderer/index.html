      Кнопки команд

      Действующий набор: встроенные кнопки (Сливай, Сделай PR, Мердж, Приберись) и ваши. Что здесь записано, то и сохранится в файле воркспейса. Кнопка с тем же label, что у встроенной, заменяет её. Поля: label, text (одна строка), description (что делает кнопка - подсказка), submit (true - текст и Enter, по умолчанию false - только вставка), hotkey (F5, Alt+S, Ctrl+Shift+K, CmdOrCtrl+Shift+M), disabled (true - скрыть кнопку; так отключается и встроенная). В text работают {branch}, {pr}, {task}. Файл воркспейса перечитывается сам. 

      [
  { "label": "Тесты", "text": "прогони тесты", "submit": true, "hotkey": "F5" },
  { "label": "Ревью", "text": "сделай ревью {pr}", "hotkey": "Alt+R" }
]

      Промпты кнопок

      Первое сообщение сессии, которую запускают кнопки: «Ревью», «Доработать» и «CI» у MR (mr.review, mr.rework, mr.ci), «Взять в работу» у задачи GitHub и GitLab (task.start) и сессия по задаче Jira (jira.start). Показаны действующие тексты с описаниями; что здесь записано, то и сохранится в файле воркспейса. В text работают только подстановки, названные в описании промпта ({mr_url}, {task_url}, {status_command}, {jira_key}): название задачи или MR, ветки и автор в промпт не попадают. Текст - одна строка, не начинается с «-».
