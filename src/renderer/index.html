    Вход Claude на хостах

    Удалённые агенты входят в Claude этим токеном, и claude auth login на хосте не нужен. Токен выдаёт claude setup-token на этой машине. Cyborg передаёт его агенту в окружении процесса при запуске и пробуждении сессии; на диск хоста токен не пишется.

    Окружение

    Переменные, которые получают все процессы, запускаемые Cyborg: сессии (локальные и на хостах), терминал запуска, git, gh, glab, jira, claude plugin, ssh. Выражение (команда sh) вычисляется при выборе и при каждом запуске Cyborg; значения хранятся в памяти, а файл содержит только значения-литералы и команды.

      Паспорт проекта

      Кнопки

      Встроенные кнопки, общие для всех воркспейсов (файлы commands.json и prompts.json) и кнопки этого воркспейса. Слой воркспейса меняет у нижней кнопки только отдельные поля: остальные берутся снизу, и правка снизу доходит сюда. Сочетание клавиш у верхней кнопки забирается у нижней без ошибки. Кнопки запуска сессий (MR, задачи, Jira) правятся только во всех воркспейсах.

      Глобальный CLAUDE.md

      Инструкции Claude Code для всех сессий на этой машине: язык, тон, длина ответов, предпочтения в работе. Это файл CLAUDE.md в каталоге настроек Claude Code (~/.claude либо CLAUDE_CONFIG_DIR); удалённые сессии получают его копию на хосте. Новая сессия читает сохранённый текст, уже идущие - нет. Правила репозитория лежат в его собственном CLAUDE.md.
