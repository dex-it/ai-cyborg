      Кнопки команд

      Общий набор - для всех воркспейсов: встроенные кнопки (Сливай, Сделай PR, Мердж, Приберись) и ваши. Хранится в commands.json в папке настроек Cyborg. Воркспейс может заменить или скрыть любую кнопку отсюда.

      Набор этого воркспейса поверх общего: здесь видны общие кнопки и кнопки воркспейса. В файл воркспейса пишутся только кнопки, отличные от общих, поэтому правка общего набора доходит и сюда.

      Кнопка с тем же label, что у встроенной или общей, заменяет её. Поля: label, text (одна строка), description (что делает кнопка - подсказка), submit (true - текст и Enter, по умолчанию false - только вставка), hotkey (F5, Alt+S, Ctrl+Shift+K, CmdOrCtrl+Shift+M), disabled (true - скрыть кнопку; так отключается и встроенная). В text работают {branch}, {pr}, {task}. Порядок строк - порядок кнопок на полосе, встроенные и общие тоже можно переставить. Встроенную или общую кнопку, удалённую из списка, редактор вернёт при следующем открытии (скройте её через disabled). Файлы перечитываются сами. 

      [
  { "label": "Тесты", "text": "прогони тесты", "submit": true, "hotkey": "F5" },
  { "label": "Ревью", "text": "сделай ревью {pr}", "hotkey": "Alt+R" }
]

      Промпты кнопок

      Первое сообщение сессии, которую запускают кнопки: «Ревью», «Доработать» и «CI» у MR (mr.review, mr.rework, mr.ci), «Взять в работу» у задачи GitHub и GitLab (task.start) и сессия по задаче Jira (jira.start). Показаны действующие тексты с описаниями; что здесь записано, то и сохранится в общем для всех воркспейсов файле prompts.json. В text работают только подстановки, названные в описании промпта ({mr_url}, {task_url}, {status_command}, {jira_key}): название задачи или MR, ветки и автор в промпт не попадают. Текст - одна строка, не начинается с «-».
